## 一、链表节点

```c
typedef struct Node {
    int data;
    struct Node *next;
} Node;
```

链表用指针把分散的内存节点串起来，适合"不知道有多少个"的数据。

## 二、头插法

```c
Node *head = NULL;
Node *n = (Node *)malloc(sizeof(Node));
n->data = 1;
n->next = head;
head = n;
```

## 三、文件读写

```c
FILE *fp = fopen("data.txt", "w");   // w 写入
fprintf(fp, "%d %s\n", 18, "小明");
fclose(fp);

fp = fopen("data.txt", "r");          // r 读取
int age; char name[32];
fscanf(fp, "%d %s", &age, name);
fclose(fp);
```

## 四、预处理

#define PI 3.14159
