## 一、if 判断

```c
int score = 85;
if (score >= 90) {
    printf("优秀\n");
} else if (score >= 60) {
    printf("及格\n");
} else {
    printf("加油\n");
}
```

## 二、switch 多分支

```c
int day = 3;
switch (day) {
    case 1: printf("周一\n"); break;
    case 2: printf("周二\n"); break;
    default: printf("其它\n");
}
```

> 记得每个分支后写 `break`，否则会"穿透"到下一个分支。

## 三、循环

```c
// for：知道次数
for (int i = 1; i <= 5; i++) {
    printf("%d ", i);
}

// while：先判断
int n = 1, sum = 0;
while (n <= 100) {
    sum += n;
    n++;
}

// do-while：先执行一次
int x;
do {
    printf("输入大于 0 的数：");
    scanf("%d", &x);
} while (x <= 0);
```

## 四、break 与 continue

- `break`：立刻跳出整个循环
- `continue`：跳过本次，进入下一次

## 五、练习：猜数字

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main(void) {
    srand((unsigned)time(NULL));
    int secret = rand() % 100 + 1;
    int guess;
    do {
        printf("猜 1~100：");
        scanf("%d", &guess);
        if (guess > secret) printf("大了\n");
        else if (guess < secret) printf("小了\n");
    } while (guess != secret);
    printf("恭喜！\n");
    return 0;
}
```
