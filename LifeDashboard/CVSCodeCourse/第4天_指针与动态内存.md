## 一、内存地址：每个变量都有"门牌号"

### 1.1 内存就是一排排小格子

计算机内存（RAM）可以想象成一排编号的格子，每个格子能存 1 个字节。
每个格子有一个**地址**（门牌号），程序里的每个变量都住在某些格子里。

```c
int x = 10;
printf("x 的值：%d\n", x);
printf("x 的地址：%p\n", (void *)&x);
```

**预期输出（地址每次运行可能不同）：**

```
x 的值：10
x 的地址：0x7ffeefbff5ac
```

`&x` 就是"x 的门牌号"（地址）。`%p` 是打印地址的占位符。

内存图：

```
地址          内容
0x...5ac  ┌──────────┐
          │    10    │   ← 变量 x（int 占 4 个字节）
          └──────────┘
```

### 1.2 指针变量：存"地址"的变量

普通变量存值，**指针变量存地址**。

```c
int x = 10;
int *p = &x;       // p 是一个"指向 int 的指针"，存的是 x 的地址
```

```
变量 p（指针）              变量 x
┌──────────┐              ┌──────────┐
│ 0x...5ac │ ───────────→ │    10    │
└──────────┘   指向        └──────────┘
  存的是地址                  存的是值
```

- `int *p`：声明"p 是指向 int 类型的指针"
- `p = &x`：把 x 的地址放进 p，此时说"p 指向 x"

### 1.3 解引用：通过地址找到那个变量

```c
int x = 10;
int *p = &x;

printf("%d\n", *p);   // *p 表示"p 指向的那个变量" → 10
*p = 20;              // 等价于 x = 20，通过指针修改 x
printf("%d\n", x);    // 20
```

`*` 在**声明**里和**表达式**里含义不同：

| 位置 | 写法 | 含义 |
|---|---|---|
| 声明 | `int *p;` | p 是一个指向 int 的指针 |
| 表达式 | `*p` | 取出 p 指向的变量的值（解引用） |

> **把 `int *p` 读成"p 是指向 int 的指针"**，`*p` 读成"p 所指的东西"，
> 这样就不会混了。`&` 是"取地址"，`*` 是"按地址取内容"，两者互为逆操作：
> `*&x == x`。

## 二、指针做参数：修改函数外面的变量

### 2.1 为什么普通参数改不了外面的变量？

第 3 天说过：形参是实参的**副本**（值传递）。

```c
void bad_swap(int a, int b) {   // ❌ 交换的是副本
    int t = a;
    a = b;
    b = t;
}
// 调用后外面的 x、y 完全没变
```

### 2.2 传地址，就能改原变量

```c
#include <stdio.h>

void swap(int *a, int *b) {     // ✅ 参数是指针，存的是地址
    int t = *a;                 // t = a 指向的那个变量的值
    *a = *b;                    // 把 b 指向的值写进 a 指向的变量
    *b = t;
}

int main(void) {
    int x = 10, y = 20;
    printf("交换前：%d %d\n", x, y);
    swap(&x, &y);               // 传地址进去
    printf("交换后：%d %d\n", x, y);
    return 0;
}
```

**预期输出：**

```
交换前：10 20
交换后：20 10
```

调用过程内存图：

```
main:  x=10  y=20
swap:  a=&x  b=&y          ← 复制的是地址，不是值
         │      │
         ▼      ▼
        x=20   y=10        ← 通过 *a *b 修改了 main 里的变量
```

> **口诀：想让函数修改外面的变量，就把那个变量的地址传进去，在函数里用 `*` 操作。**

### 2.3 const 指针参数：只读保护

```c
void printValue(const int *p) {
    printf("%d\n", *p);      // 可以读
    // *p = 99;              // ❌ 编译错误：const 保护，不能改
}
```

`const int *p` 表示"p 指向的内容不能被修改"，适合只读访问的函数，
让调用者放心：这个函数不会偷偷改我的数据。

## 三、数组与指针：数组名就是地址

### 3.1 数组名 = 首元素地址

```c
int a[3] = {10, 20, 30};
int *p = a;          // a 就等价于 &a[0]，数组名自动变成地址

printf("%d\n", *a);         // 10：a[0]
printf("%d\n", *(a + 1));   // 20：a[1]
printf("%d\n", p[2]);       // 30：指针也能用下标
```

**p[i] 和 *(p+i) 完全等价**，这是 C 语言的本质：

| 写法 | 含义 |
|---|---|
| `a[0]` | 第 0 个元素 |
| `*a` | 同上 |
| `a[i]` | 第 i 个元素 |
| `*(a + i)` | 同上（a+i 是"往后数 i 个"的地址） |
| `&a[i]` | 第 i 个元素的地址 |

内存图：

```
地址      值
0x1000 →  10   ← a / p 都指向这里（a[0]）
0x1004 →  20   ← a+1（a[1]）
0x1008 →  30   ← a+2（a[2]）
```

> 指针加 1 不是地址加 1，而是**跳到下一个元素**。对 int 指针来说，
> 地址实际加了 4（int 占 4 字节），这叫"指针运算按类型大小步进"。

### 3.2 指针遍历数组

```c
int a[5] = {1, 2, 3, 4, 5};
int *p = a;

for (int i = 0; i < 5; i++) {
    printf("%d ", *p);
    p++;              // 指针前进到下一个元素
}
printf("\n");
```

### 3.3 函数参数里 int arr[] 和 int *arr 是一回事

```c
void printArr(int arr[], int n) {   // 等价于 void printArr(int *arr, int n)
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
}
```

数组传给函数时**退化成指针**，函数里修改数组元素，外面的数组确实会变
（因为传的是地址）。这就是第 3 天冒泡排序能改到外面数组的原因。

### 3.4 指针的指针（了解）

```c
int x = 10;
int *p = &x;
int **pp = &p;      // pp 指向 p，p 指向 x

printf("%d\n", **pp);   // 10
```

指针的指针在"函数里要修改指针本身"时用（第 6 天链表头插法会用 `Node **`），
今天先混个脸熟。

## 四、动态内存：malloc 和 free

### 4.1 为什么要动态分配？

之前用的变量、数组都是**编译时就定好大小**的（在栈上）。但很多时候
程序运行时才知道需要多大：用户输入 n，要存 n 个数。这时候就用 `malloc`
在**堆**上按需分配。

### 4.2 malloc 的基本用法

```c
#include <stdio.h>
#include <stdlib.h>     // malloc / free 在这里

int main(void) {
    int n;
    printf("要存几个数？");
    scanf("%d", &n);

    // 分配 n 个 int 的空间（n * 4 字节）
    int *arr = (int *)malloc(n * sizeof(int));
    if (arr == NULL) {          // ⚠️ 必须检查分配是否成功
        printf("内存分配失败！\n");
        return 1;               // 非 0 返回表示异常退出
    }

    for (int i = 0; i < n; i++) {
        arr[i] = i * 2;         // 用起来跟数组一样
    }
    for (int i = 0; i < n; i++) {
        printf("%d ", arr[i]);
    }
    printf("\n");

    free(arr);                  // ⚠️ 用完必须释放
    return 0;
}
```

**malloc 三要素：**

| 要素 | 写法 | 说明 |
|---|---|---|
| 字节数 | `n * sizeof(int)` | 个数 × 单个大小，别写死 4 |
| 类型转换 | `(int *)` | 把 void* 转成 int* |
| 判空 | `if (arr == NULL)` | 分配失败返回 NULL，不检查会崩 |

### 4.3 free 之后要置 NULL

```c
free(arr);
arr = NULL;     // 习惯：释放后立即置空，避免"野指针"
```

### 4.4 内存三大灾难

| 问题 | 现象 | 避免方法 |
|---|---|---|
| **内存泄漏** | malloc 了但从不 free，程序内存越用越多 | 谁分配谁释放，记得 free |
| **野指针** | 指针指向未知内存（没初始化、free 后没置空） | 初始化指针、free 后置 NULL |
| **悬垂指针** | 指针指向的内存已被释放 | 释放后不要再使用该指针 |

```c
// 野指针示例（错误示范）
int *p;                 // 没初始化，p 里是随机地址
*p = 10;                // ❌ 向未知内存写入，可能崩溃

// 正确姿势
int *p = NULL;          // 初始化为 NULL
p = &x;                 // 指向确定的地方
```

## 五、指针综合实战：动态数组 + 函数

```c
#include <stdio.h>
#include <stdlib.h>

// 把数组元素翻倍（指针参数，修改外面的数组）
void doubleAll(int *arr, int n) {
    for (int i = 0; i < n; i++) {
        arr[i] *= 2;
    }
}

int main(void) {
    int n = 5;
    int *arr = (int *)malloc(n * sizeof(int));
    if (arr == NULL) return 1;

    for (int i = 0; i < n; i++) arr[i] = i + 1;   // 1 2 3 4 5
    doubleAll(arr, n);                             // 2 4 6 8 10

    for (int i = 0; i < n; i++) printf("%d ", arr[i]);
    printf("\n");

    free(arr);
    arr = NULL;
    return 0;
}
```

**预期输出：**

```
2 4 6 8 10
```

### 练习 1：swap 三兄弟
分别写出用 `int` 参数、`int *` 参数、`int **` 参数的三个交换函数，测试哪个能真正交换 main 里的变量。

<details>
<summary>练习 1 参考思路</summary>

```c
#include <stdio.h>

void swapByValue(int a, int b) {   // ❌ 只交换副本
    int t = a; a = b; b = t;
}

void swapByPtr(int *a, int *b) {   // ✅ 交换原变量
    int t = *a; *a = *b; *b = t;
}

void swapByPtrPtr(int **a, int **b) {  // ✅ 交换指针本身
    int *t = *a; *a = *b; *b = t;
}

int main(void) {
    int x = 10, y = 20;
    swapByValue(x, y);
    printf("值传递后：%d %d（没变）\n", x, y);
    swapByPtr(&x, &y);
    printf("指针传递后：%d %d（变了）\n", x, y);
    return 0;
}
```
</details>

### 练习 2：动态数组
输入 n，用 malloc 创建长度为 n 的数组，让用户逐个输入元素，再输出最大值和平均值，最后 free。

<details>
<summary>练习 2 参考思路</summary>

```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int n;
    printf("输入数组长度：");
    scanf("%d", &n);

    int *arr = (int *)malloc(n * sizeof(int));
    if (arr == NULL) { printf("分配失败\n"); return 1; }

    int sum = 0, max;
    printf("输入 %d 个数：", n);
    for (int i = 0; i < n; i++) {
        scanf("%d", &arr[i]);
        sum += arr[i];
        if (i == 0) max = arr[i];
        else if (arr[i] > max) max = arr[i];
    }
    printf("最大值 %d，平均值 %.2f\n", max, sum / (double)n);

    free(arr);
    arr = NULL;
    return 0;
}
```
</details>

### 练习 3：解释题（写下来才算会）
用自己的话写出"野指针"和"内存泄漏"是什么，并各写一条避免方法。

<details>
<summary>练习 3 参考思路</summary>

- **野指针**：指针变量没有指向合法内存（未初始化，或指向已被释放的内存），
  对它解引用会导致未定义行为甚至程序崩溃。
  避免方法：指针定义时初始化为 NULL；free 之后立刻置 NULL。
- **内存泄漏**：用 malloc 分配的内存没有被 free，程序运行时占用的内存只增不减，
  长时间运行会把内存耗尽。
  避免方法：谁 malloc 谁 free；分配和释放尽量成对出现在同一函数或同一逻辑块。
</details>

### 练习 4：反转数组（挑战）
写一个函数 `void reverse(int *arr, int n)`，原地反转数组（不开新数组）。

<details>
<summary>练习 4 参考思路</summary>

```c
#include <stdio.h>

void reverse(int *arr, int n) {
    int left = 0, right = n - 1;
    while (left < right) {
        int t = arr[left];
        arr[left] = arr[right];
        arr[right] = t;
        left++;
        right--;
    }
}

int main(void) {
    int a[] = {1, 2, 3, 4, 5};
    int n = 5;
    reverse(a, n);
    for (int i = 0; i < n; i++) printf("%d ", a[i]);
    printf("\n");   // 5 4 3 2 1
    return 0;
}
```
</details>

## 七、今天的小结

- `&x` 取地址，`*p` 解引用，`*&x == x`
- 想修改函数外面的变量 → 传地址，函数里用 `*` 操作
- 数组名就是首元素地址；`p[i]` 等价于 `*(p+i)`；指针 +1 跳到下一个元素
- `malloc` 按字节分配堆内存 → 必须判空 → 用完 `free` → 置 NULL
- 三大灾难：内存泄漏（不 free）、野指针（指向未知）、悬垂指针（指向已释放）
