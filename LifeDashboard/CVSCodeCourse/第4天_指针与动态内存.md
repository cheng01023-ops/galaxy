## 一、地址与指针

```c
int x = 10;
int *p = &x;      // p 保存 x 的地址
printf("%d\n", *p); // 解引用：取出 p 指向的值 = 10
*p = 20;          // 通过指针修改 x
```

- `&x`：x 的地址
- `int *p`：声明一个"指向 int 的指针"
- `*p`：p 指向的那个变量

## 二、用指针交换两个数

```c
void swap(int *a, int *b) {
    int t = *a;
    *a = *b;
    *b = t;
}
```

## 三、动态内存 malloc / free

```c
#include <stdlib.h>
int n = 5;
int *arr = (int *)malloc(n * sizeof(int));
if (arr == NULL) return 1;   // 分配失败
arr[0] = 10;
free(arr);                    // 用完后释放
```

- `malloc` 在堆上按字节分配内存，返回 void*
- 用完必须 `free`，否则内存泄漏
- 分配失败会返回 NULL，一定要检查

## 四、数组与指针

```c
int a[3] = {1, 2, 3};
int *p = a;        // a 就是 &a[0]
printf("%d\n", *(p + 1)); // 2
```
