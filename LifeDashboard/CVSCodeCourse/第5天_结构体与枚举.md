## 一、为什么需要结构体？

如果只用一个学生的数据，可以写：

```c
char name[32] = "小明";
int age = 18;
double score = 92.5;
```

但一个班有 30 个学生呢？难道写 30 组变量？显然不行。
**结构体（struct）能把相关的数据打包成一个整体**，就像做了一张"档案表"：

```c
struct Student {          // 定义一个"学生"模板
    char name[32];        // 姓名
    int age;              // 年龄
    double score;         // 成绩
};
```

> 定义结构体时花括号后面**必须加分号** `};`，这和函数不一样，新手最容易漏。

## 二、结构体的基本用法

### 2.1 创建变量并访问成员

```c
#include <stdio.h>
#include <string.h>

struct Student {
    char name[32];
    int age;
    double score;
};

int main(void) {
    struct Student s1;              // 用模板创建变量

    strcpy(s1.name, "小明");        // 字符串成员要用 strcpy 赋值
    s1.age = 18;                    // 普通成员直接用 =
    s1.score = 92.5;

    printf("%s 今年 %d 岁，成绩 %.1f\n", s1.name, s1.age, s1.score);
    return 0;
}
```

**预期输出：**

```
小明 今年 18 岁，成绩 92.5
```

用 `.`（点运算符）访问成员：`变量名.成员名`。

> ⚠️ **字符数组成员不能直接 `s1.name = "小明"`**——数组名是常量地址，不能重新赋值。
> 必须用 `strcpy(s1.name, "小明")`（字符串函数，第 3 天学过）。

### 2.2 结构体初始化

```c
struct Student s2 = {"小红", 17, 98.0};   // 按成员顺序初始化
struct Student s3 = {.name = "小刚", .age = 19};  // 指定成员初始化（C99 起）
```

### 2.3 结构体的内存布局

```c
struct Student { char name[32]; int age; double score; };
```

```
地址偏移  0 ~ 31      32 ~ 35     36~39(填充)   40 ~ 47
内容      name[32]    age         （对齐填充）   score
```

- 结构体占用的内存 = 所有成员之和 + 可能的**填充字节**
- 因为 CPU 读内存按对齐地址最快，编译器会在成员之间插入填充
- `sizeof(struct Student)` 通常不是简单的 32+4+8=44，而可能是 48
- 用 `%zu` 打印 `sizeof(struct Student)` 看看实际大小

> 结构体成员顺序会影响总大小：把大类型（double）放前面通常更省空间，
> 不过初学者阶段不必纠结，知道有"对齐"这回事即可。

## 三、typedef：给类型起个短名字

每次写 `struct Student` 有点啰嗦，`typedef` 可以给它起别名：

```c
typedef struct {
    char name[32];
    int age;
    double score;
} Student;              // 以后直接用 Student，不用写 struct 关键字
```

之后就能直接写：

```c
Student s1;             // 等价于 struct Student s1
```

> `typedef` 就是"给类型起别名"：`typedef 原类型 新名字;`。
> 本课程后面的例子都用 typedef 写法（更简洁），这也是工程中的常见习惯。

## 四、结构体数组

一个班 30 人 = 一个"Student 数组"：

```c
#include <stdio.h>
#include <string.h>

typedef struct {
    char name[32];
    int age;
    double score;
} Student;

int main(void) {
    Student classRoom[3] = {
        {"小明", 18, 92.5},
        {"小红", 17, 98.0},
        {"小刚", 19, 88.5}
    };

    // 遍历输出
    for (int i = 0; i < 3; i++) {
        printf("%s  %d 岁  %.1f 分\n", classRoom[i].name,
               classRoom[i].age, classRoom[i].score);
    }

    // 求平均分
    double sum = 0;
    for (int i = 0; i < 3; i++) {
        sum += classRoom[i].score;
    }
    printf("平均分：%.2f\n", sum / 3);
    return 0;
}
```

**预期输出：**

```
小明  18 岁  92.5 分
小红  17 岁  98.0 分
小刚  19 岁  88.5 分
平均分：93.00
```

`classRoom[i]` 是一个 Student，`.name` 访问它的姓名成员。

## 五、结构体指针与 `->`

### 5.1 为什么函数要传指针？

```c
void printStudent(Student s) {      // ❌ 整个结构体被复制一份
    printf("%s\n", s.name);
}
// 结构体很大时（几十上百字节），每次调用都复制，浪费内存和时间

void printStudent(const Student *s) {   // ✅ 只传地址（8 字节）
    printf("%s\n", s->name);
}
```

- 传值：复制整个结构体（大对象开销大）
- 传指针：只复制地址，快；加 `const` 保证不修改原数据

### 5.2 `->` 箭头运算符

通过指针访问成员，用 `->`（下面代码依赖前面定义的 `Student` 类型）：

```c
void printStudent(const Student *s) {
    printf("%s %d %f\n", s->name, s->age, s->score);
}

int main(void) {
    Student s1 = {"小明", 18, 92.5};
    printStudent(&s1);          // 传地址
    return 0;
}
```

**`->` 就是 `(*指针).成员` 的简写**：

```c
s->name   等价于  (*s).name
s->age    等价于  (*s).age
```

> 记不住就念："指针箭头，指向成员"。只有**结构体指针**用 `->`，
> 结构体**普通变量**用 `.`，两者别混。

### 5.3 用指针修改结构体成员

```c
void birthday(Student *s) {
    s->age++;          // 通过指针修改外面的结构体
}

int main(void) {
    Student s1 = {"小明", 18, 92.5};
    birthday(&s1);
    printf("%d\n", s1.age);   // 19
    return 0;
}
```

和普通变量一样：想让函数修改外面的结构体，就传它的地址。

## 六、枚举 enum

### 6.1 什么是枚举？

有些变量只有少数几种取值（星期、颜色、状态），枚举可以把这些"名字"定义出来，
让代码可读性大大提升：

```c
typedef enum { RED, GREEN, BLUE } Color;
```

**枚举的值本质上是整数**，默认从 0 开始递增：

```c
RED   == 0
GREEN == 1
BLUE  == 2
```

### 6.2 使用枚举

```c
#include <stdio.h>

typedef enum { RED, GREEN, BLUE } Color;

void printColor(Color c) {
    switch (c) {
        case RED:   printf("红色\n"); break;
        case GREEN: printf("绿色\n"); break;
        case BLUE:  printf("蓝色\n"); break;
        default:    printf("未知颜色\n");
    }
}

int main(void) {
    Color c = GREEN;
    printColor(c);            // 绿色
    printf("GREEN 的值是 %d\n", c);   // 1
    return 0;
}
```

### 6.3 指定枚举的值

```c
typedef enum { MON = 1, TUE, WED, THU, FRI, SAT, SUN } Weekday;
// MON=1，TUE=2，…… SUN=7
```

指定第一个为 1 后，后面自动递增，很符合"星期一到星期日"的直觉。

> **enum 和宏（#define）怎么选？** 现代 C 倾向用 enum 代替一组相关的 `#define`，
> 因为枚举有类型、能自动编号、调试时能看到名字。第 6 天会讲 `#define`。

## 七、综合实战：图书管理系统（今天的核心练习）

```c
#include <stdio.h>
#include <string.h>

typedef struct {
    char title[64];
    char author[32];
    double price;
} Book;

// 按价格排序（冒泡排序，第 3 天学的）
void sortByPrice(Book books[], int n) {
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            if (books[j].price > books[j + 1].price) {
                Book t = books[j];            // 整个结构体一次交换
                books[j] = books[j + 1];
                books[j + 1] = t;
            }
        }
    }
}

void printBooks(const Book books[], int n) {
    for (int i = 0; i < n; i++) {
        printf("%-20s %-12s ¥%.2f\n", books[i].title,
               books[i].author, books[i].price);
    }
}

int main(void) {
    Book shelf[4] = {
        {"C程序设计", "谭浩强", 39.5},
        {"算法笔记", "胡凡", 88.0},
        {"C Primer Plus", "普拉塔", 129.0},
        {"深入理解计算机系统", "布莱恩特", 99.0}
    };

    printf("排序前：\n");
    printBooks(shelf, 4);

    sortByPrice(shelf, 4);

    printf("\n按价格排序后：\n");
    printBooks(shelf, 4);
    return 0;
}
```

**预期输出（节选）：**

```
排序前：
C程序设计             谭浩强        ¥39.50
算法笔记              胡凡          ¥88.00
C Primer Plus        普拉塔        ¥129.00
深入理解计算机系统    布莱恩特      ¥99.00

按价格排序后：
C程序设计             谭浩强        ¥39.50
算法笔记              胡凡          ¥88.00
深入理解计算机系统    布莱恩特      ¥99.00
C Primer Plus        普拉塔        ¥129.00
```

> 注意 `Book t = books[j];`——结构体可以直接整体赋值/整体交换，很方便。
> 字符串成员需要 strcpy，但整个结构体用 `=` 复制是合法的。

## 八、今天的分步练习

### 练习 1：点坐标
定义一个 `Point` 结构体（x、y 两个 double），写函数计算两点之间的距离。

<details>
<summary>练习 1 参考思路</summary>

```c
#include <stdio.h>
#include <math.h>

typedef struct {
    double x;
    double y;
} Point;

double distance(Point a, Point b) {
    double dx = a.x - b.x;
    double dy = a.y - b.y;
    return sqrt(dx * dx + dy * dy);   // 需要 #include <math.h>
}

int main(void) {
    Point p1 = {0, 0};
    Point p2 = {3, 4};
    printf("距离 = %.2f\n", distance(p1, p2));   // 5.00
    return 0;
}
```

> 用 `sqrt` 需要 `#include <math.h>`，在 Xcode 里还要在
> Build Settings 的 Other Linker Flags 加 `-lm`（或直接不用 sqrt，用勾股定理手写开方）。
</details>

### 练习 2：学生数组
定义 Student 结构体，输入 3 个学生的姓名和成绩，找出成绩最高的学生并打印。

<details>
<summary>练习 2 参考思路</summary>

```c
#include <stdio.h>
#include <string.h>

typedef struct {
    char name[32];
    int score;
} Student;

int main(void) {
    Student students[3];
    for (int i = 0; i < 3; i++) {
        printf("第 %d 个学生 姓名 成绩：", i + 1);
        scanf("%s %d", students[i].name, &students[i].score);
    }

    int best = 0;                       // 记录最高分下标
    for (int i = 1; i < 3; i++) {
        if (students[i].score > students[best].score) best = i;
    }

    printf("最高分：%s %d\n", students[best].name, students[best].score);
    return 0;
}
```
</details>

### 练习 3：枚举星期
用枚举表示一周七天，输入数字 1~7，输出对应的星期名。

<details>
<summary>练习 3 参考思路</summary>

```c
#include <stdio.h>

typedef enum { MON = 1, TUE, WED, THU, FRI, SAT, SUN } Weekday;

int main(void) {
    int n;
    printf("输入 1~7：");

        case THU: printf("星期四\n"); break;
        case FRI: printf("星期五\n"); break;
        case SAT: printf("星期六\n"); break;
        case SUN: printf("星期日\n"); break;
```

### 练习 4：按成绩排序（综合）
用第 3 天的冒泡排序思想，把学生结构体数组按成绩从高到低排序。

<details>
<summary>练习 4 参考思路</summary>

```c
#include <stdio.h>
#include <string.h>

typedef struct {
    char name[32];
    int score;
} Student;

void sortDesc(Student s[], int n) {
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            if (s[j].score < s[j + 1].score) {   // 高的往前排
                Student t = s[j];
                s[j] = s[j + 1];
                s[j + 1] = t;
            }
        }
    }
}

int main(void) {
    Student classRoom[3] = {
        {"小明", 85}, {"小红", 98}, {"小刚", 76}
    };
    sortDesc(classRoom, 3);
    for (int i = 0; i < 3; i++) {
        printf("%s %d\n", classRoom[i].name, classRoom[i].score);
    }
    return 0;
}
```

## 九、今天的小结

- `struct` 把相关数据打包成自定义类型；定义结尾要**加分号**
- `typedef` 给类型起别名，让代码更简洁
- 结构体数组 = 批量管理同类型对象
- 函数传结构体用**指针 + const**，访问成员用 `->`
- `enum` 的值是整数，默认从 0 开始，可指定起始值
- 结构体可以整体赋值/交换，字符串成员用 strcpy
