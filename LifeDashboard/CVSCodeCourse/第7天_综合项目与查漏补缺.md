## 项目：学生成绩管理系统

功能要求：
1. 添加学生（姓名 + 成绩）
2. 查看所有学生
3. 按成绩排序
4. 保存到文件 / 从文件加载
5. 删除学生

核心结构：

```c
typedef struct {
    char name[32];
    int score;
} Student;

Student students[100];
int count = 0;
```

完整参考实现见 `day07_final_project.c`。
