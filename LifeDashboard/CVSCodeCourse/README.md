# C 语言七天学习方案（VSCode 版）

用 7 天，从零学会 C 语言，达到和 C++ 七天课程相当的水平。
**每天 4～6 小时，动手为主，先抄 → 再改 → 最后自己写。**

## 课程目录

| 天 | 主题 | 核心内容 |
|---|---|---|
| 第 0 天 | 预备课 | 编程是什么、编译与运行、学 C 要准备什么、学习方法 |
| 第 1 天 | VSCode 入门 + C 基础语法 | 搭建环境、.c 文件、F5 运行、printf/scanf、5 种基本类型、运算符 |
| 第 2 天 | 流程控制与循环 | if/switch、for/while/do-while、break/continue、猜数字 |
| 第 3 天 | 函数、数组、字符串 | 函数与作用域、递归、一/二维数组、字符串与 `\0` |
| 第 4 天 | 指针与动态内存 | 地址与指针、指针参数、数组与指针、malloc/free、内存安全 |
| 第 5 天 | 结构体与枚举 | struct、typedef、结构体数组/指针、->、enum |
| 第 6 天 | 链表、文件与预处理 | 单链表增删查、fopen/fprintf/fscanf、#define/#include |
| 第 7 天 | 综合项目 + 查漏补缺 | 学生成绩管理系统、调试技巧、7 天知识地图、进阶路线 |

## 配套文件

- `day01_hello.c` ~ `day07_final_project.c`：每天一份可编译运行的示例代码
- `C术语速查.md`：常用类型、库、指针要点的速查表，忘了就翻

## 学习方法

1. **看**：读当天讲解，理解概念
2. **抄**：把示例代码手敲进 VSCode 并运行，观察输出
3. **改**：改数字、改条件，看结果怎么变
4. **写**：不看答案完成练习（答案折叠在 `<details>` 里，卡住 30 分钟再翻）
5. **查**：用术语速查复习

## 环境准备（macOS）

1. 官网下载安装 VSCode（免费）
2. VSCode 扩展市场安装 **C/C++**（微软官方）
3. 终端运行 `xcode-select --install` 安装命令行工具（提供 clang 编译器）
4. 打开文件夹 → 新建 `hello.c` → 按 **F5** 选择 C++ (GDB/LLDB) 和 clang 运行

## 自测标准

学完 7 天后，你应该能独立完成：

- 写一个带函数、数组、指针、结构体的完整 C 程序
- 用 malloc/free 管理动态内存，且不泄漏
- 用链表组织动态数据
- 用文件把数据保存下来，下次启动自动加载
