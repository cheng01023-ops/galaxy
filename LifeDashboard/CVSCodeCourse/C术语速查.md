# C 术语速查

> 忘了就回来翻。本表覆盖 7 天课程的全部核心语法，按"类型 → 输入输出 → 流程 → 函数 → 指针 → 结构体 → 文件 → 预处理"排列。

## 一、基本类型

| 类型 | 说明 | 占位符 | 示例 |
|---|---|---|---|
| `int` | 整数 | `%d` | `int a = 42;` |
| `double` | 双精度小数 | `%f`（读入用 `%lf`） | `double p = 3.14;` |
| `float` | 单精度小数 | `%f` | `float f = 1.5f;` |
| `char` | 单个字符（单引号） | `%c` | `char c = 'A';` |
| `_Bool` | 布尔（1 真 / 0 假） | `%d` | `_Bool ok = 1;` |

要点：
- 字符用单引号 `'A'`，字符串用双引号 `"AB"`，别写反
- 保留小数位：`%.2f` = 保留 2 位
- 变量名：字母/数字/下划线，不能数字开头，不能是关键字，小写 + 下划线

## 二、输入输出

| 函数 | 作用 | 注意 |
|---|---|---|
| `printf("格式串", 变量...)` | 输出 | 占位符与变量类型一一对应 |
| `scanf("格式串", &变量...)` | 输入 | **普通变量前必须加 `&`** |
| `fgets(buf, size, stdin)` | 读一整行（含空格） | 字符串数组不用加 `&` |

占位符：`%d` 整数、`%f` 小数、`%c` 字符、`%s` 字符串、`%p` 地址、`%zu` size_t。

## 三、运算符

- 算术：`+ - * / %`（整数除法丢小数；`%` 取余）
- 复合赋值：`+= -= *= /=`（`n += 3` 等价于 `n = n + 3`）
- 自增自减：`++ --`（`n++` 等价于 `n = n + 1`）
- 比较：`> < >= <= == !=`（结果 0 或 1）
- 逻辑：`&&`（与）、`||`（或）、`!`（非）
- 三元：`条件 ? A : B`（真取 A，假取 B）

⚠️ `==` 判断相等，`=` 赋值，别混。

## 四、流程控制

| 语法 | 用途 | 要点 |
|---|---|---|
| `if / else if / else` | 条件分支 | 范围判断从大到小写 |
| `switch(变量) { case 值: ... break; default: }` | 多分支 | **每个 case 后写 break**，否则穿透 |
| `for (初始化; 条件; 更新)` | 固定次数循环 | 数组遍历 `i < 长度` |
| `while (条件)` | 先判断再循环 | 记得更新循环变量，防死循环 |
| `do { } while (条件);` | 至少执行一次 | 适合输入校验 |
| `break` | 退出整个循环 | 只退出最内层 |
| `continue` | 跳过本次循环 | 进入下一轮 |

随机数：`srand((unsigned)time(NULL));` → `rand() % 范围 + 起始值`

## 五、函数

| 概念 | 说明 |
|---|---|
| 定义 | `返回类型 函数名(参数) { 函数体 }` |
| 形参 | 函数定义里的占位参数 |
| 实参 | 调用时传入的实际值 |
| 返回值 | `return 值;` 无返回用 `void` |
| 声明 | 函数定义在使用之后时，先写 `返回类型 函数名(参数);` |
| 作用域 | 局部变量只在函数内有效；能用局部就不用全局 |
| 递归 | 函数调用自己，**必须有出口**（base case） |

## 六、数组与字符串

| 内容 | 要点 |
|---|---|
| 数组声明 | `int a[5] = {1,2,3,4,5};` |
| 下标 | **从 0 开始**，最后一个下标 = 长度-1 |
| 越界 | C 不检查越界，自己小心（未定义行为） |
| 二维数组 | `int m[3][4];` 先遍历行再遍历列 |
| 字符串 | char 数组 + 末尾 `\0` |
| `strlen(s)` | 长度（不含 `\0`），返回 size_t 用 `%zu` |
| `strcpy(dst, src)` | 复制，dst 要够大 |
| `strcmp(a, b)` | 比较，**相等返回 0** |
| `strcat(dst, src)` | 拼接，dst 要够大 |
| 字符串比较 | 不能用 `==`，用 `strcmp` |

## 七、指针要点（核心中的核心）

| 写法 | 含义 |
|---|---|
| `&x` | 取 x 的地址 |
| `int *p` | 声明 p 为"指向 int 的指针" |
| `*p` | 解引用：p 指向的那个变量 |
| `*&x` | 等于 x |
| `p->x` | 等价于 `(*p).x`，结构体指针访问成员 |
| `p[i]` | 等价于 `*(p+i)` |
| 数组名 | 就是首元素地址 |

动态内存三件套：
1. `int *arr = (int *)malloc(n * sizeof(int));`
2. `if (arr == NULL) return 1;`（必须判空）
3. `free(arr); arr = NULL;`（用完释放并置空）

三大灾难：
- **内存泄漏**：malloc 了不 free → 谁分配谁释放
- **野指针**：指针没指向合法内存 → 初始化 NULL，free 后置 NULL
- **悬垂指针**：指向已释放的内存 → 释放后不再使用

## 八、结构体与枚举

```c
typedef struct {
    char name[32];
    int age;
} Student;          // 结尾分号别忘

Student s = {"小明", 18};
s.age = 19;              // 普通变量用 .
print(&s);               // 传地址

void print(const Student *p) {
    printf("%s", p->name);   // 指针用 ->
}
```

枚举：值就是整数，默认从 0 开始，可指定起始值：

```c
typedef enum { RED, GREEN, BLUE } Color;
typedef enum { MON = 1, TUE, WED } Weekday;
```

## 九、文件操作

四步曲：`fopen`（**判空**）→ `fprintf`/`fscanf` → `fclose` → 检查。

| 模式 | 含义 |
|---|---|
| `"r"` | 只读（文件不存在返回 NULL） |
| `"w"` | 写入（清空原内容，不存在则创建） |
| `"a"` | 追加 |

```c
FILE *fp = fopen("data.txt", "w");
if (fp == NULL) { /* 处理失败 */ }
fprintf(fp, "%d %s\n", 18, "小明");
fclose(fp);
```

读取用 `while (fscanf(fp, "%d %s", &age, name) == 2) { ... }` 安全读完。

## 十、预处理

| 指令 | 作用 |
|---|---|
| `#include <头文件>` | 引入标准库（尖括号）；`"文件"` 引入自己的头文件 |
| `#define 名字 值` | 定义常量，宏名全大写 |
| `#define 宏(x) ((x)*2)` | 带参宏，**参数和整体都要加括号** |
| `#ifdef / #endif` | 条件编译 |

编译流程：预处理 → 编译 → 运行。

## 十二、排错速查

| 症状 | 常见原因 |
|---|---|
| 程序崩溃 | 数组越界、野指针、scanf 忘加 `&` |
| 输出乱码 | 字符串没 `\0`、占位符与类型不匹配 |
| 死循环 | 循环变量没更新、条件恒真 |
| 结果不对 | 整数除法、`==` 写成 `=` |
| 文件读不到 | 路径不对、忘判空 |
