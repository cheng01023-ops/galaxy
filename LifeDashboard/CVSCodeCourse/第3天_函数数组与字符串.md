## 一、函数

```c
int add(int a, int b) {
    return a + b;
}

int main(void) {
    printf("%d\n", add(3, 5));
    return 0;
}
```

- 形参：函数定义里的参数
- 实参：调用时传入的值
- `return` 把结果返回给调用者

## 二、递归

```c
int factorial(int n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}
```

> 递归一定要有"出口"（base case），否则会无限调用。

## 三、数组

```c
int scores[5] = {90, 80, 85, 70, 95};
for (int i = 0; i < 5; i++) {
    printf("%d ", scores[i]);
}
```

数组下标从 0 开始。C 语言**不会**帮你检查越界，要自己小心！

## 四、字符串

C 语言没有 string 类型，字符串其实是"以 \0 结尾的 char 数组"：

```c
#include <string.h>
char name[32] = "C语言";
printf("%s 长度 %zu\n", name, strlen(name));
strcpy(name, "新名字");   // 复制
if (strcmp(name, "C语言") == 0) { /* 相等 */ }
```
