## 一、if 判断：让程序"看情况办事"

### 1.1 最基本的 if

```c
#include <stdio.h>

int main(void) {
    int age = 20;
    if (age >= 18) {
        printf("已成年\n");
    }
    return 0;
}
```

执行流程：先判断括号里的条件 `age >= 18`（结果是 1 真或 0 假），
**为真（1）才执行花括号里的语句**，为假就跳过。

### 1.2 if / else：二选一

```c
int score = 55;
if (score >= 60) {
    printf("及格\n");
} else {
    printf("不及格\n");
}
```

条件为真走 if 分支，为假走 else 分支，**两个分支只会执行一个**。

### 1.3 if / else if / else：多选一

```c
int score = 85;
if (score >= 90) {
    printf("优秀\n");
} else if (score >= 80) {
    printf("良好\n");
} else if (score >= 60) {
    printf("及格\n");
} else {
    printf("不及格\n");
}
```

从上到下依次判断，**一旦某个条件为真，执行完就退出整个 if 链条**，后面的 else if 不再判断。

| 分数 | 输出 |
|---|---|
| 95 | 优秀 |
| 85 | 良好 |
| 65 | 及格 |
| 40 | 不及格 |

> **易错点**：else if 的条件顺序很重要。如果把 `score >= 60` 写在 `score >= 90` 前面，
> 那么 95 分也会先命中"及格"，后面的"优秀"永远到不了。**范围判断要从大到小写**。

### 1.4 大括号可以省略，但强烈建议不省略

```c
if (score >= 60)
    printf("及格\n");   // 只带一条语句时可以不加大括号
```

不加大括号时，if 只管到**第一条语句**。新手经常在这里出 bug，所以本课程一律推荐：
**只要写 if，就加大括号**。

### 1.5 嵌套 if

```c
int year = 2024;
int age = 17;

if (year == 2024) {
    if (age >= 18) {
        printf("2024 年的成年人\n");
    } else {
        printf("2024 年的未成年人\n");
    }
}
```

嵌套时注意**花括号配对**，缩进要对齐（Xcode 会自动缩进），一眼就能看出层级。

## 二、switch：多分支的另一种写法

当判断的是"同一个变量的多个取值"时，switch 比一长串 else if 更清晰：

```c
int day = 3;
switch (day) {
    case 1:
        printf("周一\n");
        break;
    case 2:
        printf("周二\n");
        break;
    case 3:
        printf("周三\n");
        break;
    case 4:
        printf("周四\n");
        break;
    case 5:
        printf("周五\n");
        break;
    default:
        printf("周末\n");
        break;
}
```

| 语法要素 | 说明 |
|---|---|
| `switch(变量)` | 对哪个变量做判断 |
| `case 值:` | 当变量等于这个值时执行后面的语句 |
| `break;` | **跳出整个 switch**（忘写就会"穿透"，见下） |
| `default:` | 所有 case 都不匹配时执行（可省略） |

### 2.1 什么是"穿透"（fall-through）？

如果 case 3 后面忘写 `break`，执行完"周三"后会**继续往下执行** case 4 的内容：

```c
switch (day) {
    case 3:
        printf("周三\n");   // 没有 break
    case 4:
        printf("周四\n");   // ❌ 也被执行了！
        break;
}
```

输入 3 会输出"周三"和"周四"两行。**每个 case 结尾都要写 break**（除非你故意想穿透）。

### 2.2 switch 的注意事项

- case 后面只能是**整数常量或字符常量**，不能是 `case x > 3:` 这种条件
- 多个 case 可以共用一段代码：`case 1: case 2: printf("工作日\n"); break;`
- 遇到"范围判断"（如 0~59、60~89）用 if / else if，switch 不适合

## 三、循环：让程序"重复劳动"

### 3.1 for 循环：知道要循环几次

```c
for (int i = 1; i <= 5; i++) {
    printf("%d ", i);
}
printf("\n");
```

**预期输出：**

```
1 2 3 4 5
```

for 的三个部分（都用分号隔开）：

| 部分 | 作用 | 示例 |
|---|---|---|
| 初始化 | 循环开始前执行一次 | `int i = 1;` |
| 条件 | 每次循环前判断，为真才继续 | `i <= 5;` |
| 更新 | 每轮循环结束后执行 | `i++` |

执行顺序：`初始化 → 判断 → 执行体 → 更新 → 判断 → 执行体 → 更新 → …→ 判断为假退出`

> **想清楚循环次数**：`i` 从 1 到 5 一共 5 次。如果从 0 开始 `i < 5`，也是 5 次（0,1,2,3,4）。
> C 程序员习惯从 0 开始，因为数组下标从 0 开始（第 3 天讲）。

### 3.2 while 循环：先判断再执行

适合"不知道几次，只知道条件"的情况：

```c
int n = 1, sum = 0;
while (n <= 100) {
    sum += n;
    n++;
}
printf("1+2+...+100 = %d\n", sum);
```

**预期输出：**

```
1+2+...+100 = 5050
```

`while (条件) { 语句 }`：**先判断**，条件为真才执行体，执行完再回去判断。
如果一开始条件就是假，循环体一次都不会执行。

> ⚠️ **死循环警告**：如果忘了写 `n++`，n 永远等于 1，条件永远为真，程序会一直运行。
> 在 Xcode 里按 **Ctrl + C** 或点击停止按钮可以终止死循环。

### 3.3 do-while 循环：先执行一次再判断

```c
int x;
do {
    printf("请输入一个正数：");
    scanf("%d", &x);
} while (x <= 0);
printf("你输入了 %d\n", x);
```

**do-while 至少执行一次循环体**，适合"必须先做一次，再根据结果决定要不要继续"的场景。
上面的代码保证用户至少被问一次，直到输入正数为止——这是"输入校验"的经典写法。

### 3.4 三种循环怎么选？

| 循环 | 特点 | 适合场景 |
|---|---|---|
| `for` | 次数明确 | 遍历数组、数 1 到 100 |
| `while` | 次数不明确，先判断 | "当还有数据就继续处理" |
| `do-while` | 至少执行一次 | 必须先问一次用户输入 |

## 四、break 与 continue

```c
for (int i = 1; i <= 10; i++) {
    if (i == 5) break;       // 遇到 5 立刻结束整个循环
    printf("%d ", i);
}
// 输出：1 2 3 4

for (int i = 1; i <= 5; i++) {
    if (i == 3) continue;    // 跳过 3，继续下一次
    printf("%d ", i);
}
// 输出：1 2 4 5
```

| 关键字 | 作用 | 类比 |
|---|---|---|
| `break` | **退出整个循环**（循环到此为止） | 按下紧急停止 |
| `continue` | **跳过本次循环剩余部分**，进入下一轮 | 这轮跳过，下一轮照常 |

> 注意：`break` 只跳出**最内层**的那个循环。嵌套循环时，break 不会跳出外层循环。

## 五、综合实战：猜数字小游戏

把第 1 天的知识 + 今天的循环判断全部用上：

```c
#include <stdio.h>
#include <stdlib.h>   // 用 rand 需要
#include <time.h>     // 用 time 需要

int main(void) {
    // 1. 生成 1~100 的随机数
    srand((unsigned)time(NULL));        // 用当前时间做"随机种子"
    int secret = rand() % 100 + 1;      // rand() 范围 0~32767，%100 得 0~99，+1 得 1~100

    int guess, tries = 0;
    printf("我已经想好一个 1~100 的数字，来猜吧！\n");

    // 2. 循环猜，直到猜中
    do {
        printf("请输入你的猜测：");
        scanf("%d", &guess);
        tries++;

        if (guess > secret) {
            printf("太大了！\n");
        } else if (guess < secret) {
            printf("太小了！\n");
        } else {
            printf("恭喜你，猜对了！答案是 %d，你用了 %d 次。\n", secret, tries);
        }
    } while (guess != secret);

    return 0;
}
```

**运行示例：**

```
我已经想好一个 1~100 的数字，来猜吧！
请输入你的猜测：50
太大了！
请输入你的猜测：25
太小了！
请输入你的猜测：37
太小了！
请输入你的猜测：43
恭喜你，猜对了！答案是 43，你用了 4 次。
```

### 5.1 随机数原理（理解即可）

- `srand(种子)`：给随机数生成器一个起点，种子相同则产生的随机序列相同
- `time(NULL)` 返回当前秒数，每秒都不同，所以每次运行种子都不同
- `rand() % 100`：把随机数限制到 0~99（取余数的范围），`+1` 变成 1~100

> 如果去掉 `srand`，每次运行程序产生的"随机数"会一模一样，这是新手常见困惑。

### 5.2 给游戏加难度（进阶挑战）

- 限制最多猜 7 次，超过就提示"次数用完了，答案是 X"
- 记录并显示历史猜测
- 猜中后问"再来一局？"（提示：用另一个 do-while 包住整个游戏）

### 练习 2：九九乘法表
用**双重 for 循环**输出 9×9 乘法表。

<details>
<summary>练习 2 参考思路</summary>

```c
#include <stdio.h>

int main(void) {
    for (int i = 1; i <= 9; i++) {       // 外层：行
        for (int j = 1; j <= i; j++) {   // 内层：列，只到 i
            printf("%d*%d=%-3d ", j, i, i * j);  // %-3d 左对齐占 3 位
        }
        printf("\n");                    // 每行结束换行
    }
    return 0;
}
```

**关键点**：内层循环 `j <= i` 控制列数，保证每行只输出到对角线。
`%-3d` 表示左对齐、占 3 个字符宽度，让表格对齐好看。
</details>

### 练习 3：统计数字
输入一个正整数 n，统计它**有多少位**、**各位数字之和**。
例如 n=1234 → 4 位，各位和 = 10。（提示：反复 `n % 10` 取个位，再 `n / 10` 去掉个位）

<details>
<summary>练习 3 参考思路</summary>

```c
#include <stdio.h>

int main(void) {
    int n;
    printf("请输入一个正整数：");
    scanf("%d", &n);

    int digits = 0, sum = 0;
    int m = n;              // 用副本 m，不破坏原值
    while (m > 0) {
        sum += m % 10;      // 取出个位
        m /= 10;            // 去掉个位
        digits++;
    }
    printf("%d 有 %d 位，各位数字之和 = %d\n", n, digits, sum);
    return 0;
}
```

**原理**：`m % 10` 得到个位，`m / 10` 把个位丢掉。反复执行直到 m 变成 0。
例如 1234：先取 4、再取 3、再取 2、再取 1，一共 4 位。
</details>

### 练习 4：最大公约数（挑战）
输入两个正整数，用"辗转相除法"求最大公约数。
原理：`gcd(a, b)`，反复让 `a, b = b, a % b`，直到余数为 0，此时的 b 就是答案。

<details>
<summary>练习 4 参考思路</summary>

```c
#include <stdio.h>

int main(void) {
    int a, b;
    printf("请输入两个正整数：");
    scanf("%d %d", &a, &b);

    int x = a, y = b;
    while (y != 0) {
        int r = x % y;   // 余数
        x = y;           // 下一轮的被除数 = 上一轮的除数
        y = r;           // 下一轮的除数 = 上一轮的余数
    }
    printf("gcd(%d, %d) = %d\n", a, b, x);
    return 0;
}
```

例如 gcd(48, 18)：48%18=12 → gcd(18,12)；18%12=6 → gcd(12,6)；12%6=0 → 答案 6。
这是古希腊数学家欧几里得的算法，也是"算法"最早的经典例子之一。
</details>

## 七、今天的小结

- 判断：`if / else if / else` 多选一，范围判断**从大到小写**；`switch` 适合单变量多取值，**别忘 break**
- 循环：`for`（次数明确）、`while`（先判断）、`do-while`（至少一次）
- `break` 退出整个循环，`continue` 跳过本次
- 随机数：`srand(time(NULL))` + `rand() % 范围 + 起点`
- 死循环 = 条件永远为真，记得让循环变量朝退出方向变化
