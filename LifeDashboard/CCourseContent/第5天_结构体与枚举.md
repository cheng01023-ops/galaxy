## 一、结构体

```c
struct Student {
    char name[32];
    int age;
    double score;
};

struct Student s1;
strcpy(s1.name, "小明");
s1.age = 18;
s1.score = 92.5;
```

## 二、typedef 简化

```c
typedef struct {
    char name[32];
    int age;
} Student;

Student s2;
```

## 三、结构体数组

```c
Student classRoom[30];
for (int i = 0; i < 30; i++) {
    classRoom[i].age = 18;
}
```

## 四、结构体指针

```c
void printStudent(const Student *s) {
    printf("%s %d\n", s->name, s->age);
}
```

> `->` 等价于 `(*s).`，专门用于结构体指针访问成员。

## 五、枚举

```c
typedef enum { RED, GREEN, BLUE } Color;
Color c = RED;
```
