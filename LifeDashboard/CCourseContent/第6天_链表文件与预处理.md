## 一、为什么需要链表？

数组有两个痛点：

1. **大小固定**：声明 `int a[100]` 就只能装 100 个，多了越界，少了浪费
2. **插入/删除麻烦**：在中间插入一个数，后面所有元素都要挪位置

链表用**指针把分散的内存节点串起来**，想加就加、想删就删，完美解决这两个问题。
代价是：不能像数组那样用下标直接访问第 n 个元素，必须从头一个个找。

**数组 vs 链表：**

| 特性 | 数组 | 链表 |
|---|---|---|
| 内存 | 连续的一块 | 分散的节点，用指针连接 |
| 大小 | 固定 | 动态增长 |
| 按下标访问 | O(1) 很快 | 要遍历，O(n) |
| 插入/删除 | 要搬移元素 | 改指针即可 |
| 适合场景 | 大小固定、频繁随机访问 | 频繁增删、大小不确定 |

## 二、链表的基本结构

### 2.1 节点（Node）

链表由一个个**节点**组成，每个节点有两部分：

```c
typedef struct Node {
    int data;            // 数据域：存数据
    struct Node *next;   // 指针域：指向下一个节点
} Node;
```

内存图：

```
┌─────────┐    ┌─────────┐    ┌─────────┐
│ data: 1 │    │ data: 2 │    │ data: 3 │
│ next: ●─┼──→ │ next: ●─┼──→ │ next: ●─┼──→ NULL
└─────────┘    └─────────┘    └─────────┘
   head                                           尾节点的 next 是 NULL
```

- `head`：指向第一个节点的指针（没有节点时为 NULL）
- 每个节点通过 `next` 指向下一个节点
- **最后一个节点的 `next` 必须是 NULL**，这是遍历的终点标志

> ⚠️ 注意 `struct Node *next` 里的 `struct` 不能省——在 typedef 完成之前，
> 编译器还不知道 `Node` 这个名字，必须用完整的 `struct Node`。

### 2.2 创建节点

```c
Node *createNode(int v) {
    Node *n = (Node *)malloc(sizeof(Node));  // 在堆上申请一个节点
    if (n == NULL) return NULL;
    n->data = v;
    n->next = NULL;      // 新节点默认没有后继
    return n;
}
```

> 链表的每个节点都要 `malloc` 出来，因为节点数量运行时才确定。
> **用完整个链表后，要逐个 `free` 所有节点，否则每个节点都泄漏。**

## 三、链表的四种基本操作

### 3.1 头插法（插到最前面）

```c
void insertHead(Node **head, int v) {
    Node *n = createNode(v);
    n->next = *head;     // 新节点指向原来的头
    *head = n;           // 头指针更新为新节点
}
```

> 为什么参数是 `Node **head`（指针的指针）？
> 因为要**修改 head 本身**（让头指向新节点）。只传 `Node *head` 修改的是副本，
> 外面看不见——这正是第 4 天学的"想改外面的变量就传地址"。

### 3.2 尾插法（插到最后面）

```c
void insertTail(Node **head, int v) {
    Node *n = createNode(v);
    if (*head == NULL) {       // 链表为空，新节点就是头
        *head = n;
        return;
    }
    Node *p = *head;
    while (p->next != NULL) {  // 走到最后一个节点
        p = p->next;
    }
    p->next = n;               // 挂在末尾
}
```

### 3.3 遍历打印

```c
void printList(Node *head) {
    Node *p = head;
    while (p != NULL) {
        printf("%d -> ", p->data);
        p = p->next;           // 前进到下一个节点
    }
    printf("NULL\n");
}
```

**输出示例：**

```
1 -> 2 -> 3 -> NULL
```

### 3.4 删除指定值的节点

```c
void deleteNode(Node **head, int v) {
    Node *p = *head, *prev = NULL;

    while (p != NULL && p->data != v) {   // 找到值为 v 的节点
        prev = p;
        p = p->next;
    }
    if (p == NULL) return;                // 没找到

    if (prev == NULL) {                   // 删除的是头节点
        *head = p->next;
    } else {
        prev->next = p->next;             // 跳过 p，让前一个直接指向后一个
    }
    free(p);                              // 释放被删节点的内存
}
```

删除中间节点示意图：

```
删除前：  A → B → C       删除 B
删除后：  A ────→ C
做法：    A.next = B.next（B 被跳过），再 free(B)
```

### 3.5 释放整个链表

```c
void freeList(Node *head) {
    Node *p = head;
    while (p != NULL) {
        Node *next = p->next;   // 先记下下一个节点
        free(p);                // 释放当前节点
        p = next;               // 继续
    }
}
```

> 一定要先保存 `p->next` 再 free(p)，否则 free 之后 next 就访问不了了（悬垂指针）。

### 3.6 完整示例：增删查遍历

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct Node {
    int data;
    struct Node *next;
} Node;

Node *createNode(int v) {
    Node *n = (Node *)malloc(sizeof(Node));
    if (n == NULL) return NULL;
    n->data = v;
    n->next = NULL;
    return n;
}

void insertTail(Node **head, int v) {
    Node *n = createNode(v);
    if (*head == NULL) { *head = n; return; }
    Node *p = *head;
    while (p->next) p = p->next;
    p->next = n;
}

void printList(Node *head) {
    for (Node *p = head; p; p = p->next) {
        printf("%d -> ", p->data);
    }
    printf("NULL\n");
}

int search(Node *head, int v) {
    for (Node *p = head; p; p = p->next) {
        if (p->data == v) return 1;   // 找到
    }
    return 0;                          // 没找到
}

// 释放整个链表（必须先保存 next 再 free，避免悬垂指针）
void freeList(Node *head) {
    Node *p = head;
    while (p != NULL) {
        Node *next = p->next;
        free(p);
        p = next;
    }
}

int main(void) {
    Node *head = NULL;
    insertTail(&head, 10);
    insertTail(&head, 20);
    insertTail(&head, 30);
    printList(head);                   // 10 -> 20 -> 30 -> NULL

    printf("找 20：%s\n", search(head, 20) ? "找到了" : "没找到");
    printf("找 99：%s\n", search(head, 99) ? "找到了" : "没找到");

    freeList(head);                    // 记得释放
    return 0;
}
```

## 四、文件读写：让程序"记住数据"

### 4.1 文件操作四步曲

| 步骤 | 函数 | 说明 |
|---|---|---|
| 1. 打开 | `fopen("路径", "模式")` | 返回 FILE*，失败返回 NULL |
| 2. 读写 | `fprintf` / `fscanf` | 和 printf/scanf 用法几乎一样 |
| 3. 关闭 | `fclose(fp)` | 释放文件句柄 |
| 4. 检查 | 打开后判断 NULL | 防止文件不存在导致崩溃 |

### 4.2 打开模式

| 模式 | 含义 | 文件不存在时 |
|---|---|---|
| `"r"` | 只读 | 返回 NULL（读不了） |
| `"w"` | 写入（清空原内容） | 创建新文件 |
| `"a"` | 追加（保留原内容） | 创建新文件 |
| `"r+"` | 读写 | 返回 NULL |
| `"w+"` | 读写（清空） | 创建新文件 |

### 4.3 写入文件

```c
#include <stdio.h>

int main(void) {
    FILE *fp = fopen("data.txt", "w");
    if (fp == NULL) {                 // ⚠️ 必须检查
        printf("无法打开文件！\n");
        return 1;
    }

    fprintf(fp, "%d %s\n", 18, "小明");   // 和 printf 一样，只是多一个文件参数
    fprintf(fp, "%d %s\n", 17, "小红");

    fclose(fp);
    printf("写入完成\n");
    return 0;
}
```

**data.txt 内容：**

```
18 小明
17 小红
```

### 4.4 读取文件

```c
#include <stdio.h>

int main(void) {
    FILE *fp = fopen("data.txt", "r");
    if (fp == NULL) {
        printf("文件不存在或无法打开！\n");
        return 1;
    }

    int age;
    char name[32];
    while (fscanf(fp, "%d %s", &age, name) == 2) {
        printf("%s %d 岁\n", name, age);
    }

    fclose(fp);
    return 0;
}
```

**预期输出：**

```
小明 18 岁
小红 17 岁
```

> `fscanf` 返回成功读到的项数，读不到（到文件末尾）会返回 EOF。
> 用 `while (fscanf(...) == 2)` 作为循环条件，能安全地读完整个文件。
> `fscanf` 读字符串遇到空格会停，用 `fgets` 能读整行（含空格）。

### 4.5 文件读写常见错误

| 错误 | 现象 | 避免 |
|---|---|---|
| 忘记判空 | 文件不存在直接崩溃 | 打开后立即 `if (fp == NULL)` |
| 忘记 fclose | 文件内容没写进去/句柄泄漏 | 用完就关 |
| 用 `"r"` 读不存在的文件 | 返回 NULL | 判空并提示 |
| 路径写错 | 打开失败 | 用相对路径或确认目录 |

> 程序运行时的工作目录通常是项目目录。在 Xcode 里，可以用
> Product → Scheme → Edit Scheme → Options → Working Directory 设置工作目录，
> 或者在代码里写绝对路径（如 `/Users/你的名字/data.txt`）先跑通。

## 五、预处理：编译前的"文字处理"

### 5.1 预处理是什么？

编译过程的第一阶段是**预处理**：在真正翻译成机器码之前，先把代码里的
`#include`、`#define`、`#ifdef` 等指令处理掉。

```
源代码 → [预处理] → 展开后的代码 → [编译] → 机器码 → [运行]
```

所有以 `#` 开头的都是**预处理指令**，它们在编译前执行。

### 5.2 #include：把别的文件内容"粘进来"

```c
#include <stdio.h>     // 尖括号：到系统目录找（标准库）
#include "myheader.h"  // 双引号：先到当前目录找（自己的头文件）
```

`#include <stdio.h>` 的效果 = 把 stdio.h 的内容原封不动粘贴到这一行。

### 5.3 #define：定义常量

```c
#include <stdio.h>

#define PI 3.14159
#define MAX_STUDENTS 100

int main(void) {
    double r = 2.0;
    double area = PI * r * r;             // 编译前 PI 会被替换成 3.14159
    printf("%.4f\n", area);
    return 0;
}
```

> `#define` 是**纯文本替换**，不是变量！它不占内存、没有类型。
> 习惯上宏名**全大写**，和变量区分开。

### 5.4 带参数的宏（小心括号！）

```c
#include <stdio.h>

#define SQUARE(x) ((x) * (x))
#define MAX(a, b) ((a) > (b) ? (a) : (b))

int main(void) {
    printf("%d\n", SQUARE(5));      // 25
    printf("%d\n", SQUARE(2 + 3));  // 25，因为展开成 ((2+3)*(2+3))
    printf("%d\n", MAX(3, 8));      // 8
    return 0;
}
```

> ⚠️ **参数和整个表达式都要加括号**。如果不加：
> `#define SQUARE(x) x * x` 遇到 `SQUARE(2+3)` 会展开成 `2+3*2+3 = 11`（错的！）。
> 这是宏最经典的坑，写宏时把每个参数和整体都用括号包起来。

### 5.5 条件编译（了解）

```c
#define DEBUG

#ifdef DEBUG
    printf("调试信息：当前是调试模式\n");
#endif
```

`#ifdef` 块只在宏被定义时编译，常用于调试开关、平台差异处理。

### 5.6 函数 vs 宏

| | 函数 | 带参宏 |
|---|---|---|
| 执行时机 | 运行时调用 | 编译前替换 |
| 类型检查 | 有 | 没有 |
| 速度 | 有调用开销 | 无开销（内联展开） |
| 复杂逻辑 | 适合 | 不适合（只能简单替换） |

> 现代 C 风格：常量多用 `enum` 或 `const`，简单运算才用宏，复杂逻辑用函数。

## 六、综合实战：通讯录（链表 + 文件）

把今天的链表和文件结合起来，做一个能增删查、能保存到文件的通讯录：

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

typedef struct Contact {
    char name[32];
    char phone[20];
    struct Contact *next;
} Contact;

Contact *createContact(const char *name, const char *phone) {
    Contact *c = (Contact *)malloc(sizeof(Contact));
    if (c == NULL) return NULL;
    strcpy(c->name, name);
    strcpy(c->phone, phone);
    c->next = NULL;
    return c;
}

void addContact(Contact **head, const char *name, const char *phone) {
    Contact *c = createContact(name, phone);
    c->next = *head;          // 头插法
    *head = c;
}

void printAll(const Contact *head) {
    if (head == NULL) { printf("（通讯录是空的）\n"); return; }
    int i = 1;
    for (const Contact *p = head; p; p = p->next) {
        printf("%d. %s  %s\n", i++, p->name, p->phone);
    }
}

int main(void) {
    Contact *head = NULL;

    // 从文件加载
    FILE *fp = fopen("contacts.txt", "r");
    if (fp) {
        char name[32], phone[20];
        while (fscanf(fp, "%s %s", name, phone) == 2) {
            addContact(&head, name, phone);
        }
        fclose(fp);
        printf("已从文件加载通讯录\n");
    }

    while (1) {
        printf("\n1 添加  2 查看  3 保存  0 退出：");
        int choice;
        scanf("%d", &choice);

        if (choice == 1) {
            char name[32], phone[20];
            printf("姓名 电话：");
            scanf("%s %s", name, phone);
            addContact(&head, name, phone);
        } else if (choice == 2) {
            printAll(head);
        } else if (choice == 3) {
            fp = fopen("contacts.txt", "w");
            if (fp) {
                for (const Contact *p = head; p; p = p->next) {
                    fprintf(fp, "%s %s\n", p->name, p->phone);
                }
                fclose(fp);
                printf("已保存\n");
            }
        } else if (choice == 0) {
            break;
        }
    }

    // 退出前释放链表
    Contact *p = head;
    while (p) {
        Contact *next = p->next;
        free(p);
        p = next;
    }
    return 0;
}
```

**运行示例：**

```
已从文件加载通讯录

1 添加  2 查看  3 保存  0 退出：1
姓名 电话：张三 13800000001
1 添加  2 查看  3 保存  0 退出：2
1. 张三  13800000001
1 添加  2 查看  3 保存  0 退出：3
已保存
1 添加  2 查看  3 保存  0 退出：0
```

> 下次运行程序，通讯录会从 contacts.txt 自动恢复——这就是"持久化"。

### 练习 4：链表删除（挑战）
实现 `deleteNode`（删除第一个值为 v 的节点），并测试删除头节点和中间节点两种情况。

<details>
<summary>练习 4 参考思路</summary>

```c
#include <stdio.h>
#include <stdlib.h>

typedef struct Node { int data; struct Node *next; } Node;

void insertTail(Node **head, int v) {
    Node *n = (Node *)malloc(sizeof(Node));
    n->data = v; n->next = NULL;
    if (*head == NULL) { *head = n; return; }
    Node *p = *head;
    while (p->next) p = p->next;
    p->next = n;
}

void deleteNode(Node **head, int v) {
    Node *p = *head, *prev = NULL;
    while (p && p->data != v) { prev = p; p = p->next; }
    if (!p) return;
    if (!prev) *head = p->next;   // 删头节点
    else prev->next = p->next;    // 删中间/末尾
    free(p);
}

void printList(Node *head) {
    for (Node *p = head; p; p = p->next) printf("%d -> ", p->data);
    printf("NULL\n");
}

int main(void) {
    Node *head = NULL;
    insertTail(&head, 1);
    insertTail(&head, 2);
    insertTail(&head, 3);
    printList(head);

    deleteNode(&head, 2);   // 删中间
    printList(head);        // 1 -> 3 -> NULL

    deleteNode(&head, 1);   // 删头
    printList(head);        // 3 -> NULL
    return 0;
}
```
</details>

## 八、今天的小结

- 链表节点 = 数据域 + 指针域；尾节点 next 必须是 NULL
- 头插 O(1) 快；尾插要遍历到末尾
- 修改 head 要用 `Node **`（指针的指针）
- 文件操作：fopen（判空）→ fprintf/fscanf → fclose
- 预处理在编译前：`#include` 粘文件、`#define` 做文本替换，**宏参数记得加括号**
- 链表所有 malloc 的节点都要 free
