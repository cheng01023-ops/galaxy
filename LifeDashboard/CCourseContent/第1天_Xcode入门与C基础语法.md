## 一、在 Xcode 里创建第一个 C 项目（跟着做）

### 1.1 新建项目

1. 打开 Xcode，点击 **Create a New Project**（或菜单 File → New → Project）。
2. 在模板选择页，顶部选 **macOS** 标签页。
3. 选择 **Command Line Tool**（命令行工具），点 Next。
4. Product Name 填 `HelloC`，**Language 一定要选 C**（不要选 Swift），点 Next。
5. 选择保存位置，点 Create。

> 完成后 Xcode 会自动生成一个 `main.c` 文件。Command Line Tool 是"纯文字输出"的程序，
> 最适合用来学 C——没有界面、只有黑框输出，专注语法本身。

### 1.2 认识 Xcode 界面

| 区域 | 作用 |
|---|---|
| 左侧导航栏 | 显示项目文件（如 main.c） |
| 中间编辑区 | 写代码的地方 |
| 顶部工具栏 | ▶ 运行按钮（Cmd + R） |
| 底部调试区 | 显示程序的输出结果 |

### 1.3 运行你的第一个程序

把 `main.c` 改成下面的内容，然后按 **Cmd + R**：

```c
#include <stdio.h>

int main(void) {
    printf("Hello, C!\n");
    return 0;
}
```

**预期输出：**

```
Hello, C!
```

如果一切正常，恭喜你！你已经成功运行了人生中第一个 C 程序。

## 二、逐行拆解 Hello World

```c
#include <stdio.h>          // ① 引入标准输入输出库
                            //    （printf/scanf 都住在这个库里）
int main(void) {            // ② 程序入口：main 函数
    printf("Hello, C!\n");  // ③ 一条"语句"：输出文字
    return 0;               // ④ 返回 0：告诉系统"正常结束"
}                           // ⑤ 右花括号：main 结束
```

| 代码 | 含义 | 类比 |
|---|---|---|
| `#include <stdio.h>` | 把"标准输入输出"工具包拿进来 | 借来一本《打印手册》 |
| `int main(void)` | 程序从这里开始执行 | 舞台剧的开幕 |
| `{ ... }` | 一对花括号包住一组语句 | 一个"段落"的范围 |
| `printf("...")` | 把文字打印到屏幕 | 对着话筒念台词 |
| `\n` | 换行符，光标跳到下一行 | 按了一下回车键 |
| `;` | 一句话结束的句号 | 句号 |
| `return 0;` | 程序正常结束并返回状态 0 | 谢幕，0 = 一切顺利 |

> **`\n` 是重点**：它不是一个普通字符 n，而是"换行"。试试把 `\n` 删掉再运行，
> 观察输出会变成什么样——这就是"改代码看变化"的学习法。

### 2.1 常见错误与报错怎么看

编译器报错一般长这样：`main.c:5:9: error: expected ';' after expression`

拆开看：`main.c`（哪个文件）`5`（第几行）`9`（第几个字符）`error:`（错误类型）
`expected ';' ...`（期望一个分号，但没找到）。

> 看到报错先做三步：① 看是哪个文件第几行；② 把光标移到那行；③ 对照上面的"语句要以 ; 结尾"。
> 90% 的初学者错误是：忘写分号、括号不配对、引号用了中文引号""。

## 三、变量与基本类型

### 3.1 什么是变量？

变量就是"给内存里的一个盒子起名字"。你可以往盒子里放数字、字符，也可以拿出来用。

```c
int age = 18;          // 声明一个 int 类型变量 age，并放进 18
```

拆开看：`int`（类型：装整数）→ `age`（名字）→ `=`（赋值：把右边的值放进盒子）→ `18`（值）→ `;`（结束）。

### 3.2 五种基本类型（背下来）

| 类型 | 中文 | 能装什么 | 示例 | printf 占位符 | 大致范围 |
|---|---|---|---|---|---|
| `int` | 整型 | 整数 | `int a = 42;` | `%d` | 约 ±21 亿 |
| `double` | 双精度浮点 | 小数（精度高） | `double p = 3.14;` | `%f` | 约 15 位有效数字 |
| `float` | 单精度浮点 | 小数（精度低） | `float f = 1.5f;` | `%f` | 约 7 位有效数字 |
| `char` | 字符 | 单个字符 | `char c = 'A';` | `%c` | 1 个字节 |
| `_Bool` | 布尔 | 真(1)/假(0) | `_Bool ok = 1;` | `%d` | 0 或 1 |

几个容易踩的坑：

- 字符用**单引号**：`'A'`；字符串用**双引号**：`"ABC"`。写反会报错。
- `double` 和 `float` 都用 `%f` 输出（`double` 更常用，精度更高）。
- 想控制小数位数：`%.2f` 表示保留 2 位小数，例如 `printf("%.2f\n", 3.14159);` 输出 `3.14`。

### 3.3 变量命名规则

- 只能由字母、数字、下划线组成，且**不能以数字开头**：`age` ✅、`age1` ✅、`1age` ❌
- 不能是 C 关键字：`int`、`if`、`while` 等不能当名字
- 习惯上用小写字母 + 下划线：`my_age`、`total_score`
- 名字要"见名知义"：`score` 比 `s` 好，`total_price` 比 `tp` 好

```c
int main(void) {
    int age = 18;              // 好：一看就知道是年龄
    int a = 18;                // 一般：只有自己能懂
    int 2age = 18;             // ❌ 编译报错：不能以数字开头
    int class = 1;             // ❌ 编译报错：class 是 C 的关键字
    return 0;
}
```

## 四、输入与输出（printf / scanf）

### 4.1 printf：输出

`printf("格式串", 变量1, 变量2, ...)` —— 格式串里的占位符会被后面的变量依次替换。

```c
#include <stdio.h>

int main(void) {
    int age = 18;
    double score = 92.5;
    printf("我 %d 岁，成绩 %.1f 分\n", age, score);
    return 0;
}
```

**预期输出：**

```
我 18 岁，成绩 92.5 分
```

| 占位符 | 对应类型 | 示例 |
|---|---|---|
| `%d` | int | `printf("%d", 42);` → `42` |
| `%f` | double / float | `printf("%.1f", 3.14);` → `3.1` |
| `%c` | char | `printf("%c", 'A');` → `A` |
| `%s` | 字符串 | `printf("%s", "hi");` → `hi` |

### 4.2 scanf：输入（最容易出错！）

`scanf` 从键盘读取输入，**格式串里的占位符要跟变量的类型一一对应**，
而且**普通变量前必须加 `&`**（取地址符，第 4 天会细讲）。

```c
#include <stdio.h>

int main(void) {
    int n;
    printf("请输入一个整数：");
    scanf("%d", &n);
    printf("你输入的是 %d，它的两倍是 %d\n", n, n * 2);
    return 0;
}
```

**运行过程：**

```
请输入一个整数：5
你输入的是 5，它的两倍是 10
```

> ⚠️ **scanf 的三个高频错误：**
> 1. 忘记加 `&`：`scanf("%d", n);` → 崩溃或乱码（必须 `&n`）
> 2. 占位符和类型不匹配：用 `%d` 读 double 变量
> 3. 格式串里加多余字符：`scanf("%d,", &n);` 会让程序等着你输入逗号
>
> 字符串（char 数组）变量**不用加 `&`**，这个到第 3 天再讲。

## 五、运算符

### 5.1 算术运算符

| 运算符 | 含义 | 示例 | 结果 |
|---|---|---|---|
| `+` | 加 | `7 + 3` | `10` |
| `-` | 减 | `7 - 3` | `4` |
| `*` | 乘 | `7 * 3` | `21` |
| `/` | 除 | `7 / 2` | `3`（⚠️ 整数除法！） |
| `%` | 取余 | `7 % 2` | `1` |

**整数除法是新手第一大坑**：两个整数相除，结果只保留整数部分。
`7 / 2 == 3`、`5 / 2 == 2`，小数部分直接丢掉（不是四舍五入）。

想要小数结果，至少让一边变成小数：

```c
double r1 = 7 / 2;      // r1 = 3.0  ❌ 还是整数除法，先算 7/2=3
double r2 = 7.0 / 2;    // r2 = 3.5  ✅ 有一边是小数，就是小数除法
```

`%` 取余超有用：判断奇偶（`n % 2` 是 0 就是偶数）、取数字的各位、循环换行。

### 5.2 比较运算符

| 运算符 | 含义 | 示例 | 结果 |
|---|---|---|---|
| `>` | 大于 | `5 > 3` | `1`（真） |
| `<` | 小于 | `5 < 3` | `0`（假） |
| `>=` | 大于等于 | `5 >= 5` | `1` |
| `<=` | 小于等于 | `5 <= 3` | `0` |
| `==` | 等于（判断相等） | `5 == 5` | `1` |
| `!=` | 不等于 | `5 != 5` | `0` |

> ⚠️ **`==` 和 `=` 别搞混**：`==` 是"判断相等"，`=` 是"赋值"。
> 写 `if (x = 5)` 不会报错但逻辑全错，这是 C 程序员最经典的低级错误。

### 5.3 逻辑运算符

逻辑运算的结果同样是 **0（假）或 1（真）**：

- `&&` 并且（and）：`(3>1) && (2>1)` 的结果是 `1`
- `||` 或者（or）：`(3>5) || (2>1)` 的结果是 `1`
- `!` 取反（not）：`!(3>5)` 的结果是 `1`

比较和逻辑的结果都是 **0（假）或 1（真）**，可以直接用来赋值：

```c
int isAdult = (age >= 18);        // 成年为 1，未成年为 0
int inRange = (x > 0 && x < 100); // 在 0~100 之间为 1
```

### 5.4 复合赋值与自增

```c
int n = 5;
n += 3;    // n = 8，等价于 n = n + 3
n -= 2;    // n = 6
n *= 4;    // n = 24
n /= 3;    // n = 8
n++;       // n = 9，等价于 n = n + 1
n--;       // n = 8
```

`n++` 是 `n = n + 1` 的简写，第 2 天写循环时会大量用到。

### 练习 2：两个整数
输入两个整数，输出它们的和、差、积、商和余数。

<details>
<summary>练习 2 参考思路</summary>

int main(void) {

### 练习 3：华氏温度换算
输入华氏温度 f，输出摄氏温度：`c = (f - 32) * 5 / 9`。
（提示：想得到小数结果，注意把 5 或 9 写成 5.0 或 9.0）

<details>
<summary>练习 3 参考思路</summary>

```c
#include <stdio.h>

int main(void) {
    double f, c;
    printf("请输入华氏温度：");
    scanf("%lf", &f);          // 注意：double 用 %lf 读入
    c = (f - 32) * 5.0 / 9.0;  // 用 5.0/9.0 保证小数除法
    printf("摄氏温度 = %.2f\n", c);
    return 0;
}
```

**易错点**：`(f - 32) * 5 / 9` 因为 f 是 double，5/9 会先算成 0……不对，这里其实
先算 `(f-32)*5` 是 double，再除以 int 9，结果还是 double，所以可以。但写成 `5.0 / 9.0`
更保险，别人一看就懂。
</details>

### 练习 4：判断奇偶（综合运用）
输入一个整数，用 `%` 判断它是奇数还是偶数。

<details>
<summary>练习 4 参考思路</summary>

```c
#include <stdio.h>

int main(void) {
    int n;
    printf("请输入一个整数：");
    scanf("%d", &n);
    printf("%d 是%s\n", n, (n % 2 == 0) ? "偶数" : "奇数");
    return 0;
}
```

这里用到了三元运算符 `条件 ? 结果1 : 结果2`。你也可以用 if/else 写，
那是第 2 天的内容，提前试一下也行。
</details>

## 七、今天的小结

- 输出用 `printf`，输入用 `scanf`（**变量前加 `&`**）
- 整数除法会丢小数；`==` 是判断相等、`=` 是赋值
- 报错先看"哪个文件第几行"，再对照语法修改
