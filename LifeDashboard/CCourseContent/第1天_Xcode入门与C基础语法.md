## 一、第一个 C 程序

```c
#include <stdio.h>

int main(void) {
    printf("Hello, C!\n");
    return 0;
}
```

- `#include <stdio.h>`：引入标准输入输出库
- `int main(void)`：程序入口
- `printf`：输出文字
- `return 0`：告诉系统"正常结束"

## 二、变量与类型

```c
int age = 18;          // 整数
double price = 3.14;   // 小数（双精度）
char grade = 'A';      // 单个字符
_Bool ok = 1;          // 布尔（1 真 0 假）
```

## 三、输入输出

```c
int n;
printf("请输入一个数：");
scanf("%d", &n);
printf("你输入的是 %d\n", n);
```

> `%d` 整数、`%f` 小数、`%c` 字符、`%s` 字符串。scanf 里变量前要加 `&`。

## 四、运算符

| 种类 | 例子 | 说明 |
|---|---|---|
| 算术 | `+ - * / %` | `%` 是取余 |
| 比较 | `> < >= <= == !=` | 结果是 0 或 1 |
| 逻辑 | `&& \|\| !` | 与、或、非 |
