## 一、编程到底是在做什么？

### 1.1 打个比方：编程 = 给电脑写"说明书"

电脑只会一步一步执行指令，而且必须说得**非常具体、非常清楚**。

比如让电脑"把 1 加到 100"，你要告诉它：
1. 准备一个盒子，先放 0
2. 拿 1 放进盒子
3. 拿 2 加进去
4. ……一直加到 100

**编程就是写这样一份"说明书"**，用的是电脑听得懂的语言（比如 C）。

### 1.2 为什么学 C？

C 语言是最经典的"系统语言"：
- 离电脑底层很近，能直接理解**内存、地址、指针**
- 操作系统、嵌入式、Linux 内核都用 C
- 学会 C，再学 C++、Java、Swift 会非常轻松

### 1.3 "编译"和"运行"是什么？

```
你写的 C 代码（人看的）
    ↓ 编译（翻译成机器语言，Xcode 帮你做）
机器语言程序（电脑看的）
    ↓ 运行
运行结果（屏幕上的输出）
```

> 在 Xcode 里按 Cmd + R，就是"先编译、再运行"。报错是电脑在说"这句我没看懂"，改对就好了。

## 二、学 C 需要准备什么？

- 一台 Mac
- Xcode（App Store 免费安装）
- 一颗"敢动手、不怕错"的心

> **正确学习法：先抄 → 再改 → 最后自己写。** 每一步都要真的敲代码。
