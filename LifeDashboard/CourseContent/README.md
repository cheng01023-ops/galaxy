## 🛠️ Xcode 快速配置（1 分钟版）

详细图文版在第 1 天手册的"第 1 步"里，这里给速查：

1. 打开 Xcode → **File → New → Project...**（`Cmd + Shift + N`）
2. 先点上方 **macOS** 标签 → 选 **Command Line Tool** → Next
3. **Product Name** 填 `CppLearning`，**Language 必须选 C++**（默认是 Swift！）
4. 选择保存位置 → Create
5. 把 `code/day0X_*.cpp` 的内容复制进 `main.cpp`
6. 按 **`Cmd + R`** 运行，结果在底部调试区；要输入时先点击调试区

**调试三件套（每天都要用）：**
- **打断点**：点击行号左侧，出现蓝色箭头
- **单步调试**：Continue（继续）/ Step Over（跳过）/ Step Into（进入函数）/ Step Out（跳出）
- **看变量**：调试区左侧 Variables 面板实时显示每个变量的值

## 🧭 常见问题 FAQ

**Q1：Xcode 里 Language 只有 Swift，找不到 C++？**
新建项目时先点上方 "macOS" 标签，选 "Command Line Tool"，Next 之后才会出现 Language 下拉框，选 C++。

**Q2：代码粘贴进去报一堆红错？**
多半是建成了 Swift 项目。重新建项目，Language 选 C++。

**Q3：程序运行了但看不到输出？**
按 `Cmd + Shift + Y` 打开底部调试区。

**Q4：程序要求输入，但打字没反应？**
点击底部调试区，让光标聚焦在控制台上再输入。

**Q5：cin 输入后，后面的输入"跳过去"了？**
`cin >>` 会在缓冲区留下换行符，后面用 `getline` 前要加 `cin.ignore()`（第 3 天有详解）。

**Q6：第 4 天指针太难，看不懂怎么办？**
正常！指针是公认的难点。把"信箱/门牌号"的比喻抄下来、画图理解，再打断点一步步看。第 4 天可以拆成两个晚上。

**Q7：每天时间不够怎么办？**
学编程最忌贪多。每天只求"学透 + 完成练习"，7 天变 10 天也没关系，基础牢最重要。

**Q8：这个学习过程需要联网吗？**
不需要。手册、代码、软件全部在本地，编译和运行都用你电脑上的 Xcode。只有后续进阶（LeetCode、查文档）才需要网络。

## 🎯 学习心法（读 3 遍）

1. **动手 > 观看**：所有示例亲手敲，练习先自己想，再看答案
2. **会调试 > 会背语法**：报错是老师，断点是放大镜
3. **理解"为什么" > 死记"怎么做"**：每学一个概念，先问它解决什么问题
4. **输出是最好的学习**：每天结束，用一句话向自己复述今天学会了什么
5. **接受反复**：一个概念今天不懂，睡一觉、隔天再看，往往就通了
