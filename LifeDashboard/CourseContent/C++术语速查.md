# C++ 术语速查

> 教程里出现过的术语，这里用**一句话**讲清楚。
> 想不起来的时候，随时回来查。按拼音/字母顺序排列。

---

## 🔤 程序与运行

| 术语 | 一句话解释 | 出现在 |
| --- | --- | --- |
| 程序 | 给电脑的一串指令，按顺序执行 | 预备课 |
| 编程 | 写这些指令的过程 | 预备课 |
| 编译 | 把代码"翻译"成电脑能执行的机器语言 | 预备课/第1天 |
| 运行 | 执行编译好的程序，得到结果 | 预备课/第1天 |
| 编译错误 | 代码写错（如少分号），编译阶段被电脑指出 | 第1天 |
| 运行时错误 | 能编译但运行中出错（如除数为 0） | 第1天 |
| 调试 | 找出并修复 bug 的过程 | 第1天 |
| 断点 | 打在代码行上，运行到这里会暂停，方便查看 | 第1天 |

## 🧩 数据

| 术语 | 一句话解释 | 出现在 |
| --- | --- | --- |
| 变量 | 带名字的"储物盒"，用来存数据，值可以变 | 第1天 |
| 常量 | 值不能变的量 | 第1天 |
| 数据类型 | 数据种类：整数、小数、字符、真假、字符串 | 第1天 |
| 表达式 | 由变量/常量/运算符组成的一段"算式" | 第1天 |
| 语句 | 以分号结尾的一条指令 | 第1天 |
| 作用域 | 变量"活着"的范围（花括号内） | 第3天 |
| 全局变量 | 定义在所有函数外的变量，到处能用 | 第3天 |
| 局部变量 | 定义在函数/花括号内的变量 | 第3天 |

## 🧮 运算与流程

| 术语 | 一句话解释 | 出现在 |
| --- | --- | --- |
| 运算符 | + - * / % 等"运算符号" | 第1天 |
| 取余 % | 除法剩下的余数，如 7 % 3 = 1 | 第1天 |
| 分支 | 根据条件走不同的路（if/switch） | 第2天 |
| 循环 | 反复执行同一段代码（for/while） | 第2天 |
| 死循环 | 条件永远成立，程序停不下来 | 第2天 |

## 🧭 函数

| 术语 | 一句话解释 | 出现在 |
| --- | --- | --- |
| 函数 | 打包好的一段代码，起个名字随时调用 | 第3天 |
| 参数 | 调用函数时传进去的数据 | 第3天 |
| 返回值 | 函数算完后送回的结果 | 第3天 |
| 值传递 | 传的是副本，函数里改了不影响外面 | 第3天 |
| 引用传递 | 传的是"别名"，函数里改的就是外面 | 第4天 |
| 递归 | 函数自己调用自己，把大问题拆小 | 第3天 |
| 重载 | 同名函数、参数不同，编译器自动选 | 第3天 |

## 📚 数据容器

| 术语 | 一句话解释 | 出现在 |
| --- | --- | --- |
| 数组 | 一排同类型的格子，按下标访问（从 0 开始） | 第3天 |
| 下标 | 格子的编号，如 arr[0] 是第 1 个 | 第3天 |
| 越界 | 访问了不存在的格子（下标超范围） | 第3天 |
| 字符串 string | 一串文字 | 第3天 |
| 容器 vector | 能自动变大变小的"智能数组" | 第6天 |
| 键值对 map | "字典"：用键查值 | 第6天 |

## 🧠 内存

| 术语 | 一句话解释 | 出现在 |
| --- | --- | --- |
| 地址 | 变量在内存里的"门牌号" | 第4天 |
| 指针 | 存地址的变量，可以通过它修改原数据 | 第4天 |
| 解引用 * | 顺着地址取出/修改里面的值 | 第4天 |
| 引用 & | 给变量起"别名"，直接操作原变量 | 第4天 |
| 空指针 nullptr | 不指向任何地方的安全指针 | 第4天 |
| 野指针 | 没初始化就用的指针，指向随机地址（危险） | 第4天 |
| 动态内存 new/delete | 运行时按需申请/释放内存 | 第4天 |
| 内存泄漏 | new 了不 delete，内存悄悄流失 | 第4天 |
| 悬空指针 | 内存已释放但指针还留着旧地址 | 第4天 |

## 🏛️ 面向对象

| 术语 | 一句话解释 | 出现在 |
| --- | --- | --- |
| 类 class | "模具"：描述有什么数据、能做什么 | 第5天 |
| 对象 | 用模具造出来的具体"实例" | 第5天 |
| 成员变量/函数 | 属于某个类的数据/函数 | 第5天 |
| 封装 | 数据私有 + 通过受控方法访问，保护数据 | 第5天 |
| 构造函数 | 创建对象时自动执行的初始化函数 | 第5天 |
| 析构函数 | 对象销毁时自动执行的清理函数 | 第5天 |
| 继承 | 子类复用父类的代码 | 第6天 |
| 多态 | 同一句代码，不同对象表现不同 | 第6天 |
| 虚函数 | 加了 virtual，让多态生效 | 第6天 |
| 抽象类 | 含纯虚函数的类，只能被继承不能实例化 | 第6天 |
