## 第 1 步：回顾 + 内存的直觉模型

**昨天留下一个问题**：值传递改不了外面的变量。

```cpp
void trySwap(int a, int b) { int t = a; a = b; b = t; }
int x = 1, y = 2;
trySwap(x, y);   // 换失败！因为函数里操作的是副本
```

要解决它，必须先搞懂一个底层问题：**变量到底存在哪里？**

**内存的直觉模型（请画下来）：**

想象内存是一排**信箱**（或者一排储物柜）：

```
地址（门牌号）  0x100  0x104  0x108  0x10C ...
信箱内容        25      ...    ...    ...
```

- 每个信箱有一个**编号（地址）**
- 每个变量住在某个信箱里，**地址是唯一的**
- `int age = 25;` 做的事情：找一个信箱，把 25 放进去

**核心认知：变量 = 地址 + 值。** 平时我们用"变量名"指代它，但底层是"某个地址上的某个值"。

## 第 2 步：取地址 &——问"你的门牌号是多少"

C++ 用 `&` 运算符取一个变量的**地址**：

```cpp
int age = 25;

cout << age;     // 输出信箱里的内容：25
cout << &age;    // 输出信箱的门牌号：类似 0x16f1ab6c8
```

```cpp
#include <iostream>
using namespace std;
int main() {
    int age = 25;
    int height = 180;

    cout << "age 的值：" << age << endl;          // 25
    cout << "age 的地址：" << &age << endl;        // 一串十六进制数
    cout << "height 的值：" << height << endl;     // 180
    cout << "height 的地址：" << &height << endl;  // 另一串数

    // 你会发现：相邻变量的地址往往挨得很近，差 4 个字节（一个 int 的大小）
    return 0;
}
```

**运行观察**：两次运行，地址通常不同（系统每次分配的位置可能不同），但**同一变量在同一运行里地址固定**。这就是"门牌号"。

> 地址的写法 `0x...` 是十六进制，不用会换算，知道它是"门牌号"就行。

## 第 3 步：指针——存"门牌号"的变量

> 🗣️ 大白话：指针 = 写着**门牌号**的便利贴。你不用把箱子搬来，拿着门牌号就能找到箱子、改里面的东西。

### 3.1 定义指针

**指针（pointer）就是一个用来存地址的变量**：

```cpp
int age = 25;      // 普通变量：存值
int *p = &age;     // 指针变量：存 age 的地址

// 读法：p 是指向 int 的指针（int *p）
```

**现在内存里有两个东西：**

```
变量 age（信箱）         指针 p（另一个信箱）
+-----------+           +------------------+
| 25        |           | &age（0x16f...） |
+-----------+           +------------------+
 地址 0x16f...            地址 0x16f+8...
```

- `p` 的值 = age 的地址（门牌号）
- 通过 `p`，我们能**找到并修改** age

### 3.2 解引用 *——通过门牌号进去拿东西

```cpp
*p = 30;         // 顺着 p 里存的地址，把那个信箱的内容改成 30
cout << age;     // 输出 30！age 真的被改了
```

**指针三件套（必须分清，背下来）：**

| 写法 | 含义 | 打个比方 |
| --- | --- | --- |
| `p` | 指针里存的**地址** | 门牌号 |
| `*p` | 地址里存的**值** | 敲门进去看到的箱子里的东西 |
| `&age` | 取 age 的**地址** | 问 age 的门牌号 |

![指针：p 存地址，*p 修改原变量](demos/demo_pointer.gif)
### 3.3 完整演示 + 断点观察

```cpp
#include <iostream>
using namespace std;
int main() {
    int age = 25;
    int *p = &age;

    cout << "age = " << age << endl;     // 25
    cout << "&age = " << &age << endl;   // 地址
    cout << "p = " << p << endl;         // 和 &age 一样
    cout << "*p = " << *p << endl;       // 25

    *p = 30;                             // 通过指针修改
    cout << "age = " << age << endl;     // 30 ✅

    return 0;
}
```

**必做调试**：在 `*p = 30;` 打断点，看变量面板里 `age`、`p`、`*p` 三个值，理解它们的区别。然后单步执行，观察 `*p = 30` 执行后 age 的变化。

## 第 4 步：空指针与野指针——安全红线

**空指针 `nullptr`**：不指向任何地方的指针，表示"我还没想好指哪"。

```cpp
int *p = nullptr;      // 安全的"空"
if (p == nullptr) {
    cout << "p 还没指向任何地方" << endl;
}
// 用之前先判断，安全
```

**野指针（危险！）**：**没有初始化**就使用的指针，里面是随机垃圾地址。

```cpp
int *bad;       // ❌ 没初始化！里面是随机值（野指针）
*bad = 10;      // ❌ 往随机地址写数据 → 大概率崩溃！
```

**为什么危险？** 你根本不知道 `bad` 指向哪——可能是别人的内存、系统内存。写进去轻则崩溃，重则数据损坏。**这是 C++ 最常见、最隐蔽的 bug 来源之一。**

**三条铁律（背下来）：**
1. 指针**定义时就要初始化**：要么 `= &变量`，要么 `= nullptr`
2. 解引用前**先判断是不是空**
3. 指针指向的内存释放后，**立刻置为 nullptr**

**马上动手（练习 2）**：写出"安全使用指针"的完整流程（定义 → 判断空 → 使用）。

<details><summary>点开看参考答案</summary>

```cpp
#include <iostream>
using namespace std;
int main() {
    int value = 42;
    int *p = &value;        // 1. 定义时就初始化

    if (p != nullptr) {     // 2. 用前判断
        cout << *p << endl; // 3. 使用
    }
    return 0;
}
```
</details>

## 第 5 步：指针与数组、指针运算

### 5.1 数组名就是首元素地址

```cpp
int arr[] = {10, 20, 30};
int *pa = arr;             // 等价于 int *pa = &arr[0];
```

`arr` 这个名字本身就代表首元素的地址，所以可以直接赋给指针。

### 5.2 指针 + 数字 = 跳过几个元素

```cpp
cout << *pa;        // 10（第 0 个）
cout << *(pa + 1);  // 20（第 1 个）
cout << *(pa + 2);  // 30（第 2 个）
```

**关键**：`pa + 1` 不是地址加 1，而是**跳过一整个 int（4 字节）**。指针加 n，地址实际加 `n × 类型大小`。

### 5.3 用指针遍历数组

```cpp
int arr[] = {10, 20, 30, 40};
int *p = arr;
for (int i = 0; i < 4; i++) {
    cout << *(p + i) << " ";   // 等价于 arr[i]
}
```

**这也解释了为什么"函数里改数组会影响外面"**：数组传给函数时，传的是**首地址**（不是副本），所以函数通过地址改的就是原数组。

```cpp
void addOne(int arr[], int n) {   // 这里的 arr[] 其实是 int *arr
    for (int i = 0; i < n; i++) {
        arr[i] += 1;              // 改的就是外面的数组！
    }
}
```

**马上动手（练习 3）**：用指针遍历数组，输出数组的**最大值**。

## 第 6 步：引用——比指针友好的"别名"

**引用（reference）就是给变量起个"别名"**：别名和本名指向**同一个信箱**，用哪个都一样。

```cpp
int a = 10;
int &r = a;      // r 是 a 的引用（别名），用 & 定义
r = 20;          // 相当于 a = 20
cout << a;       // 20 ✅
```

**引用和指针的本质区别（背下来）：**

| 对比 | 指针 | 引用 |
| --- | --- | --- |
| 定义写法 | `int *p = &a;` | `int &r = a;` |
| 能不能为空 | 可以是 nullptr | **必须初始化，不能为空** |
| 能不能改指向 | 可以 | **一旦绑定不能改** |
| 取里面的值 | 要解引用 `*p` | 直接用 `r` |
| 适合场景 | 动态内存、遍历等 | 函数参数、返回多个值 |

**一句话**：指针是"门牌号"，可以改；引用是"外号"，天生就是那个人。

> 为什么引用更安全？因为它**永远指向一个真实存在的变量**，没有野引用、空引用的问题。

**马上动手（练习 4）**：定义一个变量并用引用给它起别名，通过别名修改，验证原变量变了；再试试能不能让引用"改指向"另一个变量（会编译报错吗？）。

<details><summary>点开看参考答案</summary>

```cpp

int main() {
    int a = 10, b = 99;
    int &r = a;      // r 绑定 a
```

## 第 7 步：三种传参方式对比——解决"换不掉"的问题

昨天的问题现在可以解决了。三种方式：

```cpp
// 方式 1：值传递（副本，改不了外面）
void swapByValue(int a, int b) {
    int t = a; a = b; b = t;
}

// 方式 2：指针传递（传地址，能改外面）
void swapByPtr(int *a, int *b) {
    int t = *a;
    *a = *b;
    *b = t;
}

// 方式 3：引用传递（传别名，能改外面，最推荐）
void swapByRef(int &a, int &b) {
    int t = a; a = b; b = t;
}
```

```cpp
int x = 1, y = 2;
swapByValue(x, y);   // 失败：x,y 还是 1,2
swapByPtr(&x, &y);   // 成功：要传地址
swapByRef(x, y);     // 成功：直接传变量
```

**理解方式 2（指针）**：`&x` 是 x 的门牌号，函数拿到门牌号后，`*a` 就是顺着门牌号操作 x 本体。

**理解方式 3（引用）**：`int &a` 就是"a 是 x 的别名"，函数里所有 `a` 都是 x。

**用引用返回多个结果**（函数只能 return 一个值）：

```cpp
void minMax(int arr[], int n, int &minV, int &maxV) {
    minV = arr[0];
    maxV = arr[0];
    for (int i = 1; i < n; i++) {
        if (arr[i] < minV) minV = arr[i];
        if (arr[i] > maxV) maxV = arr[i];
    }
}

int nums[] = {7, 3, 9, 1, 5};
int mn, mx;
minMax(nums, 5, mn, mx);   // mn、mx 被"填"上结果
cout << mn << " " << mx;   // 1 9
```

**选哪个？** 默认用**引用**（安全、直观）；需要"可能没有值"或动态内存时用指针。

**马上动手（练习 5）**：写一个函数，用引用参数同时求出"平均值"和"最大值"并返回。

## 第 8 步：动态内存——new 和 delete

### 8.1 为什么要"动态"内存

之前所有变量都在"栈"上，**大小必须在编译时定死**：

```cpp
int n;
cin >> n;
int arr[n];        // ❌ 部分编译器不允许：数组大小要编译时确定
```

但很多场景**运行时才知道要多大**（用户输入 n）。这时用 `new` 在**堆**上动态申请：

```cpp
int n;
cout << "要几个数？";
cin >> n;

int *arr = new int[n];    // 在堆上申请 n 个 int（大小运行时才定）
for (int i = 0; i < n; i++) {
    cin >> arr[i];        // 用起来和普通数组一样
}
delete[] arr;             // 用完必须释放！
arr = nullptr;
```

### 8.2 单个变量的动态分配

```cpp
int *p = new int;      // 申请一个 int 的空间
*p = 99;               // 存值
delete p;              // 释放（注意：不是 delete[]）
p = nullptr;
```

![new/delete：申请、使用、释放](demos/demo_newdelete.gif)
### 8.3 两条铁律（必须背）

1. **`new` 必须配对 `delete`**（数组用 `delete[]`），一一对应
2. 释放后**立刻把指针置为 `nullptr`**

```cpp
int *p = new int(5);
delete p;
// 忘记 p = nullptr;  ← 危险！
*p = 99;   // ❌ p 现在是"悬空指针"，指向已释放的内存
```

### 8.4 为什么必须 delete？——内存泄漏

程序申请的堆内存，**不会自动释放**（不像栈上变量离开作用域自动销毁）。忘了 delete：

```cpp
while (true) {
    int *p = new int[1000];   // 每次都申请，从不释放
    // ... 用 ...
    // ❌ 忘了 delete[] —— 内存悄悄流失
}
```

跑久了，可用内存越来越少，程序越来越慢直到崩溃——这叫**内存泄漏**。服务器程序最怕这个。

**练习 C（挑战）：动态二维数组**
输入行数 r 和列数 c，动态创建 r×c 的二维数组，填数并求和。
提示：`int **m = new int*[r];`，每行再 `new int[c]`，用完逐行释放。

<details><summary>点开看答案</summary>

```cpp
#include <iostream>
using namespace std;
int main() {
    int r, c;
    cout << "输入行和列：";
    cin >> r >> c;

    int **m = new int*[r];        // 先建 r 个"行指针"
    for (int i = 0; i < r; i++) {
        m[i] = new int[c];        // 每行再建 c 个 int
    }

    int sum = 0;
    for (int i = 0; i < r; i++) {
        for (int j = 0; j < c; j++) {
            m[i][j] = i + j;      // 随便填个数
            sum += m[i][j];
        }
    }
    cout << "总和 = " << sum << endl;

    for (int i = 0; i < r; i++) delete[] m[i];   // 逐行释放
    delete[] m;
    return 0;
}
```
</details>

<details><summary>点开看答案</summary>

1. p 是地址；*p 是地址里的值；&age 是 age 的地址。
2. 不初始化就是野指针，指向随机地址，解引用会崩溃或损坏数据。
3. 引用必须初始化、不能为空、绑定后不能改指向；指针可以 nullptr 且可改指向。
4. 内存泄漏，长期运行内存越占越多直到崩溃。
5. 防止悬空指针——释放后地址仍存在但内容无效，再用会出错。
6. 不是，是跳过一整个类型的字节数。
7. 首元素的地址（&arr[0]）。
8. 引用（安全直观）；指针也行但要小心空指针。
9. `delete[]`。
10. 指向的内存已被释放、但指针还保留着旧地址的指针。
</details>

## ⚠️ 今日坑点汇总

| 坑 | 说明 | 正确做法 |
| --- | --- | --- |
| 野指针 | 未初始化就解引用 | 定义时初始化或置 nullptr |
| 悬空指针 | delete 后还用它 | 释放后立即置 nullptr |
| 内存泄漏 | new 了忘 delete | new/delete 一一配对 |
| 数组 delete 用错 | `delete` 而非 `delete[]` | 数组用 `delete[]` |
| 引用不初始化 | `int &r;` 编译错误 | 定义引用必须同时绑定 |
| 指针运算误解 | 以为 +1 是地址+1 | 是跳过一整个类型 |
