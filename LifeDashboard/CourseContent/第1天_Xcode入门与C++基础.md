## 第 1 步：把 Xcode 配置好（约 20 分钟）

**第 1 小步：打开 Xcode**
在"启动台"里找到 Xcode 图标并打开。第一次启动时，系统会提示安装额外组件，点击"同意"并等待完成（几分钟）。这一步只需要做一次。

**第 2 小步：新建一个 C++ 项目**
1. 菜单栏选 **File → New → Project...**（快捷键 `Cmd + Shift + N`）
2. 在弹出的窗口里，**先点最上方的 "macOS" 标签**（不是 iOS！）
3. 在模板列表里找到 **Command Line Tool**（命令行工具），选中后点 **Next**
4. 填写项目信息：
   - **Product Name（产品名称）**：填 `CppLearning`
   - **Language（语言）**：这里最关键！下拉框默认是 Swift，**必须改成 C++**
   - 其余项保持默认即可
5. 点 **Next**，选择保存位置（建议放"文稿"文件夹里建一个 `CppProjects` 文件夹统一管理），点 **Create**

> ⚠️ 最常犯的错：Language 忘选 C++，建成了 Swift 项目。如果发现代码颜色、内容不对，八成是这个原因，删掉重建即可。

**第 3 小步：认识 Xcode 的 4 个区域**
- **左侧导航区**：显示项目里的文件，我们主要用 `main.cpp`
- **中间编辑区**：写代码的地方（光标在这里）
- **底部调试区**：运行结果显示在这里，快捷键 `Cmd + Shift + Y` 可以显示/隐藏
- **顶部工具栏**：右侧的 ▶ 是运行按钮

**第 4 小步：运行你的第一个程序**
新建好的 `main.cpp` 里已经有一段代码。直接按 **`Cmd + R`**（或点 ▶），几秒后底部调试区会出现一行字：

```
Hello, World!
```

恭喜！你的 C++ 开发环境已经正式跑通了 🎉

> **小知识**：`Cmd + R` 是"编译并运行"——先把你写的代码翻译成电脑能懂的机器语言（编译），再执行（运行）。以后你会经常用到它。

**第 5 小步：验证调试工具能用（强烈建议现在就做）**
1. 在 `main.cpp` 里，找到 `return 0;` 那一行，**点击它左边灰色行号的位置**，会出现一个蓝色箭头（这就是"断点"）
2. 再按 `Cmd + R`，程序会**停在断点那一行**，不再往下执行
3. 观察底部调试区：左侧会列出当前所有变量的值
4. 点调试区顶部的"继续"按钮（▶ 图标），程序跑完
5. 把蓝色箭头拖走，取消断点

> 断点调试是学编程最重要的技能。**从今天开始养成习惯：程序结果不对 → 先打断点看变量，而不是瞎猜。**

✅ 第 1 步完成！进入下一步前，先自己把 Hello World 运行了 3 次（改一改里面的文字再运行，看看变化）。

## 第 2 步：逐行看懂 C++ 程序结构

打开 Xcode 里的 `main.cpp`，你会看到类似这样的代码。我们逐行拆开讲：

```cpp
#include <iostream>   // 第 1 行：引入"头文件"
using namespace std;  // 第 2 行：打开"命名空间"
int main() {          // 第 3 行：主函数（程序入口）
    cout << "Hello, World!" << endl;   // 第 4 行：输出一句话
    return 0;         // 第 5 行：告诉系统"正常结束"
}                     // 第 6 行：主函数结束
```

**逐行解释：**

| 行 | 作用 | 打个比方 |
| --- | --- | --- |
| `#include <iostream>` | 引入输入输出工具库，`cout`/`cin` 都来自这里 | 相当于"自带工具箱"：先声明"我要用工具箱里的工具" |
| `using namespace std;` | 允许直接写 `cout`，不用每次写 `std::cout` | 相当于"我默认用标准牌的工具，不用每次说全名" |
| `int main() {` | 定义主函数，程序**从这里开始**执行 | 相当于文章的"正文开头" |
| `cout << "..." << endl;` | 向屏幕输出文字，`endl` 表示换行 | 相当于"大声念出一句话" |
| `return 0;` | 程序正常结束，返回 0 给操作系统 | 相当于"鞠躬退场，表示一切正常" |
| `}` | 结束 main 函数 | 正文结束 |

**记忆口诀：引头文件、开命名空间、进主函数、写语句、返回 0。**

**几个马上要懂的细节：**
- 每一行"指令"结尾都要有**分号 `;`**，像中文的句号
- `//` 后面是**注释**，是写给"人"看的说明，电脑会忽略它。多写注释是好习惯！
- 大括号 `{ }` 成对出现，表示代码的"范围"

✅ 现在动手：在 `main.cpp` 里把 `"Hello, World!"` 改成你自己的名字，运行看看。再删掉一个分号运行，观察 Xcode 报的红色错误——**故意弄错一次，比背十遍都记得牢**。

## 第 3 步：cout 输出——让程序"说话"

`cout` 是 C++ 里最常用的输出工具。完整写法：

```cpp
cout << "要输出的内容" << endl;
```

拆开理解：
- `cout`：输出工具的名字（读作 "see-out"）
- `<<`：把右边的东西"送进"cout，**箭头指向屏幕**
- `"..."`：双引号包起来的是**原样输出的文字**
- `endl`：end line 的缩写，换行

**可以输出三种东西：**

```cpp
cout << "我是文字";                    // 输出文字
cout << 3 + 4;                        // 输出计算结果：7
cout << "我的年龄是" << 18 << "岁";    // 文字和数字混着输出
```

**一行可以连续输出多次**（用多个 `<<`）：

```cpp
cout << "姓名：" << "小明" << "，年龄：" << 18 << endl;
```

> 💡 为什么要用 `endl`？不加的话，下一句输出会接在同一行后面。试试把 `endl` 删掉再运行，你立刻就懂了。

## 第 4 步：变量与基本类型——让程序"记住东西"

### 4.1 什么是变量？

程序经常需要**记住数据**，比如你的年龄、身高、名字。变量就是一个"带标签的储物盒"：

- 盒子上写着标签（变量名）
- 盒子里放着数据（变量的值）
- 你可以随时**换掉盒子里的东西**（重新赋值）

```cpp
int age = 18;      // 定义一个叫 age 的盒子，里面放 18
age = 19;          // 把盒子里的东西换成 19
cout << age;       // 输出 19
```

语法拆解：`类型 变量名 = 初始值;`

![变量：储物盒里装值、换值](demos/demo_variable.gif)
### 4.2 5 种基本类型（逐个认识）

| 类型 | 存什么 | 例子 | 注意 |
| --- | --- | --- | --- |
| `int` | 整数 | `int age = 18;` | 不能存小数 |
| `double` | 小数 | `double h = 1.75;` | 也叫浮点数 |
| `char` | 单个字符 | `char g = 'A';` | **必须用单引号**，只能 1 个字符 |
| `bool` | 真假 | `bool ok = true;` | 只有 true/false，输出显示 1/0 |
| `string` | 一串文字 | `string n = "小明";` | **用双引号**，需要 `#include <string>` |

**逐个举例：**

```cpp
#include <iostream>
#include <string>     // 用 string 必须加这一行
using namespace std;

int main() {
    int age = 18;                 // 整数
    double height = 1.75;         // 小数
    char grade = 'A';             // 单个字符（单引号！）
    bool isHappy = true;          // 真假
    string name = "小明";          // 字符串（双引号！）

    cout << "年龄：" << age << endl;
    cout << "身高：" << height << " 米" << endl;
    cout << "等级：" << grade << endl;
    cout << "开心吗：" << isHappy << endl;   // true 会输出 1
    cout << "名字：" << name << endl;
    return 0;
}
```

> 注意 `char` 用单引号 `'A'`，`string` 用双引号 `"小明"`——**这是最常见的低级错误之一**，写错会直接编译报错。

### 4.3 变量命名规则（背下来）

- 只能由**字母、数字、下划线**组成
- **不能以数字开头**：`1name` 错，`name1` 对
- 不能和 C++ 关键字重名（如 `int`、`if`、`for`）
- 建议"见名知意"：存年龄用 `age`，不要用 `a`
- 常用风格：多个单词用下划线连接，如 `my_age`

### 4.4 变量常见错误

```cpp
int a = 3;
a = "hello";    // ❌ 类型不匹配：int 的盒子里不能放字符串
int 3x = 5;     // ❌ 变量名不能以数字开头
int score;      // ⚠️ 声明了但没赋值，里面的值是"随机垃圾"
cout << score;  // ⚠️ 输出不可预料！记住：变量先赋值再用
```

## 第 5 步：cin 输入——让程序"听懂你"

`cin` 是 C++ 的输入工具，作用正好和 `cout` 相反：**从键盘读数据，存进变量**。

```cpp
int age;
cin >> age;          // 程序停下来等你敲数字，按回车后存进 age
```

**箭头方向记忆法**：`cout <<`（箭头指向屏幕=输出），`cin >>`（箭头指向变量=输入）。

**一次读多个值：**

```cpp
int a, b;
cin >> a >> b;       // 输入两个数，用空格或回车隔开都可以
```

**完整例子：问名字和年龄，然后打招呼**

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name;
    int age;

    cout << "请输入你的名字：";
    cin >> name;

    cout << "请输入你的年龄：";
    cin >> age;

    cout << "你好，" << name << "！你今年 " << age << " 岁。" << endl;
    return 0;
}
```

**运行体验**：按 `Cmd + R` 后，程序会停住等你输入。**记得先点击底部调试区，让光标聚焦在那里**，然后输入名字、回车，再输入年龄、回车。

> ⚠️ 输入后没反应？90% 是因为光标没点进底部控制台。点一下调试区再输入即可。

## 第 6 步：运算符——让程序"会算数"

### 6.1 算术运算符

| 运算符 | 含义 | 例子 | 结果 |
| --- | --- | --- | --- |
| `+` | 加 | `7 + 2` | 9 |
| `-` | 减 | `7 - 2` | 5 |
| `*` | 乘 | `7 * 2` | 14 |
| `/` | 除 | `7 / 2` | **3（！）** |
| `%` | 取余 | `7 % 2` | 1 |
| `++` | 自增 1 | `i++` | i 变 i+1 |
| `--` | 自减 1 | `i--` | i 变 i-1 |

### 6.2 最经典的坑：整数除法！

```cpp
int a = 7, b = 2;
cout << a / b;      // 输出 3，不是 3.5！
```

**为什么？** 两个 `int` 相除，C++ 默认做"整数除法"，结果还是整数，小数部分被**直接丢掉**（不是四舍五入）。

**想得到小数，两种办法：**
```cpp
cout << 7.0 / 2;    // 办法一：至少一边写成小数 → 3.5
cout << (double)7 / 2;  // 办法二：强制转换 → 3.5
```

![整数除法：小数被丢掉](demos/demo_intdiv.gif)
### 6.3 复合赋值运算符（偷懒写法）

| 写法 | 等价于 | 含义 |
| --- | --- | --- |
| `sum += i` | `sum = sum + i` | 累加 |
| `sum -= i` | `sum = sum - i` | 累减 |
| `product *= 2` | `product = product * 2` | 累乘 |
| `n++` | `n = n + 1` | 加 1 |

### 6.4 比较运算符与逻辑运算符（第 2 天会大量用到，先认识）

| 运算符 | 含义 | 例子 |
| --- | --- | --- |
| `==` | 相等（注意是两个等号！） | `a == b` |
| `!=` | 不相等 | `a != b` |
| `>` `<` `>=` `<=` | 大小比较 | `a >= 0` |
| `&&` | 并且（两边都真才真） | `a > 0 && a < 10` |
| `\|\|` | 或者（一边真就真） | `a == 0 \|\| b == 0` |
| `!` | 取反 | `!ok` |

> ⚠️ `=` 是赋值，`==` 是判断相等。写 `if (a = 5)` 的人，都掉进过这个坑。

## 第 7 步：综合小项目——温度转换器（把今天全串起来）

现在把"变量 + 输入 + 输出 + 运算"组合成一个完整的小程序：输入摄氏温度，输出华氏温度。
公式：`华氏度 = 摄氏度 × 9 ÷ 5 + 32`

```cpp
#include <iostream>
using namespace std;

int main() {
    // 1. 定义变量：存摄氏温度
    double celsius;

    // 2. 提示并输入
    cout << "请输入摄氏温度：";
    cin >> celsius;

    // 3. 计算（注意用 9.0 而不是 9，避免整数除法丢小数）
    double fahrenheit = celsius * 9.0 / 5 + 32;

    // 4. 输出结果
    cout << "华氏温度是：" << fahrenheit << " 度" << endl;

    return 0;
}
```

**逐行精讲：**
- 第 1 行 `#include <iostream>`：引入输入输出工具
- `double celsius;`：声明一个小数变量（还没赋值）
- `cout << "请输入摄氏温度："`：提示用户（不加 endl，让光标停在提示后）
- `cin >> celsius;`：读取用户输入存入 celsius
- `double fahrenheit = ...`：计算并存入新变量。**为什么写 `9.0` 不写 `9`？** 因为 `celsius * 9 / 5` 里如果都是整数会丢小数（第 6.2 节的坑）
- `return 0;`：正常结束

**自己改一改：** 把程序改成反向转换（输入华氏度输出摄氏度，公式 `C = (F - 32) × 5 ÷ 9`）。

## 第 8 步：断点调试——学会自己找 bug（重点！）

程序出错不可怕，可怕的是不会找错。调试四步法：

**第 1 步：打断点**
在代码**行号左边**点一下，出现蓝色箭头。程序运行到这里会暂停。

**第 2 步：运行到断点**
按 `Cmd + R`。程序停在断点行（该行还没执行）。

**第 3 步：单步执行 + 看变量**
用调试区顶部的按钮：
- **Continue（继续 ▶）**：跑到下一个断点或结束
- **Step Over（跳过 ⬇）**：执行当前行，**不进入**函数内部
- **Step Into（进入 ⬇➡）**：**进入**函数内部，一行行看
- **Step Out（跳出 ⬆）**：从函数里跳出来

左侧"Variables（变量）"面板会实时显示每个变量的当前值——**这就是你找 bug 的放大镜**。

**第 4 步：结束调试**
点红色 ■ 停止，或按 `Cmd + .`。

**一个必做的调试练习：**
在温度转换器里，把断点打在 `double fahrenheit = ...` 那一行，运行后观察：
1. 输入 `25`
2. 断点触发，看左侧 `celsius` 的值是不是 25
3. 单步执行一行，再看 `fahrenheit` 变成了多少
4. 你会发现：程序的每一步，你都能亲眼看到

> 💡 调试心法：**结果不对 → 打断点 → 看变量在哪一步变得不符合预期 → 那一步就是 bug 所在。** 以后所有 7 天都会用到这个技能。

## 🏋️ 分级练习（先自己想 10 分钟，再看答案）

**练习 A（基础）：圆的面积**
输入半径 `r`，输出圆面积（`面积 = 3.14159 × r × r`）。
提示：r 可能是小数，用 double；注意乘法不要用 × 符号，用 `*`。

<details><summary>点开看答案</summary>


**练习 B（进阶）：三位数反转**
输入一个三位数（如 123），输出反转后的数（321）。
提示：用 `%` 取出个位，用 `/` 去掉个位，拆成百位、十位、个位再重组。

<details><summary>点开看答案</summary>

```cpp
#include <iostream>
using namespace std;
int main() {
    int n;
    cout << "请输入一个三位数：";
    cin >> n;

    int ge = n % 10;        // 个位：n 除以 10 的余数
    int shi = n / 10 % 10;  // 十位：先去掉个位，再取余
    int bai = n / 100;      // 百位：直接除以 100

    cout << "反转后：" << ge << shi << bai << endl;
    return 0;
}
```
</details>
