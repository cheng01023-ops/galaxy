## 一、空间解析几何基础

### 1.1 空间直角坐标

点 P(x,y,z) 由三个坐标确定；两点距离：

d = √[(x₂−x₁)² + (y₂−y₁)² + (z₂−z₁)²]

### 1.2 向量

- 向量 a=(a₁,a₂,a₃)
- 点积：a·b = a₁b₁+a₂b₂+a₃b₃；a⊥b ⇔ a·b=0
- 叉积：a×b 是垂直于 a、b 的向量；|a×b| = |a||b|sinθ

### 1.3 平面与直线

- 平面（点法式）：A(x−x₀)+B(y−y₀)+C(z−z₀)=0
- 直线（参数式）：r = r₀ + t·d

## 二、多元函数的积分学

### 2.1 多元函数与偏导数

z=f(x,y)，偏导数 ∂f/∂x：把 y 当常数对 x 求导。
梯度 ∇f = (∂f/∂x, ∂f/∂y)，指向变化最快的方向。

### 2.2 二重积分

∬_D f(x,y) dA = 矩形细分求和的极限

- 直角坐标：先对 x 后对 y（或反之）
- 极坐标：dA = r dr dθ，适合圆域

### 2.3 应用

- 平面区域面积：∬_D 1 dA
- 体积：∬_D f(x,y) dA

## 三、线性变化与二次曲线曲面

### 3.1 线性变换

矩阵 A 把向量 x 映射为 Ax，保持直线与比例。

- 旋转、缩放、投影都是线性变换
- 特征值/特征向量：Av = λv

### 3.2 二次曲线（标准式）

| 曲线 | 标准方程 |
|---|---|
| 圆 | x²+y²=R² |
| 椭圆 | x²/a² + y²/b² = 1 |
| 双曲线 | x²/a² − y²/b² = 1 |
| 抛物线 | y² = 2px |

### 3.3 二次曲面

| 曲面 | 标准方程 |
|---|---|
| 球面 | x²+y²+z²=R² |
| 椭球面 | x²/a²+y²/b²+z²/c²=1 |
| 椭圆抛物面 | z = x²/a² + y²/b² |
| 圆锥面 | z² = x²+y² |
| 单叶双曲面 | x²/a²+y²/b²−z²/c²=1 |
