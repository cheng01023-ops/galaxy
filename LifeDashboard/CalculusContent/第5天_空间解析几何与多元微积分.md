## 一、空间解析几何基础

### 1.1 空间直角坐标

点 P(x,y,z)，到原点距离：

```
d = √(x²+y²+z²)
```

两点 P₁(x₁,y₁,z₁)、P₂(x₂,y₂,z₂) 距离：

```
d = √[(x₂−x₁)² + (y₂−y₁)² + (z₂−z₁)²]
```

### 1.2 向量运算

- 加法/减法：对应分量相加/相减
- 数乘：k·a = (ka₁,ka₂,ka₃)
- 模：|a| = √(a₁²+a₂²+a₃²)
- **点积**：a·b = a₁b₁+a₂b₂+a₃b₃ = |a||b|cosθ
  - a⊥b ⇔ a·b=0
- **叉积**：a×b 垂直于 a、b，|a×b|=|a||b|sinθ

### 1.3 平面方程

- 点法式：n·(r−r₀)=0，展开为 Ax+By+Cz+D=0
- 三点确定一个平面（取两个向量做叉积得法向量）

**例**：过点 (1,0,0)、法向量 (1,2,3)

```
1(x−1)+2(y−0)+3(z−0)=0 ⇒ x+2y+3z−1=0
```

### 1.4 直线方程

- 参数式：r = r₀ + t·d，即 x=x₀+at, y=y₀+bt, z=z₀+ct
- 方向向量 d 决定直线方向

## 二、多元函数的积分学

### 2.1 多元函数与偏导数

z=f(x,y)：

- ∂f/∂x：把 y 固定，对 x 求导
- ∂f/∂y：把 x 固定，对 y 求导

**例**：f(x,y)=x²y

```
∂f/∂x = 2xy
∂f/∂y = x²
```

### 2.2 梯度与方向导数

```
∇f = (∂f/∂x, ∂f/∂y)
```

梯度指向函数增长最快的方向，模长就是最大方向导数。

### 2.3 二重积分

```
∬_D f(x,y) dA = lim Σ f(ξᵢ,ηᵢ)Δσᵢ
```

计算：把二重积分化为累次积分。

- 直角坐标：∬ = ∫∫ f(x,y) dy dx 或 dx dy（先确定积分限）
- 极坐标：x=r cosθ, y=r sinθ，dA = r dr dθ（适合圆域）

### 2.4 应用

- 区域面积：A = ∬_D 1 dA
- 曲面下体积：V = ∬_D f(x,y) dA

**例**：D 是 0≤x≤1、0≤y≤1，求 ∬_D xy dA

```
= ∫_0^1 [∫_0^1 xy dy] dx = ∫_0^1 x·(1/2) dx = 1/4
```

## 三、线性变换与二次曲线曲面

### 3.1 线性变换

矩阵 A 把向量 x 映为 Ax，满足：

```
A(x+y) = Ax + Ay
A(cx) = cAx
```

- 旋转、缩放、反射、投影都是线性变换
- 特征值/特征向量：Av = λv

**例**：A 是 90° 旋转矩阵 [[0,−1],[1,0]]

### 3.2 二次曲线（标准式）

| 曲线 | 标准方程 | 参数 |
|---|---|---|
| 圆 | x²+y²=R² | 圆心原点，半径 R |
| 椭圆 | x²/a²+y²/b²=1 | a 长半轴，b 短半轴 |
| 双曲线 | x²/a²−y²/b²=1 | 渐近线 y=±(b/a)x |
| 抛物线 | y²=2px | 焦点 (p/2,0) |

一般式 Ax²+Bxy+Cy²+Dx+Ey+F=0 通过配方与旋转判别类型。

**例**：x²+y²−4x=0

```
配方：(x−2)²+y²=4 ⇒ 圆心 (2,0)，半径 2 的圆
```

### 3.3 二次曲面

| 曲面 | 标准方程 |
|---|---|
| 球面 | x²+y²+z²=R² |
| 椭球面 | x²/a²+y²/b²+z²/c²=1 |
| 椭圆抛物面 | z = x²/a² + y²/b² |
| 双曲抛物面 | z = x²/a² − y²/b² |
| 圆锥面 | z² = x²+y² |
| 单叶双曲面 | x²/a²+y²/b²−z²/c²=1 |
| 双叶双曲面 | x²/a²−y²/b²−z²/c²=1 |

## 四、例题精讲

**例 1**：求点 (1,2,3) 到原点距离

```
d = √(1+4+9) = √14
```

**例 2**：求 f(x,y)=x²y 的梯度

```
∇f = (2xy, x²)
```

**例 3**：求 D={0≤x≤1,0≤y≤1} 的面积

```
A = ∬_D 1 dA = 1·1 = 1
```

**例 4**：判断 x²+y²−4x=0 曲线类型

```
(x−2)²+y²=4 ⇒ 圆，圆心 (2,0)，半径 2
```

## 五、练习（附答案）

1. 求点 (1,2,3) 到原点的距离

> 答案：√14。√(1²+2²+3²)=√14。

2. 求过点 (1,0,0)、法向量 (1,2,3) 的平面方程

> 答案：x+2y+3z−1=0。点法式 (x−1)+2y+3z=0。

3. 求 f(x,y)=x²y 的偏导数

> 答案：∂f/∂x=2xy，∂f/∂y=x²。

4. 求 D={0≤x≤1, 0≤y≤1} 上 ∬ xy dA

> 答案：1/4。累次积分 ∫₀¹x dx · ∫₀¹y dy = (1/2)(1/2)=1/4。

5. 判断 x²+y²−4x=0 是什么曲线并求圆心

> 答案：圆，圆心 (2,0)，半径 2。

6. 判断 x²/a²+y²/b²−z²/c²=1 是什么曲面

> 答案：单叶双曲面。
