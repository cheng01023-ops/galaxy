## 一、空间解析几何基础

### 1.1 空间直角坐标

点 P(x,y,z)，到原点距离：

```
d = √(x²+y²+z²)
```

两点 P₁(x₁,y₁,z₁)、P₂(x₂,y₂,z₂) 距离：

```
d = √[(x₂−x₁)² + (y₂−y₁)² + (z₂−z₁)²]
```

### 1.2 向量运算

- 加法/减法：对应分量相加/相减
- 数乘：k·a = (ka₁,ka₂,ka₃)
- 模：|a| = √(a₁²+a₂²+a₃²)
- 单位向量：a/|a|，方向与 a 相同、长度为 1
- 方向余弦：cosα=a₁/|a|、cosβ=a₂/|a|、cosγ=a₃/|a|，且 cos²α+cos²β+cos²γ=1

**点积**：

```
a·b = a₁b₁+a₂b₂+a₃b₃ = |a||b|cosθ
a⊥b ⇔ a·b=0
```

- 投影：b 在 a 上的投影 = (a·b)/|a|

**叉积**：a×b 垂直于 a、b，方向满足右手定则：

```
|a×b| = |a||b|sinθ（等于以 a、b 为邻边的平行四边形面积）
a×b = (a₂b₃−a₃b₂, a₃b₁−a₁b₃, a₁b₂−a₂b₁)
a∥b ⇔ a×b = 0
```

**混合积**（了解）：(a×b)·c 的绝对值等于以 a、b、c 为棱的平行六面体体积；为零 ⇔ 三向量共面。

### 1.3 平面方程

- 点法式：n·(r−r₀)=0，展开为 Ax+By+Cz+D=0
- 法向量 n=(A,B,C) 垂直于平面
- 三点确定一个平面（取两个向量做叉积得法向量）
- 截距式：x/a + y/b + z/c = 1

**例**：过点 (1,0,0)、法向量 (1,2,3)

```
1(x−1)+2(y−0)+3(z−0)=0 ⇒ x+2y+3z−1=0
```

**点到平面距离**：点 P₀(x₀,y₀,z₀) 到平面 Ax+By+Cz+D=0 的距离：

```
d = |Ax₀+By₀+Cz₀+D| / √(A²+B²+C²)
```

**例**：点 (1,1,1) 到平面 x+2y+3z−1=0 的距离：

```
d = |1+2+3−1|/√(1+4+9) = 5/√14
```

**两平面夹角**：等于它们法向量夹角的锐角（或直角），cosθ = |n₁·n₂|/(|n₁||n₂|)。平行 ⇔ 法向量成比例；垂直 ⇔ 法向量点积为 0。

### 1.4 直线方程

- **参数式**：r = r₀ + t·d，即 x=x₀+at, y=y₀+bt, z=z₀+ct
- **对称式（点向式）**：(x−x₀)/a = (y−y₀)/b = (z−z₀)/c
- **两点式**：过 P₁、P₂，方向向量 d = P₂−P₁
- 方向向量 d 决定直线方向

**例**：过点 (1,2,3)、方向 (1,−1,2) 的直线

```
参数式：x=1+t, y=2−t, z=3+2t
对称式：(x−1)/1 = (y−2)/(−1) = (z−3)/2
```

**直线与平面关系**：直线方向 d 与平面法向量 n：
- 直线在平面内或平行：d·n=0
- 垂直：d∥n

**两直线夹角**：取方向向量 d₁、d₂，cosθ=|d₁·d₂|/(|d₁||d₂|)。平行 ⇔ d₁×d₂=0；垂直 ⇔ d₁·d₂=0。

## 二、多元函数与偏导数

### 2.1 多元函数

z=f(x,y) 是二元函数，定义域是平面上的区域。例：z=√(1−x²−y²) 定义域为圆盘 x²+y²≤1。

### 2.2 偏导数

- ∂f/∂x：把 y 固定，对 x 求导
- ∂f/∂y：把 x 固定，对 y 求导

**例**：f(x,y)=x²y

```
∂f/∂x = 2xy
∂f/∂y = x²
```

**二阶偏导**：f_xx、f_yy、f_xy、f_yx。**混合偏导相等定理**：若二阶混合偏导连续，则 f_xy = f_yx（求导顺序可交换）。

**例**：f(x,y)=x²y + eˣ·sin y

```
f_xx = 2y + eˣ sin y
f_xy = 2x + eˣ cos y
f_yx = 2x + eˣ cos y  （与 f_xy 相同 ✓）
```

### 2.3 全微分

若 Δz = AΔx + BΔy + o(ρ)（ρ=√(Δx²+Δy²)），则 z 可微：

```
dz = (∂f/∂x)dx + (∂f/∂y)dy = f_x dx + f_y dy
```

- 可微 ⇒ 连续、偏导存在；偏导连续 ⇒ 可微（充分条件）。
- 用于近似：Δz ≈ dz。

### 2.4 复合函数链式法则

z=f(u,v)，u=u(x,y)，v=v(x,y)：

```
∂z/∂x = (∂f/∂u)(∂u/∂x) + (∂f/∂v)(∂v/∂x)
∂z/∂y = (∂f/∂u)(∂u/∂y) + (∂f/∂v)(∂v/∂y)
```

口诀：**对每个中间变量求偏导再乘它对自变量的偏导，最后相加**。

**例**：z=e^{u}·sin v，u=xy，v=x+y

```
∂z/∂x = eᵘ sin v · y + eᵘ cos v · 1 = e^{xy}[y·sin(x+y) + cos(x+y)]
```

### 2.5 隐函数偏导

F(x,y,z)=0 确定 z=z(x,y)：

```
∂z/∂x = −F_x/F_z，∂z/∂y = −F_y/F_z
```

**例**：x²+y²+z²=1 求 ∂z/∂x

```
F=x²+y²+z²−1，F_x=2x，F_z=2z
∂z/∂x = −2x/(2z) = −x/z
```

### 2.6 方向导数与梯度

函数 f(x,y) 沿单位方向 e=(cosα, cosβ) 的方向导数：

```
∂f/∂e = (∂f/∂x)cosα + (∂f/∂y)cosβ
```

**梯度**：

```
∇f = (∂f/∂x, ∂f/∂y)
```

梯度指向函数增长最快的方向，其模长就是最大方向导数：

```
∂f/∂e = ∇f · e = |∇f|·cosθ ≤ |∇f|
```

- θ=0（沿梯度方向）时方向导数最大，等于 |∇f|
- θ=π（逆梯度方向）时减小最快
- 垂直于梯度方向（沿等值线）方向导数为 0

**例**：f(x,y)=x²y 在点 (1,2) 处沿方向 (1,1)/√2 的方向导数。

```
∇f=(2xy, x²)，在 (1,2) 处 ∇f=(4,1)
∂f/∂e = (4,1)·(1/√2, 1/√2) = 5/√2
```

## 三、多元函数的极值

### 3.1 无条件极值（AC−B² 判别）

求 f(x,y) 的极值步骤：
1. 解方程组 f_x=0、f_y=0 得驻点。
2. 对每个驻点计算 A=f_xx、B=f_xy、C=f_yy：
   - AC−B²>0 且 A<0 ⇒ 极大
   - AC−B²>0 且 A>0 ⇒ 极小
   - AC−B²<0 ⇒ 不是极值（鞍点）
   - AC−B²=0 ⇒ 无法判断，需另法

**例**：求 f(x,y)=x²+y²−2x−4y 的极值。

```
f_x=2x−2=0 ⇒ x=1；f_y=2y−4=0 ⇒ y=2。驻点 (1,2)。
A=2, B=0, C=2 ⇒ AC−B²=4>0 且 A>0 ⇒ 极小。
极小值 f(1,2)=1+4−2−8=−5。
```

### 3.2 条件极值（拉格朗日乘数法）

求 f(x,y) 在约束 g(x,y)=0 下的极值：

```
构造 L(x,y,λ) = f(x,y) + λ·g(x,y)
解方程组：L_x=0, L_y=0, L_λ=0（即 g=0）
```

**例**：求 x+y=4 时 xy 的最大值。

```
L = xy + λ(x+y−4)
L_x = y+λ=0，L_y = x+λ=0 ⇒ x=y
x+y=4 ⇒ x=y=2，最大值 xy=4。
```

> 💡 应用：经济学效用最大化、给定周长求最大面积、材料最省问题等。

## 四、二重积分

### 4.1 定义

```
∬_D f(x,y) dA = lim Σ f(ξᵢ,ηᵢ)Δσᵢ
```

- 几何意义：f≥0 时是曲面 z=f(x,y) 下方、区域 D 上方的体积。
- ∬_D 1 dA = D 的面积。

### 4.2 直角坐标下的计算（累次积分）

区域 D = {(x,y) | a≤x≤b, g₁(x)≤y≤g₂(x)}（X 型）：

```
∬_D f dA = ∫_a^b [∫_{g₁(x)}^{g₂(x)} f(x,y) dy] dx
```

区域 D = {(x,y) | c≤y≤d, h₁(y)≤x≤h₂(y)}（Y 型）：

```
∬_D f dA = ∫_c^d [∫_{h₁(y)}^{h₂(y)} f(x,y) dx] dy
```

**例**：D 是 0≤x≤1、0≤y≤1，求 ∬_D xy dA

```
= ∫_0^1 [∫_0^1 xy dy] dx = ∫_0^1 x·(1/2) dx = 1/4
```

> 💡 换序技巧：某些积分先算其中一个方向很困难，换个方向就简单。关键是画出区域，确定上下限的依赖关系。

**例**（换序）：∬_D f 其中 D 由 y=x、y=x² 围成。

```
X 型：∫_0^1 ∫_{x²}^{x} f dy dx
Y 型：∫_0^1 ∫_{y}^{√y} f dx dy（两种写法等价，选好算的）
```

### 4.3 极坐标下的二重积分

x=r cosθ, y=r sinθ，dA = r dr dθ（**多一个因子 r**，别忘！）：

```
∬_D f(x,y) dxdy = ∬ f(r cosθ, r sinθ)·r dr dθ
```

适合圆域、扇形、含 x²+y² 的被积函数。

**例**：D 为 x²+y²≤1，求 ∬_D (x²+y²) dA

```
极坐标：0≤r≤1, 0≤θ≤2π
= ∫_0^{2π} ∫_0^1 r²·r dr dθ = 2π·[r⁴/4]_0^1 = π/2
```

**例**：D 为 x²+y²≤R² 的面积（圆面积公式验证）

```
∬_D 1 dA = ∫_0^{2π} ∫_0^R r dr dθ = 2π·(R²/2) = πR² ✓
```

### 4.4 应用

- 区域面积：A = ∬_D 1 dA
- 曲面下体积：V = ∬_D f(x,y) dA
- 平均值：f̄ = (1/A)·∬_D f dA
- 平面薄片质心（了解）：x̄ = (1/A)∬_D x dA，ȳ = (1/A)∬_D y dA

## 五、三重积分（了解）

```
∭_Ω f(x,y,z) dV
```

**直角坐标**：∭ = ∫∫∫ f dz dy dx（先定 z 的上下限，再投影到 xy 平面）。

**柱坐标**（适合绕 z 轴旋转体）：

```
x=r cosθ, y=r sinθ, z=z，dV = r dr dθ dz
```

**球坐标**（适合球体）：

```
x=ρ sinφ cosθ, y=ρ sinφ sinθ, z=ρ cosφ，dV = ρ² sinφ dρ dφ dθ
```

**例**：求半径为 R 的球体积。

```
球坐标：0≤ρ≤R, 0≤φ≤π, 0≤θ≤2π
V = ∫_0^{2π}∫_0^π∫_0^R ρ² sinφ dρ dφ dθ
  = 2π·[ρ³/3]_0^R·[−cosφ]_0^π = 2π·(R³/3)·2 = 4πR³/3 ✓
```

## 六、曲线积分与曲面积分（简介）

### 6.1 第一类曲线积分（对弧长）

```
∫_L f(x,y) ds = ∫_a^b f(x(t), y(t))·√(x'²+y'²) dt
```

物理意义：曲线质量、弧长（f=1 时）。

### 6.2 第二类曲线积分（对坐标，变力做功）

```
∫_L P dx + Q dy = ∫_a^b [P·x'(t) + Q·y'(t)] dt
```

物理意义：力场沿曲线做的功。

### 6.3 格林公式（平面，联系二重积分与曲线积分）

```
∮_L P dx + Q dy = ∬_D (∂Q/∂x − ∂P/∂y) dxdy
```

### 6.4 曲面积分与高斯、斯托克斯公式（了解名称与意义）

- **高斯公式**：∯_S F·n dS = ∭_Ω div F dV（通量 = 散度的体积分）
- **斯托克斯公式**：∮_L F·dr = ∬_S (curl F)·n dS（环量 = 旋度的面积分）
- **散度** div F = ∂P/∂x + ∂Q/∂y + ∂R/∂z，衡量"源"的强弱
- **旋度** curl F 衡量旋转强度

> 💡 这些是多元微积分（"场论"）的高潮，本课先建立印象：**高斯管"通量"、斯托克斯管"环量"、格林是斯托克斯在平面上的特例**。

## 七、线性变换与二次曲线曲面

### 7.1 线性变换

矩阵 A 把向量 x 映为 Ax，满足：

```
A(x+y) = Ax + Ay
A(cx) = cAx
```

- 旋转、缩放、反射、投影都是线性变换
- 特征值/特征向量：Av = λv（变换后方向不变、长度伸缩 λ 倍）
- 特征方程：|A − λI| = 0

**例**：A 是 90° 旋转矩阵 [[0,−1],[1,0]]

```
A(1,0) = (0,1)，A(0,1) = (−1,0)，确实是逆时针 90° 旋转。
```

### 7.2 二次曲线（标准式）

| 曲线 | 标准方程 | 参数 |
|---|---|---|
| 圆 | x²+y²=R² | 圆心原点，半径 R |
| 椭圆 | x²/a²+y²/b²=1 | a 长半轴，b 短半轴，c²=a²−b² |
| 双曲线 | x²/a²−y²/b²=1 | 渐近线 y=±(b/a)x |
| 抛物线 | y²=2px | 焦点 (p/2,0)，准线 x=−p/2 |

一般式 Ax²+Bxy+Cy²+Dx+Ey+F=0 通过配方与旋转判别类型。

**判别方法（了解）**：看 B²−4AC——小于 0 椭圆型、等于 0 抛物型、大于 0 双曲型。

**例**：x²+y²−4x=0

```
配方：(x−2)²+y²=4 ⇒ 圆心 (2,0)，半径 2 的圆
```

**例**：x²−4y²=4

```
两边除 4：x²/4 − y² = 1 ⇒ 双曲线，a=2，b=1，渐近线 y=±x/2。
```

### 7.3 二次曲面

| 曲面 | 标准方程 | 特征 |
|---|---|---|
| 球面 | x²+y²+z²=R² | 圆心原点半径 R |
| 椭球面 | x²/a²+y²/b²+z²/c²=1 | 三个半轴 |
| 椭圆抛物面 | z = x²/a² + y²/b² | 开口向上，碗状 |
| 双曲抛物面 | z = x²/a² − y²/b² | 马鞍形（鞍点） |
| 圆锥面 | z² = x²+y² | 顶点原点 |
| 单叶双曲面 | x²/a²+y²/b²−z²/c²=1 | 上下开口 |
| 双叶双曲面 | x²/a²−y²/b²−z²/c²=1 | 左右两叶 |

> 💡 记忆口诀：**等式右边为 1 的是"双曲面/椭球"，z 单独在一边的是"抛物面"；中间夹负号的是双曲型（马鞍/双叶）**。

## 九、练习（10 道，附答案与解析）

1. 求点 (1,2,3) 到原点的距离

> 答案：√14。√(1²+2²+3²)=√14。

2. 求过点 (1,0,0)、法向量 (1,2,3) 的平面方程

> 答案：x+2y+3z−1=0。点法式 (x−1)+2y+3z=0。

3. 求 f(x,y)=x²y 的偏导数

> 答案：∂f/∂x=2xy，∂f/∂y=x²。

4. 求 D={0≤x≤1, 0≤y≤1} 上 ∬ xy dA

> 答案：1/4。累次积分 ∫₀¹x dx · ∫₀¹y dy = (1/2)(1/2)=1/4。

5. 判断 x²+y²−4x=0 是什么曲线并求圆心

> 答案：圆，圆心 (2,0)，半径 2。

6. 判断 x²/a²+y²/b²−z²/c²=1 是什么曲面

> 答案：单叶双曲面。

7. 求 f(x,y)=x²y+3x 在 (1,2) 处的梯度

> 答案：∇f=(2xy+3, x²)，代入得 (7,1)。

8. 求 f(x,y)=x²+y² 在 (1,1) 处沿方向 (1,0) 的方向导数

> 答案：2。∇f=(2x,2y)=(2,2)，∂f/∂e=(2,2)·(1,0)=2（即沿 x 轴正向就是 f_x）。

9. 求半径为 2 的圆盘面积（用二重积分）

> 答案：4π。极坐标 ∫₀^{2π}∫₀² r dr dθ = 2π·2 = 4π。

10. 求 f(x,y)=xy 在约束 x+y=2 下的最大值

> 答案：1。拉格朗日得 x=y=1，xy=1。
