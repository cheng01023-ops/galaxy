# 微积分五天课（完整学习方案）

> 用 5 天系统学完大学微积分核心内容：从极限、导数、积分到微分方程与多元微积分。**先理解概念，再抄公式推导，最后独立完成练习。**

## 课程目标

5 天学完微积分核心，覆盖：

- 数理学习预备基础（数集、函数、初等函数）
- 微积分背景与历史（穷竭法 → 无穷小 → ε-δ）
- 数列极限与函数极限、连续性与间断点
- 函数的导数、微分、中值定理与泰勒公式
- 导数的应用（单调性、极值、凹凸、最值、洛必达）
- 一元积分学（不定积分、换元、分部、定积分、反常积分）
- 定积分的应用（面积、体积、弧长、平均值）
- 微分方程初步（可分离、一阶线性、二阶常系数）
- 微积分概念澄清与常见错误
- 空间解析几何基础（向量、平面、直线）
- 多元函数的微分学（偏导、全微分、梯度、极值）
- 多元函数的积分学（二重、三重积分）
- 曲线曲面积分与场论简介
- 线性变换与二次曲线、曲面

## 学习方法（三遍法）

1. **概念先行**：先回答"它是什么、为什么"再做题，不要一上来就背公式。
2. **推导优先**：每个公式至少自己推一遍（如两个重要极限、分部积分公式），记忆更牢。
3. **三遍法**：听课/读讲义 → 抄例题 → 独立重做（合上答案）。
4. **错误分析**：错题至少重做一遍，并写明错因（公式记错？方法选错？计算失误？）。
5. **打卡检验**：每天学完对照"打卡清单"逐项自评，完成一项勾一项。

## 每天的标准流程

1. 通读当天讲义（约 40～60 分钟），划出不懂的地方
2. 把讲义中的公式与例题抄一遍（约 60 分钟）
3. 独立完成讲义末尾的练习（约 60 分钟），再对照答案批改
4. 重做错题，并把易错点抄进自己的错题本（约 30 分钟）
5. 用"微积分速查"表做 5 分钟回顾，勾选打卡清单

## 配套工具

- **微积分速查**：公式表汇总，随时回来查。
- **打卡进度**：每天顶部清单可勾选，进度自动保存。

## 常见问题

- **学完需要多少数学基础？** 只需要高中函数基础。第 1 天会系统复习预备知识。
- **公式太多记不住怎么办？** 先记"主干公式"（导数表、积分表、两个重要极限），其余靠推导。每天用速查表回顾 5 分钟。
- **练习做不对怎么办？** 对照答案找错因，重做一遍；连续卡住就回到对应章节的例题精讲。
- **5 天学得完吗？** 能学完"核心"。深入掌握还需后续反复练习与应用，本课为你建立完整框架。
