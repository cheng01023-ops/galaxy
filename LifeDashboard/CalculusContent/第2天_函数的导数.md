## 一、导数定义

### 1.1 从平均变化率到瞬时变化率

```
平均变化率 = [f(x₀+h) − f(x₀)] / h

导数 = lim_{h→0} [f(x₀+h) − f(x₀)] / h
```

记法：f'(x₀)、y'、dy/dx、df/dx。

### 1.2 几何意义

f'(x₀) 是曲线 y=f(x) 在点 (x₀, f(x₀)) 处**切线的斜率**。
切线方程：

```
y − f(x₀) = f'(x₀)(x − x₀)
```

### 1.3 物理意义

- s(t) 位移 → v(t)=s'(t) 速度 → a(t)=v'(t) 加速度
- 导数 = 瞬时变化率

### 1.4 可导与连续

**定理**：f 在 x₀ 可导 ⇒ f 在 x₀ 连续。
反过来不成立：y=|x| 在 x=0 连续但不可导（左右导数不同）。

## 三、求导法则

### 3.1 四则运算

```
(u±v)' = u' ± v'
(uv)' = u'v + uv'
(u/v)' = (u'v − uv')/v²
(cu)' = c·u'
```

**例**：(x³·sin x)' = 3x²·sin x + x³·cos x

### 3.2 链式法则

y = f(g(x))：

```
y' = f'(g(x))·g'(x)
```

**例**：y = (3x+1)⁵

```
y' = 5(3x+1)⁴·3 = 15(3x+1)⁴
```

口诀：**外层求导 × 内层求导**。

### 3.3 隐函数求导

方程 F(x,y)=0 确定 y=y(x)，两边对 x 求导，把 y 当 x 的函数，再解出 y'。

**例**：x²+y²=25

```
2x + 2y·y' = 0  ⇒  y' = −x/y
```

### 3.4 对数求导法

对 y=f(x)^g(x) 类型：两边取 ln 再求导。

**例**：y = xˣ

```
ln y = x·ln x
y'/y = ln x + 1
y' = xˣ·(ln x + 1)
```

### 3.5 高阶导数

f''(x)、f'''(x)… 依次求导。

- f'' 表示加速度/凹凸性
- 常用记号：d²y/dx²

## 四、导数的应用

### 4.1 单调性

- f'>0 ⇒ f 递增
- f'<0 ⇒ f 递减
- f'=0 的点称为驻点，需判断两侧符号

### 4.2 极值判定

- **第一充分条件**：f' 在 x₀ 两侧变号（正→负极大；负→正极小）
- **第二充分条件**：f'(x₀)=0 且 f''(x₀)>0 ⇒ 极小；f''(x₀)<0 ⇒ 极大

### 4.3 凹凸与拐点

- f''>0 ⇒ 凹向上（下凸）
- f''<0 ⇒ 凹向下（上凸）
- 凹凸性改变的点叫拐点（需 f''=0 或不存在且两侧变号）

### 4.4 最值步骤

1. 求定义域内驻点与不可导点
2. 计算这些点的函数值
3. 与区间端点值比较

### 4.5 洛必达法则

0/0 或 ∞/∞ 型：

```
lim f/g = lim f'/g'（满足条件时可反复使用）
```

## 五、例题精讲

**例 1**：用定义求 f(x)=x² 的导数

```
f'(x) = lim_{h→0} [(x+h)²−x²]/h
      = lim [2xh+h²]/h = 2x
```

**例 2**：求 y = e^{2x}·sin x 的导数

```
y' = (e^{2x})'·sin x + e^{2x}·(sin x)'
   = 2e^{2x}·sin x + e^{2x}·cos x
   = e^{2x}(2sin x + cos x)
```

**例 3**：求 y = ln(x²+1) 的导数

```
y' = 1/(x²+1) · 2x = 2x/(x²+1)
```

**例 4**：求 y = x·cos x 的导数

```
y' = 1·cos x + x·(−sin x) = cos x − x·sin x
```

## 六、练习（附答案）

1. 求 f(x)=3x⁴−2x²+1 的导数

> 答案：f'(x)=12x³−4x。逐项求导：3·4x³ − 2·2x = 12x³−4x。

2. 求 y=ln(x²+1) 的导数

> 答案：y'=2x/(x²+1)。链式法则：1/(x²+1)·2x。

3. 求 y=eˣ·cos x 的导数

> 答案：y'=eˣ(cos x − sin x)。乘积法则：eˣ·cos x + eˣ·(−sin x)。

4. 求 y=sin²x 的导数

> 答案：y'=2sin x·cos x = sin 2x。链式：2sin x·cos x。

5. 求 y = (x²+1)/(x−1) 的导数

> 答案：y' = [2x(x−1) − (x²+1)·1]/(x−1)² = (x²−2x−1)/(x−1)²。

6. 求 f(x)=x³−3x 的单调区间与极值

> 答案：f'=3x²−3=3(x−1)(x+1)。x<−1 时 f'>0 递增；−1<x<1 时 f'<0 递减；x>1 时 f'>0 递增。x=−1 处极大 f(−1)=2，x=1 处极小 f(1)=−2。
