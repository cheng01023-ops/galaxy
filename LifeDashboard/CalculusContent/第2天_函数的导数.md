## 一、导数定义

### 1.1 从平均变化率到瞬时变化率

```
平均变化率 = [f(x₀+h) − f(x₀)] / h

导数 = lim_{h→0} [f(x₀+h) − f(x₀)] / h
```

记法：f'(x₀)、y'、dy/dx、df/dx。

> 💡 物理直觉：汽车从 A 到 B 的平均速度容易算；但"某一瞬间"的速度表读数就是瞬时速度，即位移对时间的导数。

### 1.2 几何意义

f'(x₀) 是曲线 y=f(x) 在点 (x₀, f(x₀)) 处**切线的斜率**。切线方程：

```
y − f(x₀) = f'(x₀)(x − x₀)
```

法线（与切线垂直）方程：

```
y − f(x₀) = −1/f'(x₀) · (x − x₀)   （f'(x₀)≠0 时）
```

例：求 y=x² 在 (1,1) 处的切线方程。

```
f'(x)=2x，f'(1)=2，切线：y−1=2(x−1)，即 y=2x−1。
```

### 1.3 物理意义

- s(t) 位移 → v(t)=s'(t) 速度 → a(t)=v'(t) 加速度
- 导数 = 瞬时变化率

### 1.4 可导与连续

**定理**：f 在 x₀ 可导 ⇒ f 在 x₀ 连续。
反过来不成立：y=|x| 在 x=0 连续但不可导（左右导数不同）。

```
左导数 = lim_{h→0⁻} |h|/h = −1
右导数 = lim_{h→0⁺} |h|/h = +1
左右导数不相等 ⇒ 不可导（图像上是"尖点"）
```

其他不可导的情形：切线垂直于 x 轴（如 y=x^{1/3} 在 x=0）、图像有角点、振荡（如 x·sin(1/x) 附近）。

## 二、基本导数表（务必背熟）

| f(x) | f'(x) |
|---|---|
| C | 0 |
| xⁿ | n·xⁿ⁻¹ |
| eˣ | eˣ |
| aˣ | aˣ·ln a |
| ln x | 1/x |

| sin x | cos x |
| cos x | −sin x |

| csc x | −csc x·cot x |

> - 反三角成对出现，arcsin/arccos 差负号，arctan/arccot 差负号。

## 三、求导法则

### 3.1 四则运算

```
(u±v)' = u' ± v'
(uv)' = u'v + uv'
(u/v)' = (u'v − uv')/v²
(cu)' = c·u'
```

**例**：(x³·sin x)' = 3x²·sin x + x³·cos x

### 3.2 链式法则

y = f(g(x))：

```
y' = f'(g(x))·g'(x)
```

**例**：y = (3x+1)⁵

```
y' = 5(3x+1)⁴·3 = 15(3x+1)⁴
```

口诀：**外层求导 × 内层求导**。可以"剥洋葱"一层层剥：sin²(2x) 先平方、再 sin、再 2x，共乘三段。

### 3.3 隐函数求导

方程 F(x,y)=0 确定 y=y(x)，两边对 x 求导，把 y 当 x 的函数，再解出 y'。

**例**：x²+y²=25

```
2x + 2y·y' = 0  ⇒  y' = −x/y
```

**例**（求隐函数二阶导）：由 x²+y²=25，已得 y'=−x/y，继续求导：

```
y'' = −(y − x·y')/y² = −(y − x·(−x/y))/y² = −(y + x²/y)/y²
    = −(y² + x²)/y³ = −25/y³
```

### 3.4 对数求导法

对 y=f(x)^g(x) 类型：两边取 ln 再求导。

**例**：y = xˣ

```
ln y = x·ln x
y'/y = ln x + 1
y' = xˣ·(ln x + 1)
```

**例**：y = (x²+1)³·√(x−1)/(x+2)²（连乘除，取对数化乘为加）

```
ln y = 3ln(x²+1) + (1/2)ln(x−1) − 2ln(x+2)
y'/y = 6x/(x²+1) + 1/[2(x−1)] − 2/(x+2)
y' = y·[6x/(x²+1) + 1/(2(x−1)) − 2/(x+2)]
```

> 💡 适用场景：幂指函数 xˣ、(sin x)^cos x，以及多个因式连乘除的式子。

### 3.5 参数方程求导

若 x=x(t)、y=y(t)，则：

```
dy/dx = (dy/dt)/(dx/dt) = y'(t)/x'(t)   （要求 x'(t)≠0）
```

**例**：x=t², y=t³

```
dy/dx = 3t²/(2t) = (3/2)t
```

二阶导：

```
d²y/dx² = d(dy/dx)/dx = [d(dy/dx)/dt] / (dx/dt)
```

**例**（继续）：dy/dx=(3/2)t，则 d²y/dx² = (3/2)/(2t) = 3/(4t)。

### 3.6 高阶导数

f''(x)、f'''(x)… 依次求导。

- f'' 表示加速度/凹凸性
- 常用记号：d²y/dx²、dⁿy/dxⁿ

**常用 n 阶导数公式**：

```
(eˣ)^{(n)} = eˣ
(aˣ)^{(n)} = aˣ·(ln a)ⁿ
(sin x)^{(n)} = sin(x + nπ/2)
(cos x)^{(n)} = cos(x + nπ/2)
[1/(ax+b)]^{(n)} = (−1)ⁿ·n!·aⁿ/(ax+b)ⁿ⁺¹
(ln x)^{(n)} = (−1)ⁿ⁻¹·(n−1)!/xⁿ
```

**莱布尼茨公式**（乘积的高阶导数，类似二项式展开）：

```
(uv)^{(n)} = Σ_{k=0}^{n} C(n,k)·u^{(k)}·v^{(n−k)}
```

**例**：求 y=x²·eˣ 的 20 阶导数。

```
令 u=x²，v=eˣ。u 的三阶及以上导数为 0，所以：
y^{(20)} = C(20,0)·x²·eˣ + C(20,1)·2x·eˣ + C(20,2)·2·eˣ
        = eˣ(x² + 40x + 380)
```

## 四、微分

### 4.1 定义

若函数增量 Δy=f(x₀+Δx)−f(x₀) 可写成：

```
Δy = A·Δx + o(Δx)
```

则称 y=f(x) 在 x₀ 可微，A·Δx 叫函数在 x₀ 的微分，记 dy = A·Δx。且 A = f'(x₀)。

**结论：可微 ⇔ 可导，且 dy = f'(x₀)dx。**

```
Δy ≈ dy = f'(x₀)·Δx    （当 Δx 很小时）
```

### 4.2 几何意义

微分 dy 是切线在 Δx 处的纵坐标增量，而 Δy 是曲线本身的增量。Δx 越小，dy 越接近 Δy。

### 4.3 用微分做近似计算

```
f(x₀ + Δx) ≈ f(x₀) + f'(x₀)·Δx
```

**例**：求 √4.02 的近似值。

```
取 f(x)=√x，x₀=4，Δx=0.02。
f(4)=2，f'(4)=1/(2√4)=1/4=0.25。
√4.02 ≈ 2 + 0.25×0.02 = 2.005。
```

**例**：求 e^{0.01} 的近似值。

```
f(x)=eˣ，x₀=0，Δx=0.01。f(0)=1，f'(0)=1。
e^{0.01} ≈ 1 + 1×0.01 = 1.01。
```

常用近似公式（x 很小时）：√(1+x)≈1+x/2、eˣ≈1+x、ln(1+x)≈x、sin x≈x。

## 五、微分中值定理

### 5.1 罗尔定理

若 f(x) 在 [a,b] 连续、在 (a,b) 可导，且 f(a)=f(b)，则至少存在 ξ∈(a,b)，使 f'(ξ)=0。

> 几何意义：两端点同高时，中间至少有一条水平切线。

**例**：验证 f(x)=x²−2x 在 [0,2] 上满足罗尔定理，并求 ξ。

```
f(0)=0，f(2)=0，连续可导。f'(x)=2x−2=0 ⇒ x=1∈(0,2)。ξ=1。✓
```

### 5.2 拉格朗日中值定理

若 f(x) 在 [a,b] 连续、在 (a,b) 可导，则至少存在 ξ∈(a,b)，使：

```
f(b) − f(a) = f'(ξ)·(b − a)
```

> 几何意义：曲线上至少有一点切线平行于两端点的连线。
> 推论 1：若 f'(x)≡0，则 f(x) 为常数。
> 推论 2：若 f'(x)=g'(x)，则 f(x)−g(x) 为常数（两个函数只差一个常数）。

**例**：证明 |sin b − sin a| ≤ |b − a|。

```
由拉格朗日定理，sin b − sin a = cos ξ·(b − a)。
两边取绝对值：|sin b − sin a| = |cos ξ|·|b − a| ≤ |b − a|。✓
```

### 5.3 柯西中值定理

若 f、g 在 [a,b] 连续、在 (a,b) 可导，且 g'(x)≠0，则存在 ξ∈(a,b)：

```
[f(b) − f(a)] / [g(b) − g(a)] = f'(ξ) / g'(ξ)
```

它是洛必达法则与泰勒公式的理论基础。

## 六、泰勒公式（局部线性化的升级版）

### 6.1 带佩亚诺余项的麦克劳林公式

若 f 在 x=0 附近有 n+1 阶导数：

```
f(x) = f(0) + f'(0)x + f''(0)x²/2! + … + f^{(n)}(0)xⁿ/n! + o(xⁿ)
```

在 x=a 处的一般形式（泰勒公式）：

```
f(x) = f(a) + f'(a)(x−a) + f''(a)(x−a)²/2! + … + f^{(n)}(a)(x−a)ⁿ/n! + o((x−a)ⁿ)
```

### 6.2 常用麦克劳林展开（务必背熟，x→0）

```
eˣ = 1 + x + x²/2! + x³/3! + … + xⁿ/n! + …
sin x = x − x³/3! + x⁵/5! − x⁷/7! + …
cos x = 1 − x²/2! + x⁴/4! − x⁶/6! + …
ln(1+x) = x − x²/2 + x³/3 − x⁴/4 + …
1/(1−x) = 1 + x + x² + x³ + …（|x|<1）
(1+x)^α = 1 + αx + α(α−1)x²/2! + …
```

**例**：用泰勒展开求 lim_{x→0} (sin x − x)/x³。

```
sin x = x − x³/3! + o(x³)
(sin x − x)/x³ = (−x³/6 + o(x³))/x³ → −1/6
```

> 💡 这是第 1 天"等价无穷小不可用于加减"的完美解法：加减中要用泰勒展开的高阶项。

## 七、导数的应用

### 7.1 单调性

- f'>0 ⇒ f 递增
- f'<0 ⇒ f 递减
- f'=0 的点称为驻点，需判断两侧符号

**完整判断步骤**：求 f' → 找 f'=0 与 f' 不存在的点 → 用这些点划分区间 → 在每个区间内取一点判断 f' 符号。

### 7.2 极值判定

- **第一充分条件**：f' 在 x₀ 两侧变号（正→负极大；负→正极小；不变号则不是极值）
- **第二充分条件**：f'(x₀)=0 且 f''(x₀)>0 ⇒ 极小；f''(x₀)<0 ⇒ 极大；f''(x₀)=0 时无法判断，用第一充分条件

> ⚠️ 注意区分"极值"与"最值"：极值是局部的（邻域内最大/最小），最值是全局的。端点只可能是最值，不可能是极值。

### 7.3 凹凸与拐点

- f''>0 ⇒ 凹向上（下凸，图像像 ∪）
- f''<0 ⇒ 凹向下（上凸，图像像 ∩）
- 凹凸性改变的点叫拐点（需 f''=0 或不存在，且两侧 f'' 变号）

> 💡 记忆：f''>0 时切线斜率在增加，曲线"开口向上"。

### 7.4 最值步骤

1. 求定义域内驻点与不可导点
2. 计算这些点的函数值
3. 与区间端点值比较，最大者为最大值、最小者为最小值

**例**：求 f(x)=x³−3x 在 [0,2] 上的最值。

```
f'(x)=3x²−3=3(x−1)(x+1)，在 [0,2] 内驻点 x=1。
f(0)=0，f(1)=−2，f(2)=2。
最大值 2（x=2），最小值 −2（x=1）。
```

### 7.5 洛必达法则

0/0 或 ∞/∞ 型：

```
lim f/g = lim f'/g'（满足条件时可反复使用）
```

**使用条件**（三个都要满足）：
1. 极限是 0/0 或 ∞/∞ 型；
2. f、g 在去心邻域内可导且 g'≠0；
3. lim f'/g' 存在（或为无穷大）。

**例**：求 lim_{x→0} (eˣ−1−x)/x²。

```
0/0 型，洛必达：(eˣ−1)/(2x) 仍为 0/0，再洛必达：eˣ/2 → 1/2。
```

> ⚠️ 常见坑：
> - 不是 0/0 或 ∞/∞ 不能用（如 lim (1+cos x)/1 直接算）。
> - 洛必达失效时（如 lim_{x→∞} x/(x+sin x)，求导后极限振荡不存在），改用夹逼或同除。
> - 能先化简/等价无穷小的先化简，往往一步到位。

### 7.6 曲率（了解）

曲线 y=f(x) 在一点的弯曲程度用曲率 K 描述：

```
K = |y''| / (1 + y'²)^{3/2}
```

半径 R=1/K。直线 K=0；圆半径 R 的曲率 K=1/R。

## 八、例题精讲（12 道）

**例 1**：用定义求 f(x)=x² 的导数

```
f'(x) = lim_{h→0} [(x+h)²−x²]/h
      = lim [2xh+h²]/h = 2x
```

**例 2**：求 y = e^{2x}·sin x 的导数

```
y' = (e^{2x})'·sin x + e^{2x}·(sin x)'
   = 2e^{2x}·sin x + e^{2x}·cos x
   = e^{2x}(2sin x + cos x)
```

**例 3**：求 y = ln(x²+1) 的导数

```
y' = 1/(x²+1) · 2x = 2x/(x²+1)
```

**例 4**：求 y = x·cos x 的导数

```
y' = 1·cos x + x·(−sin x) = cos x − x·sin x
```

**例 5**：求 y = tan(x³) 的导数

```
y' = sec²(x³)·3x² = 3x²·sec²(x³)
```

**例 6**：求 y = xˣ 的导数

```
ln y = x ln x ⇒ y'/y = ln x + 1 ⇒ y' = xˣ(ln x + 1)
```

**例 7**：求由 x²+y²=25 确定的 y' 与 y''

```
2x+2yy'=0 ⇒ y'=−x/y；y''=−25/y³（见 3.3）。
```

**例 8**：求参数方程 x=cos t, y=sin t 的 dy/dx

```
dy/dx = (cos t)/(−sin t) = −cot t
```

**例 9**：求 y=x³−3x 的单调区间、极值、凹凸与拐点

```
f'=3(x−1)(x+1)：x<−1 增，−1<x<1 减，x>1 增。
极大 f(−1)=2，极小 f(1)=−2。
f''=6x：x<0 凹向下，x>0 凹向上，拐点 (0,0)。
```

**例 10**：求 lim_{x→0} (1−cos x)/x²

```
0/0 型，洛必达：sin x/(2x) → 1/2。
```

**例 11**：求 f(x)=x³−6x²+9x 的极值

```
f'=3x²−12x+9=3(x−1)(x−3)。x=1 极大 f(1)=4；x=3 极小 f(3)=0。
```

**例 12**：求 y=√x 在 x=4 处的切线方程

```
f'(x)=1/(2√x)，f'(4)=1/4，f(4)=2。
切线：y−2=(1/4)(x−4)，即 y=x/4+1。
```

## 九、练习（12 道，附答案与解析）

1. 求 f(x)=3x⁴−2x²+1 的导数

> 答案：f'(x)=12x³−4x。逐项求导：3·4x³ − 2·2x = 12x³−4x。

2. 求 y=ln(x²+1) 的导数

> 答案：y'=2x/(x²+1)。链式法则：1/(x²+1)·2x。

3. 求 y=eˣ·cos x 的导数

> 答案：y'=eˣ(cos x − sin x)。乘积法则：eˣ·cos x + eˣ·(−sin x)。

4. 求 y=sin²x 的导数

> 答案：y'=2sin x·cos x = sin 2x。链式：2sin x·cos x。

5. 求 y = (x²+1)/(x−1) 的导数

> 答案：y' = [2x(x−1) − (x²+1)·1]/(x−1)² = (x²−2x−1)/(x−1)²。

6. 求 f(x)=x³−3x 的单调区间与极值

> 答案：f'=3x²−3=3(x−1)(x+1)。x<−1 时 f'>0 递增；−1<x<1 时 f'<0 递减；x>1 时 f'>0 递增。x=−1 处极大 f(−1)=2，x=1 处极小 f(1)=−2。

7. 求 y = x·ln x 的导数

> 答案：y'=ln x + 1。乘积法则：1·ln x + x·(1/x)。

8. 求由方程 eʸ = x·y 确定的 y'

> 答案：两边对 x 求导：eʸ·y' = y + x·y'，解得 y' = y/(eʸ−x)。

9. 求 y = (sin x)^x 的导数

> 答案：ln y = x·ln(sin x)，y'/y = ln(sin x) + x·cot x，故 y' = (sin x)^x·[ln(sin x) + x·cot x]。

10. 求 y=x³−3x 在 [0,2] 上的最值

> 答案：驻点 x=1（在区间内）。f(0)=0，f(1)=−2，f(2)=2。最大值 2，最小值 −2。

11. 求 lim_{x→0} (eˣ−1−x)/x²

> 答案：1/2。两次洛必达：先得 (eˣ−1)/(2x)，再得 eˣ/2→1/2。

12. 求 f(x)=e^{−x}·sin x 的导数

> 答案：y'=e^{−x}(cos x − sin x)。乘积法则：e^{−x}·(−sin x) + (−e^{−x})·sin x = e^{−x}(cos x − sin x)。

## 十、易错点自查（今日重点）

- [ ] 链式法则漏乘内层导数（如把 e^{2x} 的导数写成 e^{2x}）
- [ ] 商法则分子顺序写反（是 u'v−uv'，不是 uv'−u'v）
- [ ] 隐函数求导时 y 忘记当复合函数（y² 的导数是 2y·y'）
- [ ] 极值只找 f'=0，漏不可导点与端点
- [ ] 洛必达前没验证 0/0 或 ∞/∞
