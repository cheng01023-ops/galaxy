## 一、导数定义

函数 y=f(x) 在 x₀ 的导数：

```
f'(x₀) = lim_{h→0} [f(x₀+h) - f(x₀)] / h
```

几何意义：曲线在 x₀ 处**切线的斜率**。
物理意义：瞬时变化率（如瞬时速度 v = s'(t)）。

例：f(x)=x²

```
f'(x) = lim_{h→0} [(x+h)² - x²]/h
      = lim_{h→0} [2xh + h²]/h = 2x
```

## 二、基本导数表

| f(x) | f'(x) |
|---|---|
| C（常数） | 0 |
| xⁿ | n·xⁿ⁻¹ |
| eˣ | eˣ |
| aˣ | aˣ·ln a |
| ln x | 1/x |
| sin x | cos x |
| cos x | -sin x |
| tan x | sec²x |

## 三、四则运算法则

```
(u+v)' = u' + v'
(u−v)' = u' − v'
(uv)'  = u'v + uv'
(u/v)' = (u'v − uv')/v²
```

例：(x³·sin x)' = 3x²·sin x + x³·cos x

## 四、链式法则（复合函数）

若 y = f(g(x))，则：

```
y' = f'(g(x)) · g'(x)
```

例：(sin 2x)' = cos 2x · 2 = 2cos 2x

口诀：**外层求导，内层再求导，乘起来。**

## 五、高阶导数

- 二阶导数 f''(x)：导数再求导，表示**凹凸性/加速度**
- f''>0 ⇒ 下凸（凹向上）
- f''<0 ⇒ 上凸（凹向下）

## 六、导数应用

1. 单调性：f'>0 ⇒ 递增；f'<0 ⇒ 递减
2. 极值：f'=0 且 f' 变号 ⇒ 极值点
3. 最值：比较极值与端点值
4. 切线方程：y − f(x₀) = f'(x₀)(x − x₀)

## 一、不定积分

若 F'(x) = f(x)，则称 F(x) 是 f(x) 的一个原函数。

```
∫ f(x) dx = F(x) + C
```

C 是任意常数，**千万别漏**。

## 二、基本积分表

| ∫ f(x) dx | 结果 |
|---|---|
| ∫ xⁿ dx | xⁿ⁺¹/(n+1) + C（n≠−1） |
| ∫ 1/x dx | ln|x| + C |
| ∫ eˣ dx | eˣ + C |
| ∫ sin x dx | −cos x + C |
| ∫ cos x dx | sin x + C |
| ∫ a dx | ax + C |

## 三、换元法

遇到复合结构，令 u=g(x)：

```
∫ f(g(x))·g'(x) dx = ∫ f(u) du
```

例：∫ 2x·e^(x²) dx，令 u=x²，du=2x dx ⇒ e^u + C = e^(x²)+C

## 四、分部积分法

```
∫ u dv = uv − ∫ v du
```

选择顺序口诀：**反对幂指三**（先选 u）。

例：∫ x·eˣ dx，取 u=x，dv=eˣdx ⇒ x·eˣ − ∫ eˣ dx = x·eˣ − eˣ + C

## 五、定积分

```
∫_a^b f(x) dx = F(b) − F(a)
```

（牛顿-莱布尼茨公式：先用不定积分求原函数，再代上下限相减）

几何意义：曲线 y=f(x) 与 x 轴在 [a,b] 上围成的（有向）面积。

## 六、定积分性质

```
∫_a^b c·f dx = c·∫_a^b f dx
∫_a^b (f+g) dx = ∫_a^b f dx + ∫_a^b g dx
∫_a^b f dx = −∫_b^a f dx
∫_a^b f dx = ∫_a^c f dx + ∫_c^b f dx
```

## 七、应用

- 面积：A = ∫_a^b [上曲线 − 下曲线] dx
- 旋转体体积：V = π∫_a^b [f(x)]² dx

## 八、练习

1. 求 ∫ (3x² − 2x + 1) dx
2. 求 ∫ sin(3x) dx
3. 求 ∫ x·cos x dx（分部积分）
4. 求 ∫_0^1 x² dx，并用几何意义验证
