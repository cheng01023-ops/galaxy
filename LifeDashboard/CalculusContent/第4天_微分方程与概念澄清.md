## 一、微分方程基本概念

含未知函数及其导数的方程叫微分方程。

- **阶**：最高阶导数的阶数
- **通解**：含任意常数的解（n 阶方程通解含 n 个任意常数）
- **特解**：由初值条件确定的解
- **初值问题**：方程 + 初值条件

例：

```
y' = 2x          → 一阶
y'' + y = 0      → 二阶
y(0) = 1         → 初值条件
```

**线性**：方程中未知函数及其各阶导数都是一次的（如 y'' + p(x)y' + q(x)y = f(x) 是二阶线性；y·y' 或 (y')² 出现则是非线性）。

**解的存在唯一性（了解）**：一阶方程 y'=f(x,y) 在初值点附近若 f 和 ∂f/∂y 连续，则初值问题存在唯一解。这保证了"有初值就有确定答案"。

## 二、可分离变量方程

形如 y' = f(x)·g(y)：

```
dy/g(y) = f(x) dx
∫ dy/g(y) = ∫ f(x) dx
```

步骤：分离 → 两边积分 → 解出 y（能显式就显式）。

**例**：y' = y

```
dy/y = dx
ln|y| = x + C
y = C·eˣ
```

> ⚠️ 注意：ln|y| = x + C 两边取指数时，C 是任意常数，通常直接写 y = C·eˣ（C 可正可负可零），不必纠结符号。

**例**：y' = x·y

```
dy/y = x dx
ln|y| = x²/2 + C
y = C·e^{x²/2}
```

**例**：y' = 2x·y²，y(1)=1

```
dy/y² = 2x dx ⇒ −1/y = x² + C ⇒ y = −1/(x²+C)
代入 y(1)=1：−1/(1+C)=1 ⇒ C=−2
特解：y = −1/(x²−2) = 1/(2−x²)
```

> 💡 分离变量法的关键：把 y 的表达式和 dy 放一边，x 和 dx 放另一边。含 ln 时结果常写成指数形式更简洁。

## 三、一阶线性微分方程

形如 y' + p(x)y = q(x)，积分因子 μ = e^{∫p dx}：

```
y = e^{−∫p dx}·[ ∫ q·e^{∫p dx} dx + C ]
```

**推导思路**：方程两边同乘 μ，左边恰好是 (y·μ)'：

```
(y·e^{∫p dx})' = q·e^{∫p dx}
两边积分再除以 e^{∫p dx} 即得通解公式。
```

**例**：y' + y = eˣ

```
p=1 ⇒ μ=eˣ
y = e^{−x}·[ ∫ eˣ·eˣ dx + C ]
  = e^{−x}·[ e^{2x}/2 + C ]
  = eˣ/2 + C·e^{−x}
```

**例**：y' + 2y = 4x（初值 y(0)=1）

```
p=2 ⇒ μ=e^{2x}
y = e^{−2x}·[ ∫ 4x·e^{2x} dx + C ]
∫ 4x·e^{2x} dx = 2x·e^{2x} − e^{2x}（分部）
y = e^{−2x}·(2x·e^{2x} − e^{2x} + C) = 2x − 1 + C·e^{−2x}
代入 y(0)=1：−1 + C = 1 ⇒ C=2
特解：y = 2x − 1 + 2e^{−2x}
```

> 💡 识别特征：y' 和 y 都是一次，且不出现 y·y'、y²、(y')² 等项。q(x)=0 时是齐次的，直接可分离变量。

## 四、伯努利方程（了解）

形如 y' + p(x)y = q(x)·yⁿ（n≠0,1）。令 z = y^{1−n}，化为 z 的一阶线性方程：

```
z' + (1−n)p(x)z = (1−n)q(x)
```

**例**：y' + y = y²（n=2）

```
令 z=y^{−1}，则 z' = −y^{−2}·y'，原式除以 y²：
y^{−2}·y' + y^{−1} = 1 ⇒ −z' + z = 1 ⇒ z' − z = −1
一阶线性：p=−1，μ=e^{−x}
z = e^{x}·[ ∫ −e^{−x} dx + C ] = e^{x}·(e^{−x} + C) = 1 + C·e^{x}
y = 1/(1 + C·e^{x})
```

## 五、全微分方程（了解）

若 P(x,y)dx + Q(x,y)dy = 0 且 ∂P/∂y = ∂Q/∂x，则它是某个函数 u(x,y) 的全微分，通解为 u(x,y)=C。

**例**：(2x+y)dx + (x+2y)dy = 0

```
∂P/∂y = 1，∂Q/∂x = 1，相等 ⇒ 全微分方程。
u = ∫(2x+y)dx = x² + xy + φ(y)
∂u/∂y = x + φ'(y) = x + 2y ⇒ φ'(y)=2y ⇒ φ(y)=y²
通解：x² + xy + y² = C
```

## 六、可降阶的高阶微分方程

### 6.1 y'' = f(x) 型：直接积分两次

**例**：y'' = 6x

```
y' = 3x² + C₁
y = x³ + C₁x + C₂
```

### 6.2 y'' = f(x, y') 型（不含 y）：令 p=y'

令 p=y'，则 y''=p'，方程化为 p' = f(x,p)（一阶），解出 p 再积分。

**例**：y'' − y' = x

```
令 p=y'，p' − p = x，一阶线性（p=−1，μ=e^{−x}）：
p = eˣ·[∫ x·e^{−x} dx + C₁] = −(x+1) + C₁eˣ
y = ∫ p dx = −x²/2 − x + C₁eˣ + C₂
```

### 6.3 y'' = f(y, y') 型（不含 x）：令 p=y'，把 y 当自变量

此时 y'' = p·dp/dy，方程化为 p·dp/dy = f(y,p)。

**例**：y·y'' = (y')²

```
令 p=y'，y'' = p·dp/dy：y·p·dp/dy = p²
p≠0 时：dp/p = dy/y ⇒ ln|p| = ln|y| + C₁ ⇒ p = C₁y
dy/dx = C₁y ⇒ y = C₂·e^{C₁x}
```

## 七、二阶常系数齐次方程

ay'' + by' + cy = 0，设 y=e^{λx}，得特征方程 aλ²+bλ+c=0：

| 判别式 | 通解 |
|---|---|
| 两不同实根 λ₁,λ₂ | C₁e^{λ₁x}+C₂e^{λ₂x} |
| 重根 λ | (C₁+C₂x)e^{λx} |
| 共轭复根 λ=α±βi | e^{αx}(C₁cosβx+C₂sinβx) |

**例**：y''+y=0

```
特征方程 λ²+1=0 ⇒ λ=±i（α=0, β=1）
y = C₁cos x + C₂sin x
```

**例**：y''−3y'+2y=0

```
λ²−3λ+2=0 ⇒ λ=1,2
y = C₁eˣ + C₂e^{2x}
```

**例**：y''−2y'+y=0

```
(λ−1)²=0 ⇒ 重根 λ=1
y = (C₁+C₂x)eˣ
```

> 💡 记忆：**两个不同实根直接写；重根补一个 x；复根前面乘 e^{αx}，后面配 cos/sin**。

## 八、二阶常系数非齐次方程（待定系数法）

ay'' + by' + cy = f(x)。通解 = 齐次通解 + 一个特解 y*。

特解形式由 f(x) 决定：

| f(x) 形式 | 特解假设 |
|---|---|
| Pₘ(x)（多项式） | y* = xᵏ·Qₘ(x)（k=0/1/2，按 0 是否为特征根） |
| e^{λx}·Pₘ(x) | y* = xᵏ·e^{λx}·Qₘ(x)（k=0/1/2，按 λ 是否为特征根的重数） |
| e^{λx}[A cos βx + B sin βx] | y* = xᵏ·e^{λx}(C cos βx + D sin βx) |

> 💡 k 的取法：λ（或 0）不是特征根取 0，是单根取 1，是重根取 2。

**例**：y'' + y = 2eˣ

```
齐次通解：C₁cos x + C₂sin x（λ=±i）。
λ=1 不是特征根，设 y*=Aeˣ。
代入：(Aeˣ)+(Aeˣ)=2Aeˣ=2eˣ ⇒ A=1。
通解：y = C₁cos x + C₂sin x + eˣ
```

**例**：y'' − 3y' + 2y = 2x

```
齐次通解：C₁eˣ+C₂e^{2x}。0 不是特征根，设 y*=Ax+B。
代入：0 − 3A + 2(Ax+B) = 2Ax + (2B−3A) = 2x
比较系数：2A=2 ⇒ A=1；2B−3=0 ⇒ B=3/2。
通解：y = C₁eˣ+C₂e^{2x} + x + 3/2
```

**例**：y'' + y = sin x

```
齐次通解：C₁cos x+C₂sin x。λ=i 是特征根（单根），设 y*=x(Acos x + Bsin x)。
代入（略）：A=−1/2, B=0（结果 y* = −(x/2)cos x）。
通解：y = C₁cos x + C₂sin x − (x/2)cos x
```

> ⚠️ 关键坑：f(x) 的"共振项"（与齐次解同形，如上面的 sin x）必须乘 x，否则代入后左边为 0，永远解不出特解。

## 九、微分方程的应用

- **指数增长/衰减模型**：y' = k·y ⇒ y = C·e^{kx}
  - k>0 增长（人口、复利）；k<0 衰减（放射性衰变、药物代谢）
  - **半衰期**：T = (ln 2)/k
- **牛顿冷却定律**：T' = k(T−T₀)，T₀ 为环境温度
- **逻辑斯蒂增长**：y' = ky(1 − y/L)，L 为环境容量（种群饱和模型）
- **简谐振动**：y'' = −ω²y ⇒ y = A sin(ωt+φ)（弹簧、单摆小角度）
- **RC/RL 电路**：一阶线性方程描述充放电电流变化

**例**：某放射性物质 10 年衰变到原来的一半，求再过 10 年剩多少。

```
y = C·e^{kt}，t=10 时 y=C/2：e^{10k}=1/2 ⇒ k=−(ln2)/10
t=20 时：y=C·e^{20k}=C·(1/2)²=C/4
答案：剩原来的 1/4。
```

**例**：牛顿冷却。物体 100°C 放入 20°C 房间，10 分钟后 60°C，问何时到 30°C？

```
T' = k(T−20) ⇒ T = 20 + 80e^{kt}
t=10：60 = 20 + 80e^{10k} ⇒ e^{10k}=1/2 ⇒ k=−(ln2)/10
30 = 20 + 80e^{kt} ⇒ e^{kt}=1/8 ⇒ t = 30 分钟
```

## 十、微积分概念澄清

1. **导数 vs 微分**：导数是极限比值 f'(x)；微分 dy = f'(x)dx 是增量 Δy 的线性主部，用于近似计算。
2. **dx 不是普通数**：dx 是极限过程中的记号，不能随意约分（虽然很多推导形式上像分数）。
3. **积分常数 C**：不定积分必须加 C；两个"原函数"可以差一个常数。
4. **极限存在 ≠ 连续**：连续还要求 lim_{x→x₀} f(x) = f(x₀)（函数值存在且等于极限）。
5. **无穷大不是数**：∞−∞、0×∞、1^∞ 都是未定式，要先变形再求。
6. **0/0 ≠ 0**：0/0 是未定式，要先化简、等价无穷小或洛必达。
7. **定积分是数，不定积分是函数族**：定积分 ∫_a^b 结果是数值；不定积分结果含 C。
8. **导数为 0 不一定极值**：还要检查两侧符号（如 x³ 在 x=0，f'=0 但无极值，是拐点）。
9. **可导 ⇒ 连续，但连续不 ⇒ 可导**：y=|x| 在 0 连续但不可导。
10. **原函数存在 ≠ 初等函数**：如 e^{−x²} 有原函数（积分存在），但写不出初等函数形式，积分要保留 ∫ 形式（概率论中用）。

## 十一、常见错误自查清单

- [ ] ∫ 1/x dx 漏写绝对值：应为 ln|x|+C
- [ ] 链式法则漏乘内层导数
- [ ] 分部积分 u、dv 选反
- [ ] 定积分上下限代反
- [ ] 极值只找 f'=0，漏不可导点与端点
- [ ] 洛必达前没验证 0/0 或 ∞/∞
- [ ] 微分方程解完没代回验证
- [ ] 二阶非齐次特解设错（共振项漏乘 x）
- [ ] 特征方程写错符号（如 y''−y 写成 λ²+1）
- [ ] 分离变量时丢掉 y=0 的常数解

## 十二、例题精讲（10 道）

**例 1**：求 y' = 2x 且 y(0)=1 的特解

```
y = x² + C，代入 y(0)=1 ⇒ C=1，特解 y=x²+1。
```

**例 2**：求 y' + y = eˣ 的通解

```
μ=eˣ，y = e^{−x}(e^{2x}/2 + C) = eˣ/2 + Ce^{−x}。
```

**例 3**：求 y'' + y = 0 的通解

```
λ²+1=0 ⇒ λ=±i，y = C₁cos x + C₂sin x。
```

**例 4**：求 y'' − 3y' + 2y = 0 的通解

```
λ²−3λ+2=0 ⇒ λ=1,2，y = C₁eˣ + C₂e^{2x}。
```

**例 5**：求 y'' + y = 2eˣ 的通解

```
齐次通解 C₁cos x+C₂sin x；设 y*=Aeˣ 得 A=1。
y = C₁cos x + C₂sin x + eˣ。
```

**例 6**：求 y' = x·y 的通解

```
dy/y = x dx ⇒ ln|y|=x²/2+C ⇒ y=Ce^{x²/2}。
```

**例 7**：求 y' = y² 且 y(0)=1 的特解

```
dy/y²=dx ⇒ −1/y = x+C ⇒ y = −1/(x+C)
y(0)=1 ⇒ C=−1 ⇒ y = 1/(1−x)（x<1）
```

**例 8**：求 y'' = 6x 的通解

```
y' = 3x²+C₁，y = x³+C₁x+C₂。
```

**例 9**：求 y'' − y' = 0 的通解

```
特征 λ²−λ=0 ⇒ λ=0,1 ⇒ y = C₁ + C₂eˣ。
```

**例 10**：放射性衰变，半衰期 10 年，问 40 年后剩多少

```
y=C·e^{kt}，e^{10k}=1/2。t=40：y=C·(1/2)^4 = C/16，剩 1/16。
```

## 十三、练习（10 道，附答案与解析）

1. 求 y' = x·y 的通解

> 答案：y = C·e^{x²/2}。分离变量后两边积分。

2. 求 y' + y = eˣ 的通解

> 答案：y = eˣ/2 + C·e^{−x}。积分因子 eˣ。

3. 求 y'' + y = 0 的通解

> 答案：y = C₁cos x + C₂sin x。特征根 ±i。

4. 求 y' = 2x 且 y(0)=1 的特解

> 答案：y = x² + 1。通解 y=x²+C，代入 y(0)=1 ⇒ C=1。

5. 改正：∫ (1/x) dx = ln x

> 答案：应写 ∫ (1/x) dx = ln|x| + C。x 可能为负，必须加绝对值并补积分常数。

6. 求 y'' − 4y = 0 的通解

> 答案：y = C₁e^{2x} + C₂e^{−2x}。特征根 λ=±2。

7. 求 y'' + 4y = 0 的通解

> 答案：y = C₁cos 2x + C₂sin 2x。特征根 λ=±2i（α=0, β=2）。

8. 求 y'' − 2y' + y = 0 的通解

> 答案：y = (C₁+C₂x)eˣ。特征根为重根 λ=1。

9. 求 y'' + y' = 2 的通解

> 答案：y = C₁ + C₂e^{−x} + 2x。齐次通解 C₁+C₂e^{−x}；设 y*=Ax，代入得 A=2。

10. 求 y' − y = x 的通解

> 答案：y = C·eˣ − x − 1。μ=e^{−x}，y=eˣ[∫x·e^{−x}dx+C]=eˣ(−(x+1)e^{−x}+C)=C·eˣ−x−1。

- [ ] 把 0/0 直接当 0
- [ ] 把无穷大当普通数参与运算
