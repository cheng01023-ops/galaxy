## 一、微分方程基本概念

含未知函数及其导数的方程叫微分方程。

- **阶**：最高阶导数的阶数
- **通解**：含任意常数的解
- **特解**：由初值条件确定的解
- **初值问题**：方程 + 初值条件

例：

```
y' = 2x          → 一阶
y'' + y = 0      → 二阶
y(0) = 1         → 初值条件
```

---

## 二、可分离变量方程

形如 y' = f(x)·g(y)：

```
dy/g(y) = f(x) dx
∫ dy/g(y) = ∫ f(x) dx
```

**例**：y' = y

```
dy/y = dx
ln|y| = x + C
y = C·eˣ
```

**例**：y' = x·y

```
dy/y = x dx
ln|y| = x²/2 + C
y = C·e^{x²/2}
```

---

## 三、一阶线性微分方程

形如 y' + p(x)y = q(x)，积分因子 μ = e^{∫p dx}：

```
y = e^{−∫p dx}·[ ∫ q·e^{∫p dx} dx + C ]
```

**例**：y' + y = eˣ

```
p=1 ⇒ μ=eˣ
y = e^{−x}·[ ∫ eˣ·eˣ dx + C ]
  = e^{−x}·[ e^{2x}/2 + C ]
  = eˣ/2 + C·e^{−x}
```

---

## 四、二阶常系数齐次方程（简介）

ay'' + by' + cy = 0，设 y=e^{λx}，得特征方程 aλ²+bλ+c=0：

| 判别式 | 通解 |
|---|---|
| 两不同实根 λ₁,λ₂ | C₁e^{λ₁x}+C₂e^{λ₂x} |
| 重根 λ | (C₁+C₂x)e^{λx} |
| 共轭复根 λ=α±βi | e^{αx}(C₁cosβx+C₂sinβx) |

**例**：y''+y=0

```
特征方程 λ²+1=0 ⇒ λ=±i
y = C₁cos x + C₂sin x
```

## 六、微积分概念澄清

1. **导数 vs 微分**：导数是极限比值；微分 dy = f'(x)dx 是近似增量
2. **dx 不是普通数**：是极限记号，不能随意约分
3. **积分常数 C**：不定积分必须加 C
4. **极限存在 ≠ 连续**：还要 lim = f(x₀)
5. **无穷大不是数**：∞−∞、0×∞、1^∞ 都要先变形
6. **0/0 ≠ 0**：先化简或洛必达
7. **定积分是数，不定积分是函数族**
8. **导数为 0 不一定极值**：还要检查两侧符号（如 x³ 在 x=0）

## 七、常见错误自查清单

- [ ] ∫ 1/x dx 漏写绝对值：应为 ln|x|+C
- [ ] 链式法则漏乘内层导数
- [ ] 分部积分 u、dv 选反
- [ ] 定积分上下限代反
- [ ] 极值只找 f'=0，漏不可导点与端点
- [ ] 洛必达前没验证 0/0 或 ∞/∞
- [ ] 微分方程解完没代回验证

## 八、练习（附答案）

1. 求 y' = x·y 的通解

> 答案：y = C·e^{x²/2}。分离变量后两边积分。

2. 求 y' + y = eˣ 的通解

> 答案：y = eˣ/2 + C·e^{−x}。积分因子 eˣ。

3. 求 y'' + y = 0 的通解

> 答案：y = C₁cos x + C₂sin x。特征根 ±i。

4. 求 y' = 2x 且 y(0)=1 的特解

> 答案：y = x² + 1。通解 y=x²+C，代入 y(0)=1 ⇒ C=1。

5. 改正：∫ (1/x) dx = ln x

> 答案：应写 ∫ (1/x) dx = ln|x| + C。x 可能为负，必须加绝对值并补积分常数。
