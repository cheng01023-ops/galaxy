## 一、微分方程基本概念

含未知函数及其导数的方程叫微分方程。

- 阶：方程中最高阶导数的阶数
- 通解：含任意常数的解
- 特解：由初值条件确定的解

例：

```
y' = 2x          → 一阶
y'' + y = 0      → 二阶
y(0) = 1         → 初值条件
```

## 二、可分离变量方程

形如 y' = f(x)·g(y)，把变量分开再积分：

```
dy/g(y) = f(x) dx
∫ dy/g(y) = ∫ f(x) dx
```

例：y' = y，得 ln|y| = x + C ⇒ y = C·eˣ

## 三、一阶线性微分方程

形如 y' + p(x)y = q(x)，公式：

```
y = e^{−∫p dx} · [ ∫ q·e^{∫p dx} dx + C ]
```

> 先求积分因子 μ = e^{∫p dx}，再套公式。

## 四、二阶常系数齐次（简介）

ay'' + by' + cy = 0，设 y=e^{λx}，得特征方程 aλ² + bλ + c = 0：

- 两不同实根：y = C₁e^{λ₁x} + C₂e^{λ₂x}
- 重根：y = (C₁ + C₂x)e^{λx}
- 共轭复根 λ=α±βi：y = e^{αx}(C₁cosβx + C₂sinβx)

## 五、微积分概念澄清

1. **导数 vs 微分**：导数是一个比值极限；微分是"近似增量" dy = f'(x)dx
2. **dx 不是普通数**：dx 是极限过程中的记号，不能随意消去
3. **积分常数 C**：不定积分必须加 C，否则答案不完整
4. **极限存在 ≠ 连续**：极限存在还要等于函数值才连续
5. **无穷大不是数**：∞−∞、0×∞ 等是未定型，要先变形再求
6. **0/0 不等于 0**：要因式分解、约分或用洛必达法则

## 一、空间解析几何基础

### 1.1 空间直角坐标

点 P(x,y,z) 由三个坐标确定；两点距离：

```
d = √[(x₂−x₁)² + (y₂−y₁)² + (z₂−z₁)²]
```

### 1.2 向量

- 向量 a=(a₁,a₂,a₃)
- 点积：a·b = a₁b₁+a₂b₂+a₃b₃；a⊥b ⇔ a·b=0
- 叉积：a×b 是垂直于 a、b 的向量；|a×b| = |a||b|sinθ

### 1.3 平面与直线

- 平面（点法式）：n·(r−r₀)=0，即 A(x−x₀)+B(y−y₀)+C(z−z₀)=0
- 直线（参数式）：r = r₀ + t·d

## 二、多元函数的积分学

### 2.1 多元函数与偏导数

z=f(x,y)，偏导数 ∂f/∂x：把 y 当常数对 x 求导。
梯度 ∇f = (∂f/∂x, ∂f/∂y)，指向变化最快的方向。

### 2.2 二重积分

```
∬_D f(x,y) dA = lim 矩形细分求和
```

- 直角坐标：先对 x 后对 y（或反之）
- 极坐标：dA = r dr dθ，适合圆域

### 2.3 应用

- 平面区域面积：∬_D 1 dA
- 体积：∬_D f(x,y) dA

## 三、线性变化与二次曲线曲面

### 3.1 线性变换

矩阵 A 把向量 x 映射为 Ax，保持直线与比例。

- 旋转、缩放、投影都是线性变换
- 特征值/特征向量：Av = λv

### 3.2 二次曲线（标准式）

| 曲线 | 标准方程 |
|---|---|
| 圆 | x²+y²=R² |
| 椭圆 | x²/a² + y²/b² = 1 |
| 双曲线 | x²/a² − y²/b² = 1 |
| 抛物线 | y² = 2px |

判别：把一般式 Ax²+Bxy+Cy²+Dx+Ey+F=0 配方后归类。

### 3.3 二次曲面

| 曲面 | 标准方程 |
|---|---|
| 球面 | x²+y²+z²=R² |
| 椭球面 | x²/a²+y²/b²+z²/c²=1 |
| 椭圆抛物面 | z = x²/a² + y²/b² |
| 圆锥面 | z² = x²+y² |
| 单叶双曲面 | x²/a²+y²/b²−z²/c²=1 |
