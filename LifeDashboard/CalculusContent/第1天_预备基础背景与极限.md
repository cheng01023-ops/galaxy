## 一、数理学习预备基础

### 1.1 数集与数轴

| 记号 | 名称 | 例子 | 特点 |
|---|---|---|---|
| N | 自然数 | 0,1,2,3… | 离散 |
| Z | 整数 | …−2,−1,0,1,2… | 离散 |
| Q | 有理数 | 1/2, −3/7 | 可写成分数 |
| R | 实数 | √2, π, e | 连续，填满数轴 |

微积分的研究对象主要是**实数集 R**，因为只有实数是"连续的"。

区间记号：
- 闭区间 [a,b]：a≤x≤b
- 开区间 (a,b)：a<x<b
- 半开 [a,b)、(a,b]

### 1.2 函数：严格定义

设 A、B 是两个非空实数集，若对每个 x∈A，按某个规则 f 都有**唯一**的 y∈B 与之对应，则称 f 是从 A 到 B 的函数：

```
y = f(x)
```

- **定义域** D(f)：x 能取的所有值
- **值域** R(f)：f(x) 能取到的所有值
- 函数的三要素：定义域、对应法则、值域

例：f(x)=√(x−1)，定义域 x≥1；值域 y≥0。

### 1.3 基本初等函数

| 类别 | 例子 | 定义域注意 |
|---|---|---|
| 幂函数 | xⁿ | n 为分数时注意根号/分母 |
| 指数函数 | aˣ (a>0,a≠1) | 全体实数 |
| 对数函数 | log_a x | x>0 |
| 三角函数 | sin x, cos x, tan x | tan x 的 x≠π/2+kπ |
| 反三角函数 | arcsin x | −1≤x≤1 |
| 常数函数 | c | 全体实数 |

复合函数 f(g(x)) 的定义域：先满足 g(x) 的定义域，再满足 f 的定义域。

### 1.4 学习心态与方法

1. 概念先行：先回答"它是什么、为什么"再做题
2. 推导优先：每个公式自己推一遍，记忆更牢
3. 三遍法：听课 → 抄例题 → 独立重做

## 二、微积分背景与历史

### 2.1 古代：穷竭法

古希腊阿基米德用"穷竭法"计算圆面积：把圆切成越来越多的扇形，面积越来越接近圆面积。这就是"极限 + 积分"的雏形。

### 2.2 17 世纪：问题的提出

- 费马研究切线问题：求曲线上一点的切线斜率
- 伽利略研究运动：求瞬时速度

这两个问题都归结为同一个数学操作：**让增量趋于 0**。

### 2.3 牛顿与莱布尼茨

- **牛顿**：从物理出发，把"流数"（导数）与"流量"（函数）联系起来
- **莱布尼茨**：从几何出发，发明了记号 dx、dy、∫，并给出乘积法则、链式法则

他们各自独立发现了"导数与积分互逆"——即**微积分基本定理**。

### 2.4 严格化

早期"无穷小"概念含糊，引发争论。19 世纪柯西、魏尔斯特拉斯用 ε-δ 语言把极限严格化，微积分才建立在坚实基础上。

**历史启示**：微积分是一套"先直观、后严格"的思想，学的时候可以先用直觉，再逐步严谨。

## 三、极限

### 3.1 直观定义

当 x 无限接近 a（但不等于 a）时，f(x) 无限接近 L，就记：

```
lim_{x→a} f(x) = L
```

"无限接近"可以用 ε-δ 精确化：

> 对任意 ε>0，都存在 δ>0，使得当 0<|x−a|<δ 时，恒有 |f(x)−L|<ε。

### 3.2 左右极限

- 左极限：lim_{x→a⁻} f(x)（从左边接近）
- 右极限：lim_{x→a⁺} f(x)（从右边接近）

**结论**：lim_{x→a} f(x) 存在 ⇔ 左右极限都存在且相等。

例：

```
f(x) = |x|/x, x≠0
左极限 = −1，右极限 = 1，极限不存在
```

### 3.3 四则运算法则

若 lim f=A、lim g=B，则：

```
lim (f±g) = A±B
lim (f·g) = A·B
lim (f/g) = A/B（B≠0）
lim [cf] = cA
```

### 3.4 常用求极限方法

1. **直接代入**：先代 x=a 试
2. **因式分解约分**：消除 0/0
3. **分子有理化**：含根号时
4. **同除最高次项**：x→∞ 的分式
5. **夹逼定理**：一边放、一边收
6. **两个重要极限**
7. **等价无穷小**：x→0 时 sin x~x、tan x~x、eˣ−1~x、ln(1+x)~x

### 3.5 无穷小与无穷大

- 无穷小：极限为 0 的量
- 若 lim β/α = 0，称 β 是 α 的高阶无穷小
- 若 lim β/α = c≠0，称同阶无穷小（c=1 时为等价无穷小）
- 无穷大：|f(x)| 无限增大

### 3.6 两个重要极限

```
(1) lim_{x→0} (sin x)/x = 1
(2) lim_{x→∞} (1 + 1/x)^x = e
```

变形：lim_{x→0} (1+x)^{1/x} = e；lim_{x→0} sin(kx)/x = k。

### 3.7 连续

f 在 x₀ 连续 ⇔ lim_{x→x₀} f(x) = f(x₀)（且两边都存在）。

- 基本初等函数在其定义域内连续
- 连续函数四则运算仍连续；复合函数连续
- 最值定理：闭区间上连续函数必有最大值和最小值
- 介值定理：连续函数从 f(a) 到 f(b) 会经过中间一切值

## 四、例题精讲

**例 1**：求 lim_{x→3} (x²−9)/(x−3)

解：直接代入得 0/0。因式分解：

```
(x²−9)/(x−3) = (x−3)(x+3)/(x−3) = x+3（x≠3）
lim = 3+3 = 6
```

**例 2**：求 lim_{x→∞} (3x²+1)/(2x²−5)

解：分子分母同除 x²：

```
(3+1/x²)/(2−5/x²) → 3/2
```

**例 3**：求 lim_{x→0} (sin 3x)/x

解：利用重要极限：

```
(sin 3x)/x = 3·(sin 3x)/(3x) → 3·1 = 3
```

**例 4**：求 lim_{x→0} (1−cos x)/x²

解：1−cos x = 2sin²(x/2) ~ 2·(x/2)² = x²/2，所以极限 = 1/2。

## 五、练习（附答案）

1. 求 lim_{x→2} (x²−4)/(x−2)

> 答案：4。因式分解 (x−2)(x+2)/(x−2) = x+2，代入 x=2 得 4。

2. 求 lim_{x→∞} (2x+1)/(3x−4)

> 答案：2/3。分子分母同除 x：(2+1/x)/(3−4/x) → 2/3。

3. 求 lim_{x→0} (sin 2x)/x

> 答案：2。= 2·(sin 2x)/(2x) → 2·1 = 2。

4. 判断 f(x) = (x²−1)/(x−1) 在 x=1 是否连续

> 答案：不连续。lim_{x→1} f(x) = lim (x+1) = 2，但 f(1) 无定义（0/0），所以不满足"函数值=极限"。

5. 求 lim_{x→∞} (1 + 2/x)^x

> 答案：e²。令 t=x/2，则原式 = [(1+1/t)^t]² → e²。

6. 求 lim_{x→0} (eˣ − 1)/x

> 答案：1。等价无穷小 eˣ−1 ~ x。
