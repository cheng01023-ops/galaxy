## 一、数理学习预备基础

### 1.1 数集与数轴

| 记号 | 名称 | 例子 | 特点 |
|---|---|---|---|
| N | 自然数 | 0,1,2,3… | 离散，可数 |
| Z | 整数 | …−2,−1,0,1,2… | 离散，可数 |
| Q | 有理数 | 1/2, −3/7, 0.3 | 可写成分数 p/q（q≠0） |
| R | 实数 | √2, π, e, 0.101001… | 连续，填满数轴 |

微积分的研究对象主要是**实数集 R**，因为只有实数是"连续的"——数轴上没有任何"空隙"。

几个容易混淆的点：
- 每个有理数都是实数，但实数不都是有理数（如 √2、π 是无理数）。
- 无理数不能写成 p/q 的形式，其小数展开是**无限不循环**小数。
- 两个不同实数之间一定还有实数（稠密性）。

**区间记号**：
- 闭区间 [a,b]：a≤x≤b
- 开区间 (a,b)：a<x<b
- 半开半闭 [a,b)、(a,b]
- 无穷区间：(−∞,a]、[a,∞)、(a,∞)、(−∞,b) 等

**邻域**（极限中常用）：以 a 为中心、δ 为半径的开区间 (a−δ, a+δ) 叫 a 的 δ 邻域；去掉 a 本身后叫**去心邻域**，记作 U(a,δ)。

### 1.2 函数：严格定义

设 A、B 是两个非空实数集，若对每个 x∈A，按某个规则 f 都有**唯一**的 y∈B 与之对应，则称 f 是从 A 到 B 的函数：

```
y = f(x)
```

- **定义域** D(f)：x 能取的所有值
- **值域** R(f)：f(x) 能取到的所有值
- 函数的三要素：定义域、对应法则、值域

> ⚠️ 注意：两个函数相同 ⇔ 定义域相同 **且** 对应法则相同。例如 f(x)=x 与 g(x)=x²/x 不是同一个函数（g 在 x=0 无定义）。

例：f(x)=√(x−1)，定义域 x≥1；值域 y≥0。

### 1.3 几个重要的特殊函数

- **绝对值函数** |x|：x≥0 时为 x，x<0 时为 −x。图像是 V 形，在 x=0 处是"尖点"。
- **符号函数** sgn(x)：x>0 为 1，x=0 为 0，x<0 为 −1。
- **取整函数** [x]：不超过 x 的最大整数，如 [2.7]=2、[−1.3]=−2。
- **狄利克雷函数**（了解）：有理数取 1、无理数取 0，处处不连续——这是"病态函数"的经典例子。

### 1.4 函数的基本特性

| 特性 | 定义 | 例子 |
|---|---|---|
| 有界性 | 存在 M>0，使 ｜f(x)｜≤M 对定义域内一切 x 成立 | sin x、cos x 有界 |
| 单调性 | x₁<x₂ ⇒ f(x₁)≤f(x₂) 为递增；< 为严格递增 | x² 在 [0,∞) 递增 |
| 奇偶性 | f(−x)=f(x) 偶函数（关于 y 轴对称）；f(−x)=−f(x) 奇函数（关于原点对称） | x² 偶，x³ 奇 |
| 周期性 | 存在 T>0，使 f(x+T)=f(x) | sin x 周期 2π |

常见结论：
- 奇函数 + 奇函数 = 奇函数；偶函数 × 偶函数 = 偶函数；奇函数 × 偶函数 = 奇函数。
- 任意函数 f(x) 都可拆成偶部 [f(x)+f(−x)]/2 与奇部 [f(x)−f(−x)]/2。

### 1.5 反函数

若 y=f(x) 是严格单调函数（一一对应），则可解出 x=φ(y)，即反函数，记作 f⁻¹(y)。

- 反函数与原函数图像关于直线 y=x 对称。
- 定义域与值域互换。
- 例：y=eˣ 的反函数是 y=ln x；y=sin x（在 [−π/2, π/2] 上）的反函数是 y=arcsin x。

### 1.6 基本初等函数

| 类别 | 例子 | 定义域注意 |
|---|---|---|
| 幂函数 | xⁿ | n 为分数时注意根号/分母；x⁰=1（x≠0） |
| 指数函数 | aˣ (a>0,a≠1) | 全体实数，值域 (0,∞) |
| 对数函数 | log_a x (a>0,a≠1) | x>0 |
| 三角函数 | sin x, cos x, tan x, cot x, sec x, csc x | tan x 的 x≠π/2+kπ；cot x 的 x≠kπ |
| 反三角函数 | arcsin x, arccos x, arctan x | arcsin/arccos 的 −1≤x≤1 |
| 常数函数 | c | 全体实数 |

**由基本初等函数经有限次四则运算和复合得到的函数叫初等函数**，初等函数在其定义域内处处连续（这是后面连续定理的依据）。

### 1.7 复合函数

复合函数 f(g(x)) 的定义域：先满足 g(x) 的定义域，再满足 f 的定义域。

例：y=√(1−x²) 可看作 f(u)=√u 与 u=1−x² 的复合。要求 1−x²≥0，即 −1≤x≤1。

例：y=ln(x²−1)，要求 x²−1>0，即 x<−1 或 x>1。

## 二、微积分背景与历史

### 2.1 古代：穷竭法

古希腊阿基米德用"穷竭法"计算圆面积：把圆切成越来越多的扇形，面积越来越接近圆面积。这就是"极限 + 积分"的雏形。

- 中国魏晋时期刘徽的"割圆术"：用圆内接正多边形逼近圆，"割之弥细，所失弥少，割之又割，以至于不可割，则与圆周合体而无所失矣"——这就是极限思想。

### 2.2 17 世纪：问题的提出

- 费马研究切线问题：求曲线上一点的切线斜率
- 伽利略研究运动：求瞬时速度
- 笛卡尔引入坐标系，把几何问题代数化

这两个问题都归结为同一个数学操作：**让增量趋于 0**。

### 2.3 牛顿与莱布尼茨

- **牛顿**：从物理出发，把"流数"（导数）与"流量"（函数）联系起来
- **莱布尼茨**：从几何出发，发明了记号 dx、dy、∫，并给出乘积法则、链式法则

他们各自独立发现了"导数与积分互逆"——即**微积分基本定理**。

### 2.4 严格化

早期"无穷小"概念含糊，引发争论（如贝克莱主教抨击"无穷小量的鬼魂"）。19 世纪柯西、魏尔斯特拉斯用 ε-δ 语言把极限严格化，微积分才建立在坚实基础上。

**历史启示**：微积分是一套"先直观、后严格"的思想，学的时候可以先用直觉，再逐步严谨。

## 三、数列的极限

### 3.1 什么是数列

按一定次序排列的一列数 a₁, a₂, a₃, …, aₙ, … 叫数列，可看作定义在正整数集上的函数 aₙ=f(n)。

例：
- aₙ = 1/n：1, 1/2, 1/3, … 越来越接近 0
- aₙ = (−1)ⁿ：−1, 1, −1, 1, … 来回跳动，不接近任何数
- aₙ = n：1, 2, 3, … 无限增大，不接近任何有限数

### 3.2 数列极限的直观与 ε-N 定义

直观：当 n 无限增大时，aₙ 无限接近常数 A，就说数列收敛于 A：

```
lim_{n→∞} aₙ = A
```

严格定义（ε-N 语言）：

> 对任意 ε>0，总存在正整数 N，使得当 n>N 时，恒有 |aₙ − A| < ε。

意思是：无论你给的"误差范围" ε 多小，从某一项 N 之后的所有项都能落进 (A−ε, A+ε) 这个小区间里。

**例**：用定义证明 lim_{n→∞} 1/n = 0。

```
任给 ε>0，要使 |1/n − 0| = 1/n < ε，只需 n > 1/ε。
取 N = [1/ε]+1（或任意大于 1/ε 的整数），当 n>N 时就有 1/n<ε。
故 lim 1/n = 0。✓
```

### 3.3 收敛数列的性质

1. **唯一性**：收敛数列的极限唯一。
2. **有界性**：收敛数列必有界（但有界不一定收敛，如 (−1)ⁿ）。
3. **保号性**：若 lim aₙ = A>0，则从某一项起 aₙ>0（A<0 同理）。
4. **夹逼准则**：若 aₙ≤bₙ≤cₙ 且 lim aₙ = lim cₙ = A，则 lim bₙ = A。
5. **单调有界准则**：单调递增且有上界的数列必收敛（单调递减且有下界同理）。这是证明重要极限 (1+1/n)ⁿ 存在的基础。

## 四、函数的极限

### 4.1 直观定义

当 x 无限接近 a（但不等于 a）时，f(x) 无限接近 L，就记：

```
lim_{x→a} f(x) = L
```

"无限接近"可以用 ε-δ 精确化：

> 对任意 ε>0，都存在 δ>0，使得当 0<|x−a|<δ 时，恒有 |f(x)−L|<ε。

> 💡 理解要点：极限看的是 x **接近** a 时的趋势，与 f 在 a 点有没有定义、等于多少**无关**。例如 f(x)=(x²−1)/(x−1) 在 x=1 无定义，但 lim_{x→1} f(x)=2。

### 4.2 左右极限

- 左极限：lim_{x→a⁻} f(x)（从左边接近）
- 右极限：lim_{x→a⁺} f(x)（从右边接近）

**结论**：lim_{x→a} f(x) 存在 ⇔ 左右极限都存在且相等。

例：

```
f(x) = |x|/x, x≠0
左极限 = −1，右极限 = 1，极限不存在
```

### 4.3 极限的性质

- **唯一性**：函数极限存在则唯一。
- **局部有界性**：若 lim_{x→a} f(x) 存在，则 f 在 a 的某去心邻域内有界。
- **保号性**：若 lim_{x→a} f(x)=A>0，则 f 在 a 的某去心邻域内恒为正（A<0 同理）。
- **四则运算法则**：若 lim f=A、lim g=B，则：

```
lim (f±g) = A±B
lim (f·g) = A·B
lim (f/g) = A/B（B≠0）
lim [cf] = cA
```

- **复合函数极限**：若 lim_{x→a} g(x)=b 且 lim_{u→b} f(u)=L，则 lim_{x→a} f(g(x))=L（满足一定连续性条件时可直接代入）。
- **夹逼准则**：若 g(x)≤f(x)≤h(x) 且 lim g = lim h = L，则 lim f = L。

### 4.4 常用求极限方法（完整清单）

1. **直接代入**：先代 x=a 试。若得到具体数值就是答案。
2. **因式分解约分**：消除 0/0（如 (x²−9)/(x−3)）。
3. **分子有理化**：含根号时（如 (√(x+1)−1)/x）。
4. **同除最高次项**：x→∞ 的分式，看分子分母最高次。
5. **夹逼定理**：一边放、一边收（常配合同三角函数的有界性 |sin x|≤1）。
6. **两个重要极限**：sin x/x 与 (1+1/x)ˣ。
7. **等价无穷小替换**：x→0 时把复杂因子换成等价简单因子。
8. **洛必达法则**（第 2 天会学）：0/0 或 ∞/∞ 型对分子分母分别求导。

**关于 x→∞ 的分式极限（重要规律）**：

```
lim_{x→∞} (aₙxⁿ + …) / (bₘxᵐ + …)
- 若 n = m：极限 = 最高次系数比 aₙ/bₘ
- 若 n < m：极限 = 0（分母跑得更快）
- 若 n > m：极限 = ∞（分子跑得更快）
```

### 4.5 未定式的类型

| 类型 | 例子 | 处理思路 |
|---|---|---|
| 0/0 | (sin x)/x | 约分、有理化、等价无穷小、洛必达 |
| ∞/∞ | (3x²+1)/(2x²−5) | 同除最高次、洛必达 |
| 0·∞ | x·ln x | 变形为 0/0 或 ∞/∞ 再处理 |
| ∞−∞ | √(x²+1)−x | 分子有理化 |
| 1^∞ | (1+1/x)ˣ | 凑重要极限或取对数 |
| 0⁰、∞⁰ | xˣ (x→0⁺) | 取对数化为 0·∞ |

> ⚠️ 记忆：遇到未定式不要慌，先识别类型，再选对应方法。**不是未定式**的极限直接代入即可，例如 lim_{x→1} (x+2)/(x−1) 分母趋于 0 而分子趋于 3，结果是 ∞（属于"非零/零"型）。

## 五、无穷小与无穷大

### 5.1 无穷小

极限为 0 的量叫无穷小（注意：无穷小是"变量"不是"很小的数"，0 是唯一的常数无穷小）。

### 5.2 无穷小的比较

设 α、β 都是 x→x₀ 时的无穷小：

| 条件 | 结论 |
|---|---|
| lim β/α = 0 | β 是 α 的**高阶**无穷小，记 β=o(α) |
| lim β/α = c≠0 | β 与 α 是**同阶**无穷小 |
| lim β/α = 1 | β 与 α 是**等价**无穷小，记 β~α |
| lim β/αᵏ = c≠0（k>0） | β 是 α 的 **k 阶**无穷小 |

### 5.3 常用等价无穷小（x→0 时，务必背熟）

| 等价关系 | 说明 |
|---|---|
| sin x ~ x | 最常用 |
| tan x ~ x | 最常用 |
| arcsin x ~ x | 常用 |
| arctan x ~ x | 常用 |
| ln(1+x) ~ x | 常用 |
| eˣ − 1 ~ x | 常用 |
| aˣ − 1 ~ x·ln a | 一般化 |
| 1 − cos x ~ x²/2 | 二分之一 x 平方 |
| (1+x)^α − 1 ~ αx | 幂指一般化，如 √(1+x)−1 ~ x/2 |

> ⚠️ 使用规则：等价无穷小**只可在乘除中替换，不可在加减中随意替换**。例如 lim (sin x − x)/x³ 不能把 sin x 换成 x 得到 0，正确结果是 −1/6（需泰勒展开，第 2 天学）。

### 5.4 无穷大

若 |f(x)| 无限增大，称 f(x) 为无穷大，记 lim f(x)=∞。

- 无穷大不是数，不能参与普通四则运算。
- 若 lim f=∞，则 1/f 是无穷小；若 f 是无穷小且 f≠0，则 1/f 是无穷大。

## 六、两个重要极限

```
(1) lim_{x→0} (sin x)/x = 1
(2) lim_{x→∞} (1 + 1/x)^x = e
```

**变形**：
- lim_{x→0} (1+x)^{1/x} = e
- lim_{x→0} sin(kx)/x = k
- lim_{x→0} (1+kx)^{1/x} = eᵏ
- lim_{x→0} (1+x)^{k/x} = eᵏ

> 💡 两个重要极限的识别特征：
> - 第一个：分子是 sin，分母是同一个"整体"，且这个整体趋于 0。
> - 第二个：底数 = 1 + (趋于 0 的量)，指数 = 该量的倒数。

<details><summary>📐 推导：为什么 lim_{x→0} (sin x)/x = 1（了解）</summary>

在单位圆中，设圆心角为 x（弧度制，0<x<π/2），则：
- △OAB 面积 < 扇形 OAB 面积 < △OAC 面积
- (1/2)sin x < (1/2)x < (1/2)tan x

除以 (1/2)sin x 得：1 < x/sin x < 1/cos x，即 cos x < sin x/x < 1。

由夹逼准则，且 lim cos x = 1，得 lim (sin x)/x = 1。✓

</details>

## 七、函数的连续性

### 7.1 定义

f 在 x₀ 连续 ⇔ 下面三条同时成立：
1. f(x₀) 有定义；
2. lim_{x→x₀} f(x) 存在；
3. lim_{x→x₀} f(x) = f(x₀)。

等价地：lim_{Δx→0} [f(x₀+Δx) − f(x₀)] = 0，即"自变量的微小改变引起函数值的微小改变"。

### 7.2 间断点的四种类型

f 在 x₀ 不连续（即间断），按左右极限情况分类：

| 类型 | 特征 | 例子 |
|---|---|---|
| 可去间断点 | 左右极限存在且相等，但不等于 f(x₀) 或 f(x₀) 无定义 | (x²−1)/(x−1) 在 x=1 |
| 跳跃间断点 | 左右极限都存在但不相等 | ｜x｜/x 在 x=0 |
| 无穷间断点 | 左右极限至少有一个为 ∞ | 1/x 在 x=0；tan x 在 x=π/2 |
| 振荡间断点 | 左右极限都不存在（来回振荡） | sin(1/x) 在 x=0 |

> 💡 口诀：**可去（相等但不符）、跳跃（左右不相等）、无穷（跑到天边）、振荡（来回乱跳）**。

### 7.3 连续函数的运算性质

- 基本初等函数在其定义域内连续。
- 连续函数四则运算仍连续（除法要求分母不为 0）。
- 连续函数的复合函数连续。
- 反函数在对应区间连续。

### 7.4 闭区间上连续函数的三大定理

1. **最值定理**：f 在 [a,b] 上连续 ⇒ f 在 [a,b] 上有最大值 M 与最小值 m。
2. **介值定理**：f 在 [a,b] 上连续，且 m≤μ≤M，则至少存在一点 ξ∈[a,b]，使 f(ξ)=μ。即连续函数从 f(a) 到 f(b) 会经过中间一切值。
3. **零点定理**（介值定理的特例）：若 f(a)·f(b)<0（两端异号），则至少存在一点 ξ∈(a,b)，使 f(ξ)=0。

> 💡 零点定理是证明"方程有根"的万能工具：只要找到一个区间两端函数值异号，就能断定方程在区间内有根。

例：证明方程 x³ − 3x + 1 = 0 在 (0,1) 内有根。

```
令 f(x)=x³−3x+1，f 连续。
f(0)=1>0，f(1)=−1<0，两端异号。
由零点定理，存在 ξ∈(0,1) 使 f(ξ)=0，即方程在 (0,1) 内有根。✓
```

## 八、例题精讲（12 道）

**例 1**：求 lim_{x→3} (x²−9)/(x−3)

解：直接代入得 0/0。因式分解：

```
(x²−9)/(x−3) = (x−3)(x+3)/(x−3) = x+3（x≠3）
lim = 3+3 = 6
```

**例 2**：求 lim_{x→∞} (3x²+1)/(2x²−5)

解：分子分母同除 x²：

```
(3+1/x²)/(2−5/x²) → 3/2
```

**例 3**：求 lim_{x→0} (sin 3x)/x

解：利用重要极限：

```
(sin 3x)/x = 3·(sin 3x)/(3x) → 3·1 = 3
```

**例 4**：求 lim_{x→0} (1−cos x)/x²

解：1−cos x = 2sin²(x/2) ~ 2·(x/2)² = x²/2，所以极限 = 1/2。

**例 5**：求 lim_{x→0} (√(1+x) − 1)/x

解：分子有理化，或直接用等价无穷小 √(1+x)−1 ~ x/2：

```
lim = (x/2)/x = 1/2
```

**例 6**：求 lim_{x→∞} (√(x²+1) − x)

解：∞−∞ 型，分子有理化：

```
(√(x²+1)−x)(√(x²+1)+x) / (√(x²+1)+x)
= 1 / (√(x²+1)+x) → 0
```

**例 7**：求 lim_{x→0} x·sin(1/x)

解：这是 0 × 有界 型。因为 |sin(1/x)|≤1，而 x→0：

```
由夹逼：−|x| ≤ x·sin(1/x) ≤ |x|，两边都趋于 0
lim = 0
```

**例 8**：求 lim_{x→0} (eˣ − 1)/x

解：等价无穷小 eˣ−1 ~ x，极限 = 1。

**例 9**：求 lim_{x→0} ln(1+3x)/x

解：ln(1+3x) ~ 3x，极限 = 3。

**例 10**：求 lim_{x→∞} (1 + 2/x)^x

解：令 t=x/2，则 x=2t，原式 = [(1+1/t)^t]² → e²。

**例 11**：求 lim_{x→0} (1+x)^{3/x}

解：这是 1^∞ 型，凑重要极限：

```
(1+x)^{3/x} = [(1+x)^{1/x}]³ → e³
```

**例 12**：判断 f(x)=(x²−1)/(x−1) 在 x=1 的类型，若是间断点则说明类型。

解：

```
x=1 处无定义（0/0），但左右极限存在且相等：
lim_{x→1} (x²−1)/(x−1) = lim (x+1) = 2
所以 x=1 是可去间断点（可补充定义 f(1)=2 使其连续）。
```

## 九、练习（12 道，附答案与解析）

1. 求 lim_{x→2} (x²−4)/(x−2)

> 答案：4。因式分解 (x−2)(x+2)/(x−2) = x+2，代入 x=2 得 4。

2. 求 lim_{x→∞} (2x+1)/(3x−4)

> 答案：2/3。分子分母同除 x：(2+1/x)/(3−4/x) → 2/3。

3. 求 lim_{x→0} (sin 2x)/x

> 答案：2。= 2·(sin 2x)/(2x) → 2·1 = 2。

4. 求 lim_{x→0} tan(5x)/(3x)

> 答案：5/3。tan(5x)~5x，故原式 ~5x/(3x)=5/3。

5. 求 lim_{x→0} (1−cos 2x)/x²

> 答案：2。1−cos 2x ~ (2x)²/2 = 2x²，故极限 = 2。

6. 判断 f(x) = (x²−1)/(x−1) 在 x=1 是否连续

> 答案：不连续。lim_{x→1} f(x) = lim (x+1) = 2，但 f(1) 无定义（0/0），所以不满足"函数值=极限"。且这是可去间断点。

7. 求 lim_{x→∞} (1 + 2/x)^x

> 答案：e²。令 t=x/2，则原式 = [(1+1/t)^t]² → e²。

8. 求 lim_{x→0} (eˣ − 1)/x

> 答案：1。等价无穷小 eˣ−1 ~ x。

9. 求 lim_{x→0} x·sin(1/x)

> 答案：0。0×有界=0，用夹逼定理：−|x|≤x·sin(1/x)≤|x|。

10. 求 lim_{x→0} (√(1+x)−1)/(2x)

> 答案：1/4。√(1+x)−1 ~ x/2，故 (x/2)/(2x)=1/4。

11. 指出 f(x)=1/(x−2) 在 x=2 的间断点类型

> 答案：无穷间断点。x→2⁻ 时 f→−∞，x→2⁺ 时 f→+∞，左右极限至少一个为无穷。

12. 证明方程 x³ − 3x + 1 = 0 在 (0,1) 内有根

> 答案：令 f(x)=x³−3x+1（连续），f(0)=1>0，f(1)=−1<0，由零点定理存在 ξ∈(0,1) 使 f(ξ)=0。
