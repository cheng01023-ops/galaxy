### 1.2 函数是什么

函数是"输入 → 规则 → 输出"：

```
x ——> f ——> f(x)
```

- 定义域：x 能取的范围
- 值域：f(x) 能取到的范围
- 常见的函数：多项式、幂、指数、对数、三角函数

例：f(x) = x²，x=3 时 f(3)=9。

## 二、微积分背景与历史

微积分由**牛顿**（物理角度）与**莱布尼茨**（几何/符号角度）在 17 世纪独立创立。

它要解决两类问题：

1. **切线问题**：曲线上某点的切线斜率 → 导数
2. **面积问题**：曲线下的面积 → 积分

核心思想是**"无限细分，再求和/取极限"**：

```
求瞬时速度：
    平均速度 = Δs / Δt
    让 Δt → 0（瞬时速度）
```

微积分把"变化"和"累积"统一起来，是物理、工程、经济学的通用语言。

## 三、极限

### 3.1 直观定义

当 x 无限接近 a 时，f(x) 无限接近某个数 L，就说：

```
lim_{x→a} f(x) = L
```

例：

```
lim_{x→2} (3x+1) = 7
lim_{x→0} (sin x)/x = 1
```

### 3.2 左右极限

- 左极限：从左边接近，记 lim_{x→a⁻}
- 右极限：从右边接近，记 lim_{x→a⁺}
- 极限存在 ⇔ 左右极限都存在且相等

### 3.3 四则运算法则

若 lim f(x)=A、lim g(x)=B，则：

```
lim [f+g] = A+B
lim [f-g] = A-B
lim [f·g] = A·B
lim [f/g] = A/B（B≠0）
```

### 3.4 无穷大与无穷小

- 无穷小：极限为 0 的量
- 无穷大：绝对值无限增大的量
- 常见处理：分子分母同除最高次项

例：

```
lim_{x→∞} (3x²+1)/(2x²-5) = 3/2
```

### 3.5 两个重要极限

```
lim_{x→0} (sin x)/x = 1
lim_{x→∞} (1 + 1/x)^x = e
```

### 3.6 连续

f 在 x₀ 连续 ⇔ 同时满足：

1. f(x₀) 存在
2. lim_{x→x₀} f(x) 存在
3. lim_{x→x₀} f(x) = f(x₀)

> 连续 = "函数图像在这一点不断开"。
