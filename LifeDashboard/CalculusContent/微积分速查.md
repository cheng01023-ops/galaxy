# 微积分速查

## 常用极限

- lim_{x→0} (sin x)/x = 1
- lim_{x→∞} (1 + 1/x)^x = e
- 0/0、∞/∞ 型可用洛必达法则：lim f/g = lim f'/g'

## 基本导数

| f(x) | f'(x) |
|---|---|
| xⁿ | n·xⁿ⁻¹ |
| eˣ | eˣ |
| ln x | 1/x |
| sin x | cos x |
| cos x | −sin x |
| tan x | sec²x |

运算法则：(uv)'=u'v+uv'；链式 f(g(x))'=f'(g(x))·g'(x)

## 基本积分

| ∫ f(x) dx | 结果 |
|---|---|
| ∫ xⁿ dx | xⁿ⁺¹/(n+1)+C |
| ∫ 1/x dx | ln|x|+C |
| ∫ eˣ dx | eˣ+C |
| ∫ sin x dx | −cos x+C |
| ∫ cos x dx | sin x+C |

定积分：∫_a^b f(x)dx = F(b)−F(a)

## 微分方程

- 可分离：dy/g(y)=f(x)dx 两边积分
- 一阶线性：y=e^{−∫p dx}[∫q·e^{∫p dx}dx+C]

## 积分技巧

- 分部积分：∫u dv = uv − ∫v du
- 第一换元：令 u=g(x)，∫f(g)g' dx = ∫f(u) du
- 定积分：∫_a^b f dx = F(b)−F(a)

## 常用几何公式

- 两点距离：d=√[(x₂−x₁)²+(y₂−y₁)²]
- 平面方程：A(x−x₀)+B(y−y₀)+C(z−z₀)=0
- 圆：x²+y²=R²；椭圆：x²/a²+y²/b²=1
