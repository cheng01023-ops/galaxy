## 常用极限

- lim_{x→0} (sin x)/x = 1
- lim_{x→∞} (1 + 1/x)^x = e
- lim_{x→0} (1+x)^{1/x} = e
- 0/0、∞/∞ 型可用洛必达法则：lim f/g = lim f'/g'

## 等价无穷小（x→0）

- sin x ~ x，tan x ~ x，arcsin x ~ x，arctan x ~ x
- ln(1+x) ~ x，eˣ−1 ~ x，aˣ−1 ~ x·ln a
- 1−cos x ~ x²/2，(1+x)^α−1 ~ αx

## 基本导数

|  f(x)  |  f'(x)  |
| --- | --- |
|  xⁿ  |  n·xⁿ⁻¹  |
|  eˣ  |  eˣ  |
|  aˣ  |  aˣ·ln a  |
|  ln x  |  1/x  |
|  log_a x  |  1/(x·ln a)  |

运算法则：(uv)'=u'v+uv'；(u/v)'=(u'v−uv')/v²；链式 f(g(x))'=f'(g(x))·g'(x)

## 基本积分

| ∫ f(x) dx | 结果 |
|---|---|
| ∫ xⁿ dx | xⁿ⁺¹/(n+1)+C（n≠−1） |
| ∫ 1/x dx | ln｜x｜+C |
| ∫ eˣ dx | eˣ+C |
| ∫ aˣ dx | aˣ/ln a+C |
| ∫ sin x dx | −cos x+C |
| ∫ cos x dx | sin x+C |
| ∫ sec²x dx | tan x+C |
| ∫ csc²x dx | −cot x+C |
| ∫ sec x·tan x dx | sec x+C |
| ∫ tan x dx | −ln｜cos x｜+C |
| ∫ sec x dx | ln｜sec x+tan x｜+C |
| ∫ 1/(1+x²) dx | arctan x+C |
| ∫ 1/√(1−x²) dx | arcsin x+C |
| ∫ 1/(a²+x²) dx | (1/a)arctan(x/a)+C |
| ∫ 1/(x²−a²) dx | (1/2a)ln｜(x−a)/(x+a)｜+C |

定积分：∫_a^b f(x)dx = F(b)−F(a)；换元必换限

## 积分技巧

- 分部积分：∫u dv = uv − ∫v du（u 的选择：反对幂指三）
- 第一换元：令 u=g(x)，∫f(g)g' dx = ∫f(u) du
- 偶函数对称区间：∫_{−a}^a f dx = 2∫_0^a f dx；奇函数：= 0
- 三角降幂：sin²x=(1−cos2x)/2，cos²x=(1+cos2x)/2

## 常用泰勒展开（x→0）

- eˣ = 1 + x + x²/2! + x³/3! + …
- sin x = x − x³/3! + x⁵/5! − …
- cos x = 1 − x²/2! + x⁴/4! − …
- ln(1+x) = x − x²/2 + x³/3 − …
- 1/(1−x) = 1 + x + x² + x³ + …（|x|<1）

## 微分中值定理

- 罗尔：f(a)=f(b) ⇒ 存在 ξ 使 f'(ξ)=0
- 拉格朗日：f(b)−f(a) = f'(ξ)(b−a)
- 柯西：[f(b)−f(a)]/[g(b)−g(a)] = f'(ξ)/g'(ξ)

## 微分方程

- 可分离：dy/g(y)=f(x)dx 两边积分
- 一阶线性：y=e^{−∫p dx}[∫q·e^{∫p dx}dx+C]
- 二阶常系数齐次：特征根 λ₁≠λ₂ ⇒ C₁e^{λ₁x}+C₂e^{λ₂x}；重根 ⇒ (C₁+C₂x)e^{λx}；复根 α±βi ⇒ e^{αx}(C₁cosβx+C₂sinβx)
- 增长/衰减：y'=ky ⇒ y=Ce^{kx}；半衰期 T=(ln2)/k

## 多元微积分

- 偏导：∂f/∂x 把 y 当常数求导
- 全微分：dz = f_x dx + f_y dy
- 梯度：∇f = (f_x, f_y)，指向增长最快方向
- 方向导数：∂f/∂e = ∇f·e
- 极值判别：A=f_xx, B=f_xy, C=f_yy；AC−B²>0 且 A>0 极小，A<0 极大；AC−B²<0 非极值
- 条件极值：L=f+λg，解 L_x=L_y=L_λ=0
- 二重积分极坐标：x=r cosθ, y=r sinθ，dA = r dr dθ

## 常用几何公式

- 两点距离：d=√[(x₂−x₁)²+(y₂−y₁)²+(z₂−z₁)²]
- 点积：a·b=|a||b|cosθ；a⊥b ⇔ a·b=0
- 点到平面距离：d=|Ax₀+By₀+Cz₀+D|/√(A²+B²+C²)
- 平面方程：A(x−x₀)+B(y−y₀)+C(z−z₀)=0
- 圆：x²+y²=R²；椭圆：x²/a²+y²/b²=1；双曲线：x²/a²−y²/b²=1；抛物线：y²=2px

## 二次曲面

- 球面：x²+y²+z²=R²
- 椭球面：x²/a²+y²/b²+z²/c²=1
- 椭圆抛物面：z=x²/a²+y²/b²；双曲抛物面：z=x²/a²−y²/b²
- 圆锥面：z²=x²+y²；单叶双曲面：x²/a²+y²/b²−z²/c²=1；双叶双曲面：x²/a²−y²/b²−z²/c²=1
