## 一、原函数与不定积分

若 F'(x)=f(x)，则 F(x) 是 f(x) 的一个原函数。

```
∫ f(x) dx = F(x) + C
```

- 原函数不是唯一：F(x)+C 都是原函数（因为常数的导数为 0）
- **C 是任意常数，不能漏**
- 求导与求积分互为逆运算：d/dx [∫f(x)dx] = f(x)；∫ f'(x)dx = f(x)+C

基本性质：

```
∫ [f±g] dx = ∫f dx ± ∫g dx
∫ k·f dx = k·∫ f dx
```

## 三、换元法

### 3.1 第一换元（凑微分）

若 ∫ f(g(x))·g'(x) dx，令 u=g(x)，du=g'(x)dx：

```
∫ f(u) du
```

核心是"看出来" g'(x)dx = d[g(x)]，把 g(x) 整体当自变量。

**例**：∫ 2x·e^{x²} dx，u=x²，du=2x dx

```
= ∫ e^u du = e^u + C = e^{x²} + C
```

**例**：∫ sin(3x) dx，令 u=3x

```
= (1/3)∫ sin u du = −(1/3)cos 3x + C
```

**例**：∫ x·√(1+x²) dx，令 u=1+x²，du=2x dx

```
= (1/2)∫ √u du = (1/2)·(2/3)u^{3/2} + C = (1/3)(1+x²)^{3/2} + C
```

**例**：∫ tan x dx

```
∫ tan x dx = ∫ sin x/cos x dx，令 u=cos x，du=−sin x dx
= −∫ du/u = −ln|u| + C = −ln|cos x| + C
```

### 3.2 第二换元（去根号/三角代换）

被积函数含 √(a²−x²)、√(a²+x²)、√(x²−a²) 时用三角代换：

|  根式  |  代换  |  依据  |
| --- | --- | --- |
|  √(a²−x²)  |  x=a·sin t  |  1−sin²t=cos²t  |
|  √(a²+x²)  |  x=a·tan t  |  1+tan²t=sec²t  |
|  √(x²−a²)  |  x=a·sec t  |  sec²t−1=tan²t  |

**例**：∫ 1/√(1−x²) dx = arcsin x + C（直接用公式）。

**例**：求 ∫ √(1−x²) dx（0≤x≤1 上的半圆面积公式验证）

```
令 x=sin t，dx=cos t dt，√(1−x²)=cos t。
∫ cos²t dt = ∫ (1+cos 2t)/2 dt = t/2 + (sin 2t)/4 + C
回代 t=arcsin x：= (arcsin x)/2 + x√(1−x²)/2 + C
```

> 💡 回代技巧：三角代换后要画直角三角形把 sin/cos 还原成 x 的表达式。

### 3.3 根式代换（补充）

含 √(ax+b) 的一次根式，直接令 t=√(ax+b)。

**例**：∫ 1/(1+√x) dx，令 t=√x，x=t²，dx=2t dt

```
= ∫ 2t/(1+t) dt = ∫ [2 − 2/(1+t)] dt = 2t − 2ln|1+t| + C
= 2√x − 2ln(1+√x) + C
```

## 四、分部积分法

```
∫ u dv = uv − ∫ v du
```

**选择 u 的顺序：反对幂指三**（反三角、对数、幂、指数、三角，越靠左越优先当 u；剩下部分当 dv）。

**例**：∫ x·eˣ dx，取 u=x，dv=eˣ dx

```
= x·eˣ − ∫ eˣ dx = x·eˣ − eˣ + C = eˣ(x−1) + C
```

**例**：∫ x·cos x dx，取 u=x，dv=cos x dx

```
= x·sin x − ∫ sin x dx = x·sin x + cos x + C
```

**例**：∫ ln x dx（对数函数直接当 u）

```
u=ln x，dv=dx ⇒ du=dx/x，v=x
= x·ln x − ∫ x·(1/x) dx = x·ln x − x + C = x(ln x − 1) + C
```

**例**：∫ x²·eˣ dx（需要分部两次）

```
第一次：u=x²，dv=eˣdx ⇒ x²eˣ − 2∫ x·eˣ dx
第二次：∫ x·eˣ dx = eˣ(x−1)（前面例）
= x²eˣ − 2eˣ(x−1) + C = eˣ(x² − 2x + 2) + C
```

**例**：∫ eˣ·sin x dx（"循环积分"：两次分部后出现原积分，移项求解）

```
I = ∫ eˣ sin x dx
= eˣ sin x − ∫ eˣ cos x dx
= eˣ sin x − (eˣ cos x + ∫ eˣ sin x dx)   ← 括号内再分部，出现 I
= eˣ(sin x − cos x) − I
2I = eˣ(sin x − cos x) ⇒ I = eˣ(sin x − cos x)/2 + C
```

## 五、有理函数的部分分式积分

被积函数是分式 P(x)/Q(x)，若分母可因式分解，就拆成简单分式之和。

**例**：∫ 1/[(x−1)(x−2)] dx

```
设 1/[(x−1)(x−2)] = A/(x−1) + B/(x−2)
通分：A(x−2)+B(x−1) = 1
令 x=2：B=1；令 x=1：−A=1 ⇒ A=−1
= ∫ [−1/(x−1) + 1/(x−2)] dx = −ln|x−1| + ln|x−2| + C
= ln|(x−2)/(x−1)| + C
```

> 💡 求 A、B 的快速法（"代入法"）：令 x 分别等于各因式的零点，直接解出系数，比联立方程组快得多。

**例**：∫ (2x+3)/(x²+3x+2) dx

```
分母 = (x+1)(x+2)。设 (2x+3)/[(x+1)(x+2)] = A/(x+1)+B/(x+2)
令 x=−1：A·1 = 1 ⇒ A=1；令 x=−2：B·(−1) = −1 ⇒ B=1
= ∫ [1/(x+1) + 1/(x+2)] dx = ln|x+1| + ln|x+2| + C = ln|(x+1)(x+2)| + C
```

## 六、三角函数的积分技巧

### 6.1 降幂公式（偶次幂必用）

```
sin²x = (1−cos 2x)/2
cos²x = (1+cos 2x)/2
sin x·cos x = (sin 2x)/2
```

**例**：∫ sin²x dx = ∫ (1−cos 2x)/2 dx = x/2 − (sin 2x)/4 + C

### 6.2 奇次幂分离（sin 或 cos 为奇次时）

留一个 sin x（配 cos），其余 sin² 用 1−cos²x 换。

**例**：∫ sin³x·cos²x dx

```
= ∫ sin x·sin²x·cos²x dx = ∫ sin x·(1−cos²x)·cos²x dx
令 u=cos x，du=−sin x dx
= −∫ (1−u²)u² du = −∫ (u²−u⁴) du = −u³/3 + u⁵/5 + C
= −cos³x/3 + cos⁵x/5 + C
```

### 6.3 万能代换（了解）

令 t=tan(x/2)，则 sin x=2t/(1+t²)、cos x=(1−t²)/(1+t²)、dx=2dt/(1+t²)，可将任何三角有理式化为 t 的有理式。一般用于 sin、cos 混合且次数复杂的积分。

## 七、定积分

### 7.1 定义（黎曼和）

把 [a,b] 分成 n 份，取每份内一点 ξᵢ，求和 Σ f(ξᵢ)Δxᵢ，令 n→∞（每份宽度→0）：

```
∫_a^b f(x) dx = lim Σ f(ξᵢ)Δxᵢ
```

**几何意义**：∫_a^b f(x)dx 是曲线与 x 轴围成的**有向面积**——x 轴上方为正、下方为负。因此"总面积"要分段取绝对值。

### 7.2 牛顿-莱布尼茨公式（微积分基本定理）

```
∫_a^b f(x) dx = F(b) − F(a)
```

其中 F 是 f 的任意一个原函数。这个公式把"求和"与"求导"联系起来，是微积分的核心定理。

### 7.3 变上限积分

```
若 Φ(x) = ∫_a^x f(t) dt，则 Φ'(x) = f(x)
```

更一般（复合函数形式）：

```
d/dx [∫_{a}^{g(x)} f(t) dt] = f(g(x))·g'(x)
```

**例**：求 d/dx [∫_0^{x²} sin t dt]

```
= sin(x²)·(x²)' = 2x·sin(x²)
```

### 7.4 性质

```
∫_a^b c·f dx = c·∫_a^b f dx
∫_a^b (f+g) dx = ∫_a^b f dx + ∫_a^b g dx
∫_a^b f dx = −∫_b^a f dx
∫_a^b f dx = ∫_a^c f dx + ∫_c^b f dx
∫_a^a f dx = 0
若在 [a,b] 上 f(x)≥0，则 ∫_a^b f dx ≥ 0
```

### 7.5 对称性（奇偶函数的定积分）

f 在 [−a,a] 上连续：

```
若 f 为偶函数：∫_{−a}^{a} f dx = 2∫_0^a f dx
若 f 为奇函数：∫_{−a}^{a} f dx = 0
```

> 💡 非常好用：碰到对称区间先看奇偶性，能省一半甚至全部计算。

**例**：∫_{−1}^{1} x³·cos x dx。x³ 奇、cos x 偶，乘积为奇函数，积分 = 0。

### 7.6 定积分的换元与分部

**换元必换限**：令 x=φ(t)，则 x=a→t 的下限，x=b→t 的上限，dx=φ'(t)dt：

```
∫_a^b f(x) dx = ∫_{α}^{β} f(φ(t))·φ'(t) dt   （a=φ(α), b=φ(β)）
```

**例**：∫_0^1 x·√(1−x²) dx

```
令 u=1−x²，du=−2x dx；x=0⇒u=1，x=1⇒u=0
= −(1/2)∫_1^0 √u du = (1/2)∫_0^1 u^{1/2} du = (1/2)·(2/3) = 1/3
```

**定积分分部**：

```
∫_a^b u dv = uv|_a^b − ∫_a^b v du
```

**例**：∫_0^1 x·eˣ dx

```
= x·eˣ|_0^1 − ∫_0^1 eˣ dx = (e−0) − (e−1) = 1
```

### 7.7 反常积分（广义积分）

**无穷区间**：

```
∫_a^∞ f dx = lim_{b→∞} ∫_a^b f dx（极限存在则收敛，否则发散）
```

**无界函数**（瑕积分）：f 在 a（或 b）无界时：

```
∫_a^b f dx = lim_{t→a⁺} ∫_t^b f dx（极限存在则收敛）
```

**p-积分（重要结论，背熟）**：

```
∫_1^∞ 1/xᵖ dx：p>1 收敛，p≤1 发散
∫_0^1 1/xᵖ dx：p<1 收敛，p≥1 发散
```

**例**：∫_1^∞ 1/x² dx = lim_{b→∞} [−1/x]_1^b = lim (1 − 1/b) = 1，收敛。

**例**：∫_1^∞ 1/x dx = lim_{b→∞} ln b = ∞，发散。

**例**：∫_0^1 1/√x dx = lim_{t→0⁺} [2√x]_t^1 = 2，收敛（尽管 x=0 处无界）。

> ⚠️ 注意：反常积分必须先判断收敛再"算结果"，∞−∞ 或无界点都可能让"看起来能算"的积分发散。

## 八、定积分应用

- **平面面积**：A = ∫_a^b [上−下] dx（两条曲线之间取 |上−下|）
- **旋转体体积（绕 x 轴，垫片法）**：V = π∫_a^b [f(x)]² dx
- **旋转体体积（绕 y 轴，柱壳法）**：V = 2π∫_a^b x·f(x) dx（f(x)≥0）
- **平面曲线弧长**：L = ∫_a^b √(1 + (f')²) dx
- **参数曲线弧长**：L = ∫_α^β √(x'² + y'²) dt
- **旋转曲面面积（绕 x 轴）**：S = 2π∫_a^b |f(x)|·√(1+(f')²) dx
- **函数平均值**：f̄ = [1/(b−a)]·∫_a^b f(x) dx

**例（面积）**：求 y=x² 与 y=x 围成的面积。

```
交点：x²=x ⇒ x=0 或 1。在 (0,1) 上 y=x 在上方。
A = ∫_0^1 (x − x²) dx = [x²/2 − x³/3]_0^1 = 1/2 − 1/3 = 1/6
```

**例（体积）**：y=x² 在 [0,1] 上绕 x 轴旋转。

```
V = π∫_0^1 x⁴ dx = π·[x⁵/5]_0^1 = π/5
```

**例（弧长）**：y=x^{3/2} 从 x=0 到 x=1。

```
y' = (3/2)√x，L = ∫_0^1 √(1 + 9x/4) dx
= (2/3)·(4/9)·[(1+9x/4)^{3/2}]_0^1 = (8/27)((13/4)^{3/2} − 1)
```

**例（平均值）**：f(x)=x² 在 [0,1] 上的平均值 = ∫_0^1 x² dx / 1 = 1/3。

## 九、例题精讲（12 道）

**例 1**：求 ∫ (3x²−2x+1) dx

```
= 3·x³/3 − 2·x²/2 + x + C = x³ − x² + x + C
```

**例 2**：求 ∫ x·e^{x²} dx

```
令 u=x²，du=2x dx，∫ = (1/2)∫ e^u du = (1/2)e^{x²}+C
```

**例 3**：求 ∫_0^1 x² dx

```
= x³/3 |_0^1 = 1/3 − 0 = 1/3
```

**例 4**：求 ∫ x·cos x dx

```
u=x，dv=cos x dx ⇒ x·sin x + cos x + C
```

**例 5**：求 ∫ x·√(1+x²) dx

```
u=1+x²，du=2x dx ⇒ (1/2)∫√u du = (1/3)(1+x²)^{3/2} + C
```

**例 6**：求 ∫ ln x dx

```
u=ln x，dv=dx ⇒ x ln x − x + C
```

**例 7**：求 ∫ 1/(x²−1) dx

```
= ∫ 1/[(x−1)(x+1)] dx = (1/2)[∫ 1/(x−1) dx − ∫ 1/(x+1) dx]
= (1/2)ln|(x−1)/(x+1)| + C
```

**例 8**：求 ∫_0^π sin x dx

```
= [−cos x]_0^π = −cos π + cos 0 = 1+1 = 2
```

**例 9**：求 ∫_0^1 x·eˣ dx

```
= x·eˣ|_0^1 − ∫_0^1 eˣ dx = e − (e−1) = 1
```

**例 10**：求 ∫_{−1}^{1} (x³ + x²) dx

```
x³ 是奇函数积分为 0；x² 是偶函数 ∫_{−1}^1 x² dx = 2∫_0^1 x² dx = 2/3
答案 = 0 + 2/3 = 2/3
```

**例 11**：求 ∫_1^∞ 1/x² dx

```
= lim_{b→∞} [−1/x]_1^b = lim (1 − 1/b) = 1，收敛。
```

**例 12**：求 y=x² 与 y=x 围成的面积

```
A = ∫_0^1 (x−x²) dx = 1/6（见第八节例）。
```

## 十、练习（12 道，附答案与解析）

1. 求 ∫ (4x³ − 3x² + 2) dx

> 答案：x⁴ − x³ + 2x + C。逐项：4·x⁴/4= x⁴，−3·x³/3=−x³，2x。

2. 求 ∫ sin(3x) dx

> 答案：−(1/3)cos 3x + C。令 u=3x，du=3dx。

3. 求 ∫ 2x·e^{x²} dx

> 答案：e^{x²} + C。令 u=x²，du=2x dx。

4. 求 ∫ x·eˣ dx

> 答案：eˣ(x−1) + C。分部积分，u=x，dv=eˣdx。

5. 求 ∫_1^2 (2x+1) dx

> 答案：4。原函数 x²+x，代入： (4+2)−(1+1)=6−2=4。

6. 求由 y=x² 与 x 轴、x=0、x=1 围成的面积

> 答案：1/3。A = ∫_0^1 x² dx = 1/3。

7. 求 ∫ x·cos(2x) dx

> 答案：(x/2)·sin 2x + (1/4)·cos 2x + C。u=x，dv=cos 2x dx ⇒ v=(1/2)sin 2x。

8. 求 ∫_0^1 x·√(1−x²) dx

> 答案：1/3。令 u=1−x²，换限后 (1/2)∫_0^1 u^{1/2} du = 1/3。

9. 求 ∫ tan x dx

> 答案：−ln|cos x| + C。令 u=cos x。

10. 求 ∫_{−1}^{1} x⁵·cos x dx

> 答案：0。x⁵ 是奇函数，cos x 是偶函数，乘积为奇函数，对称区间积分为 0。

11. 判断 ∫_1^∞ 1/x dx 是否收敛

> 答案：发散。lim_{b→∞} ln b = ∞。

12. 求 y=√x 在 [0,4] 上绕 x 轴旋转所得旋转体体积

> 答案：8π。V = π∫_0^4 x dx = π·[x²/2]_0^4 = 8π。
