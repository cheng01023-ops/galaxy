## 一、不定积分

若 F'(x) = f(x)，则称 F(x) 是 f(x) 的一个原函数。

∫ f(x) dx = F(x) + C

C 是任意常数，千万别漏。

## 二、基本积分表

| ∫ f(x) dx | 结果 |
|---|---|
| ∫ xⁿ dx | xⁿ⁺¹/(n+1) + C（n≠−1） |
| ∫ 1/x dx | ln|x| + C |
| ∫ eˣ dx | eˣ + C |
| ∫ sin x dx | −cos x + C |
| ∫ cos x dx | sin x + C |
| ∫ a dx | ax + C |

## 三、换元法

遇到复合结构，令 u=g(x)：

∫ f(g(x))·g'(x) dx = ∫ f(u) du

例：∫ 2x·e^(x²) dx，令 u=x²，du=2x dx，得 e^u + C = e^(x²) + C

## 四、分部积分法

∫ u dv = uv − ∫ v du

选择 u 的顺序口诀：反对幂指三。

例：∫ x·eˣ dx，取 u=x，dv=eˣ dx，得 x·eˣ − ∫ eˣ dx = x·eˣ − eˣ + C

## 五、定积分

∫_a^b f(x) dx = F(b) − F(a)

（牛顿-莱布尼茨公式：先求原函数，再代上下限相减）

几何意义：曲线与 x 轴围成的有向面积。

## 六、定积分性质

- ∫_a^b c·f dx = c·∫_a^b f dx
- ∫_a^b (f+g) dx = ∫_a^b f dx + ∫_a^b g dx
- ∫_a^b f dx = −∫_b^a f dx
- ∫_a^b f dx = ∫_a^c f dx + ∫_c^b f dx

## 七、应用

- 面积：A = ∫_a^b [上曲线 − 下曲线] dx
- 旋转体体积：V = π∫_a^b [f(x)]² dx
