## 一、原函数与不定积分

若 F'(x)=f(x)，则 F(x) 是 f(x) 的一个原函数。

```
∫ f(x) dx = F(x) + C
```

- 原函数不是唯一：F(x)+C 都是原函数
- **C 是任意常数，不能漏**

基本性质：

```
∫ [f±g] dx = ∫f dx ± ∫g dx
∫ k·f dx = k·∫ f dx
```

## 二、基本积分表（扩展）

| ∫ f(x) dx | 结果 |
|---|---|
| ∫ xⁿ dx | xⁿ⁺¹/(n+1) + C（n≠−1） |
| ∫ 1/x dx | ln|x| + C |
| ∫ eˣ dx | eˣ + C |
| ∫ aˣ dx | aˣ/ln a + C |
| ∫ sin x dx | −cos x + C |
| ∫ cos x dx | sin x + C |
| ∫ sec²x dx | tan x + C |
| ∫ 1/(1+x²) dx | arctan x + C |
| ∫ 1/√(1−x²) dx | arcsin x + C |

## 三、换元法

### 3.1 第一换元（凑微分）

若 ∫ f(g(x))·g'(x) dx，令 u=g(x)，du=g'(x)dx：

```
∫ f(u) du
```

**例**：∫ 2x·e^{x²} dx，u=x²，du=2x dx

```
= ∫ e^u du = e^u + C = e^{x²} + C
```

**例**：∫ sin(3x) dx，令 u=3x

```
= (1/3)∫ sin u du = −(1/3)cos 3x + C
```

### 3.2 第二换元（去根号）

被积函数含 √(a²−x²) 等时，用三角代换。

**例**：∫ 1/√(1−x²) dx = arcsin x + C（直接用公式）。

## 四、分部积分法

```
∫ u dv = uv − ∫ v du
```

**选择 u 的顺序：反对幂指三**（反三角、对数、幂、指数、三角，越靠左越优先当 u）。

**例**：∫ x·eˣ dx，取 u=x，dv=eˣ dx

```
= x·eˣ − ∫ eˣ dx = x·eˣ − eˣ + C = eˣ(x−1) + C
```

**例**：∫ x·cos x dx，取 u=x，dv=cos x dx

```
= x·sin x − ∫ sin x dx = x·sin x + cos x + C
```

## 五、定积分

### 5.1 定义（黎曼和）

把 [a,b] 分成 n 份，取每份内一点 ξᵢ，求和 Σ f(ξᵢ)Δxᵢ，令 n→∞：

```
∫_a^b f(x) dx = lim Σ f(ξᵢ)Δxᵢ
```

### 5.2 牛顿-莱布尼茨公式

```
∫_a^b f(x) dx = F(b) − F(a)
```

### 5.3 变上限积分

```
若 Φ(x) = ∫_a^x f(t) dt，则 Φ'(x) = f(x)
```

### 5.4 性质

```
∫_a^b c·f dx = c·∫_a^b f dx
∫_a^b (f+g) dx = ∫_a^b f dx + ∫_a^b g dx
∫_a^b f dx = −∫_b^a f dx
∫_a^b f dx = ∫_a^c f dx + ∫_c^b f dx
∫_a^a f dx = 0
```

### 5.5 反常积分（简介）

- 无穷区间：∫_a^∞ f dx = lim_{b→∞} ∫_a^b f dx
- 无界函数：∫_a^b f dx 当 f 在端点无界时取极限

---

## 六、定积分应用

- **面积**：A = ∫_a^b [上−下] dx
- **旋转体体积**：V = π∫_a^b [f(x)]² dx
- **弧长**：L = ∫_a^b √(1 + (f')²) dx

## 七、例题精讲

**例 1**：求 ∫ (3x²−2x+1) dx

```
= 3·x³/3 − 2·x²/2 + x + C = x³ − x² + x + C
```

**例 2**：求 ∫ x·e^{x²} dx

```
令 u=x²，du=2x dx，∫ = (1/2)∫ e^u du = (1/2)e^{x²}+C
```

**例 3**：求 ∫_0^1 x² dx

```
= x³/3 |_0^1 = 1/3 − 0 = 1/3
```

**例 4**：求 ∫ x·cos x dx

```
u=x，dv=cos x dx ⇒ x·sin x + cos x + C
```

## 八、练习（附答案）

1. 求 ∫ (4x³ − 3x² + 2) dx

> 答案：x⁴ − x³ + 2x + C。逐项：4·x⁴/4= x⁴，−3·x³/3=−x³，2x。

2. 求 ∫ sin(3x) dx

> 答案：−(1/3)cos 3x + C。令 u=3x，du=3dx。

3. 求 ∫ 2x·e^{x²} dx

> 答案：e^{x²} + C。令 u=x²，du=2x dx。

4. 求 ∫ x·eˣ dx

> 答案：eˣ(x−1) + C。分部积分，u=x，dv=eˣdx。

5. 求 ∫_1^2 (2x+1) dx

> 答案：4。原函数 x²+x，代入： (4+2)−(1+1)=6−2=4。

6. 求由 y=x² 与 x 轴、x=0、x=1 围成的面积

> 答案：1/3。A = ∫_0^1 x² dx = 1/3。
