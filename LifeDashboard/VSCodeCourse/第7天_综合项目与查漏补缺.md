## 第 2 步：文件读写——让数据"活过"程序运行

**问题**：程序一关，内存里的数据全没了。学生成绩一关软件就丢，显然不合格。**文件读写**就是解决这个的。

### 2.1 写入文件（ofstream）

```cpp
#include <fstream>     // 文件读写头文件

ofstream out("students.txt");   // 打开（或创建）文件，准备写入
if (!out) {                     // 打开失败检查（重要！）
    cout << "打开文件失败！" << endl;
    return 1;
}

out << "张三" << " " << 90 << endl;   // 像 cout 一样写入
out << "李四" << " " << 85 << endl;

out.close();                        // 关闭（养成好习惯）
```

**要点：**
- `ofstream`：output file stream，**输出**到文件
- 用法和 `cout` 几乎一样：`out << 内容`
- 文件不存在会自动创建；**存在会被覆盖清空**
- 用前判断 `if (!out)`，用后 `close()`

### 2.2 读取文件（ifstream）

```cpp
ifstream in("students.txt");
if (!in) {
    cout << "文件不存在！" << endl;
    return 1;
}

string name;
int score;
while (in >> name >> score) {      // 像 cin 一样读，读不到就退出循环
    cout << name << " " << score << endl;
}
in.close();
```

**要点：**
- `ifstream`：input file stream，从文件**读取**
- 用法和 `cin` 几乎一样：`in >> 变量`
- `while (in >> ...)`：读到文件末尾自动停止，这是最常用的读法

![文件读写：程序 ⇄ 磁盘文件](demos/demo_fileio.gif)
### 2.3 追加模式

不想覆盖原文件、只想在后面加内容时，用 `ios::app`：

```cpp
ofstream out("log.txt", ios::app);   // append：追加模式
out << "新增一条记录" << endl;
out.close();
```

### 2.4 文件存哪了？

**文件保存在"程序的工作目录"**。在 VSCode 里运行，就是你在终端里运行 `./main` 时所在的文件夹（一般是 `main.cpp` 所在的文件夹）。找它的办法：程序里输出当前路径，或者直接在文件管理器里搜索文件名 `students.txt`。

**马上动手（练习 1）**：写一个程序：第一次运行输入 3 个名字写入文件；第二次运行从文件读出来显示。

## 第 5 步：逐个实现功能

### 5.1 添加学生

```cpp
bool idExists(const string &id) {          // 学号是否已存在（避免重复）
    for (const Student &s : students) {
        if (s.id == id) return true;
    }
    return false;
}

void addStudent() {
    Student s;
    cout << "请输入学号：";
    cin >> s.id;
    if (idExists(s.id)) {
        cout << "该学号已存在，添加失败！" << endl;
        return;
    }
    cout << "请输入姓名：";
    cin >> s.name;
    cout << "请输入语文成绩：";
    cin >> s.chinese;
    cout << "请输入数学成绩：";
    cin >> s.math;
    cout << "请输入英语成绩：";
    cin >> s.english;

    students.push_back(s);          // 第 6 天学的 vector！
    cout << "添加成功！" << endl;
}
```

**用到第 2 天的分支、第 3 天的函数、第 6 天的 vector 和 range-for。**

### 5.2 显示所有学生（表格）

```cpp
void showAll() {
    if (students.empty()) {                    // vector 判空
        cout << "目前没有学生记录。" << endl;
        return;
    }
    cout << "------------------------------------------------" << endl;
    cout << left << setw(10) << "学号" << setw(10) << "姓名"
         << setw(8) << "语文" << setw(8) << "数学"
         << setw(8) << "英语" << setw(8) << "总分" << endl;
    cout << "------------------------------------------------" << endl;
    for (const Student &s : students) {
        cout << left << setw(10) << s.id << setw(10) << s.name
             << setw(8) << s.chinese << setw(8) << s.math
             << setw(8) << s.english << setw(8) << s.total() << endl;
    }
    cout << "------------------------------------------------" << endl;
}
```

**新知识 `setw(10)`**：让输出占 10 个字符宽度，配合 `left` 左对齐，表格才整齐。需要 `#include <iomanip>`。

### 5.3 按学号查找（+ 辅助函数）

```cpp
int findIndexById(const string &id) {     // 找到返回下标，找不到返回 -1
    for (size_t i = 0; i < students.size(); i++) {
        if (students[i].id == id) return (int)i;
    }
    return -1;
}

void findStudent() {
    string id;
    cout << "请输入要查找的学号：";
    cin >> id;
    int idx = findIndexById(id);
    if (idx == -1) {
        cout << "没有找到该学号的学生。" << endl;
        return;
    }
    Student &s = students[idx];
    cout << "姓名：" << s.name << "，语文：" << s.chinese
         << "，数学：" << s.math << "，英语：" << s.english
         << "，总分：" << s.total() << endl;
}
```

### 5.4 修改成绩

```cpp
void modifyStudent() {
    string id;
    cout << "请输入要修改的学号：";
    cin >> id;
    int idx = findIndexById(id);
    if (idx == -1) {
        cout << "没有找到该学号的学生。" << endl;
        return;
    }
    Student &s = students[idx];        // 引用：直接改 vector 里的数据
    cout << "当前成绩：语文 " << s.chinese << "，数学 " << s.math
         << "，英语 " << s.english << endl;
    cout << "请输入新的语文成绩：";
    cin >> s.chinese;
    cout << "请输入新的数学成绩：";
    cin >> s.math;
    cout << "请输入新的英语成绩：";
    cin >> s.english;
    cout << "修改成功！" << endl;
}
```

> 注意 `Student &s = students[idx];` 用了第 4 天的**引用**——这样改 s 就是改 vector 里的原数据。

### 5.5 删除学生

```cpp
void deleteStudent() {
    string id;
    cout << "请输入要删除的学号：";
    cin >> id;
    int idx = findIndexById(id);
    if (idx == -1) {
        cout << "没有找到该学号的学生。" << endl;
        return;
    }
    cout << "确定删除 " << students[idx].name << " 吗？(y/n)：";
    char ch;
    cin >> ch;
    if (ch == 'y' || ch == 'Y') {
        students.erase(students.begin() + idx);   // vector 删除
        cout << "已删除。" << endl;
    } else {
        cout << "已取消。" << endl;
    }
}
```

## 第 6 步：排序 + 文件保存/读取

### 6.1 按总分排序（用 sort + lambda）

```cpp
void sortByTotal() {
    sort(students.begin(), students.end(),
         [](const Student &a, const Student &b) {
             return a.total() > b.total();     // 总分高的排前面
         });
    cout << "已按总分从高到低排序。" << endl;
    showAll();
}
```

**lambda（匿名函数）快速理解**：`[](参数){ 函数体 }` 就是"随手写一个用完即走的小函数"。这里的 `sort` 需要知道"怎么比较两个 Student"，我们通过 lambda 告诉它：按 `total()` 比。

### 6.2 保存与读取

```cpp
void saveToFile() {
    ofstream out(FILE_NAME);
    if (!out) {
        cout << "保存失败：无法打开文件！" << endl;
        return;
    }
    out << students.size() << endl;                 // 第一行写人数
    for (const Student &s : students) {
        out << s.id << " " << s.name << " "
            << s.chinese << " " << s.math << " " << s.english << endl;
    }
    out.close();
    cout << "已保存 " << students.size() << " 条记录。" << endl;
}

void loadFromFile() {
    ifstream in(FILE_NAME);
    if (!in) {
        cout << "没有找到存档，从空名单开始。" << endl;
        return;
    }
    int count = 0;
    in >> count;
    students.clear();                                // 先清空
    for (int i = 0; i < count; i++) {
        Student s;
        in >> s.id >> s.name >> s.chinese >> s.math >> s.english;
        students.push_back(s);
    }
    in.close();
    cout << "已载入 " << students.size() << " 条记录。" << endl;
}
```

**保存格式设计**：第一行人数，后面每行一个学生（字段用空格分隔）。这种"自己定义的简单文本格式"是最常见的入门做法。
