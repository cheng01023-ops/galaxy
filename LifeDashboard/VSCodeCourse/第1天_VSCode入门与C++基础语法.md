## 第 1 步：装好 VSCode 和 C++ 编译器（约 30 分钟）

### 第 1 小步：安装 VSCode

1. 打开浏览器，进入 VSCode 官网：`https://code.visualstudio.com`
2. 点右上角 **Download**，选你的系统（Mac / Windows）
3. 下载后打开安装包：
   - **Mac**：把 VSCode 拖进"应用程序"文件夹；第一次打开时如果系统提示"无法验证开发者"，去 **系统设置 → 隐私与安全性** 点"仍要打开"
   - **Windows**：一路点"下一步"即可（记得勾选"添加到 PATH"）
4. 打开 VSCode，左侧图标栏从上往下是：资源管理器、搜索、源代码管理、运行与调试、扩展……

### 第 2 小步：安装 C/C++ 扩展（必须）

1. 点左侧最下面的 **扩展（Extensions）** 图标（四个小方块）
2. 搜索框输入：**C/C++**
3. 认准发布者是 **Microsoft** 的那个（第一个），点 **Install（安装）**
4. 顺手再装一个 **Code Runner**（也可以不装，后面用官方方式编译）

> 装好扩展后，VSCode 打开 `.cpp` 文件时代码会有颜色高亮、自动补全、报错提示，非常方便。

### 第 3 小步：安装编译器

**👉 Mac 用户：**
1. 打开"终端"（启动台里搜"终端"）
2. 输入下面命令回车：
```bash
xcode-select --install
```
3. 按提示安装 **Command Line Tools**（几分钟）。装好后系统自带 `clang++` 和 `g++`
4. 验证是否成功，输入：
```bash
g++ --version
```
   能看到版本号就 OK 了 ✅

**👉 Windows 用户：**
1. 下载 **MinGW-w64**（推荐用 [winlibs.com](https://winlibs.com) 的发布包，选 UCRT + GCC 最新版）
2. 解压到比如 `C:\mingw64`
3. 把 `C:\mingw64\bin` 加入系统环境变量 PATH
4. 打开"命令提示符"，输入：
```cmd
g++ --version
```
   能看到版本号就 OK 了 ✅

### 第 4 小步：准备一个"代码文件夹"

编程要有条理，给 C++ 建一个专属文件夹：

1. 在"文稿"（或你喜欢的目录）新建文件夹，比如 `CppProjects`
2. 在 VSCode 里：**File → Open Folder…** 打开 `CppProjects`
3. 以后每天的项目都放这里（`day01`、`day02`…… 每个一个小文件夹）

✅ 第 1 步完成！进入第 2 步前，先确认 `g++ --version` 能打印出版本号。

## 第 2 步：编译并运行你的第一个程序

### 第 1 小步：新建 main.cpp

1. 在 VSCode 左侧资源管理器里，点"新建文件"图标
2. 文件名叫 `main.cpp`
3. 输入下面内容（先照着敲一遍，第 2 步会逐行解释）：

```cpp
#include <iostream>
using namespace std;
int main() {
    cout << "Hello, World!" << endl;
    return 0;
}
```

### 第 2 小步：用 VSCode 编译运行（两种方式任选）

**方式 A：终端直接编译（推荐，最直观）**
1. 在 VSCode 里按 **`` Ctrl + ` ``**（Mac 是 **`Control + `**）打开"终端"面板
2. 输入编译命令：
```bash
g++ main.cpp -o main
```
3. 回车后如果没报错，就生成了可执行文件 `main`
4. 再输入运行命令：
```bash
./main
```
5. 终端里打印出 `Hello, World!` 就成功了 🎉

> Mac 上 `g++` 实际是 `clang++` 的别名，用法完全一样。

**方式 B：配置 tasks.json 一键编译（后面每天都省事）**
1. 按 **`Cmd/Ctrl + Shift + B`**，VSCode 会提示"没有构建任务"，点 **Create tasks.json file from template**
2. 选 **Others**
3. 把生成的 `tasks.json` 内容替换成：

```json
{
    "version": "2.0.0",
    "tasks": [
        {
            "label": "build cpp",
            "type": "shell",
            "command": "g++ main.cpp -o main && ./main",
            "group": "build",
            "problemMatcher": []
        }
    ]
}
```
4. 以后每次按 **`Cmd/Ctrl + Shift + B`**，就会"编译并运行"当前的 main.cpp

> ⚠️ 最常犯的错：终端里提示 `command not found: g++`。说明编译器没装好或 PATH 没配好，回到第 1 步第 3 小步检查。

**恭喜！你的 C++ 开发环境已经正式跑通了 🎉**

### 第 3 小步：认识 VSCode 的 4 个区域
- **左侧资源管理器**：看项目文件（我们主要用 `main.cpp`）
- **中间编辑区**：写代码的地方（光标在这里）
- **底部终端/调试控制台**：运行结果显示在这里（`` Ctrl + ` `` 打开终端）
- **顶部菜单**：File、Edit、Run（运行和调试都在这里）

> **小知识**：`g++ main.cpp -o main` 是"编译"——把你写的代码翻译成电脑能懂的机器语言；`./main` 是"运行"——执行编译好的程序。以后你会经常用到这两个命令。

## 第 3 步：逐行看懂 C++ 程序结构

打开 VSCode 里的 `main.cpp`，你会看到类似这样的代码。我们逐行拆开讲：

```cpp
#include <iostream>   // 第 1 行：引入"头文件"
using namespace std;  // 第 2 行：打开"命名空间"
int main() {          // 第 3 行：主函数（程序入口）
    cout << "Hello, World!" << endl;   // 第 4 行：输出一句话
    return 0;         // 第 5 行：告诉系统"正常结束"
}                     // 第 6 行：主函数结束
```

**逐行解释：**

| 行 | 作用 | 打个比方 |
| --- | --- | --- |
| `#include <iostream>` | 引入输入输出工具库，`cout`/`cin` 都来自这里 | 相当于"自带工具箱"：先声明"我要用工具箱里的工具" |
| `using namespace std;` | 允许直接写 `cout`，不用每次写 `std::cout` | 相当于"我默认用标准牌的货" |
| `int main() {` | 主函数，程序从这里开始执行 | 相当于文章的"正文开头" |
| `cout << "..." << endl;` | 向屏幕输出文字，`endl` 表示换行 | 相当于"大声念出一句话" |
| `return 0;` | 告诉操作系统程序正常结束，返回 0 给操作系统 | 相当于"鞠躬退场，表示结束" |
| `}` | 主函数结束 | 正文结束 |

**三条黄金规则（今天就要记住）：**
1. **每一条语句结尾都要有分号 `;`** —— 忘了分号是新手第一号报错原因
2. **花括号要成对出现** `{ }` —— VSCode 会自动帮你配对，注意缩进
3. **代码是"从上往下"执行的** —— 第 1 行先跑，再第 2 行……

## 第 4 步：用 cout 让程序"说话"

`cout` 念作"see-out"，意思是"输出"。用法：`cout << 内容 << endl;`，箭头方向**指向屏幕**。

```cpp
#include <iostream>
using namespace std;
int main() {
    cout << "你好，世界！" << endl;
    cout << "我的年龄是" << 18 << "岁";    // 文字和数字混着输出
    return 0;
}
```

**注意三点：**
1. **字符串（文字）要用双引号** `"..."`；单引号是给单个字符用的（后面讲）
2. 可以一次输出很多段：`cout << A << B << C << endl;` 会按顺序拼在一起
3. `endl` 是"换行"，相当于按一次回车

**马上动手：** 把上面代码敲进 `main.cpp`，`g++ main.cpp -o main && ./main` 跑一遍，再改成输出你自己的名字和年龄。

## 第 5 步：变量与 5 种基本类型

**变量 = 带名字的"储物盒"**，用来存数据，值可以变：

```
int age = 18;        // 整数
double height = 1.75;  // 小数
char grade = 'A';    // 单个字符（单引号！）
bool isHappy = true; // 真假
string name = "小明"; // 字符串（双引号！）
```

**5 种基本类型速查：**

| 类型 | 存什么 | 例子 |
| --- | --- | --- |
| `int` | 整数 | `-5`、`0`、`100` |
| `double` | 小数 | `3.14`、`-0.5` |
| `char` | 单个字符 | `'A'`、`'7'` |
| `bool` | 真假 | `true`、`false` |
| `string` | 一串文字 | `"hello"` |

**变量三件事：声明 → 赋值 → 使用**。声明就是"我要一个叫 age 的整数盒子"：

```cpp
int age;        // 声明
age = 18;       // 赋值
cout << age;    // 使用
```

> ⚠️ **变量必须先赋值再使用**，否则里面是"随机垃圾值"，输出结果不可预料。VSCode 里如果用了没初始化的变量，会看到黄色波浪线提示。

**马上动手：** 写一个程序，声明一个 `int`、一个 `double`、一个 `string`，把三个值都 `cout` 出来。

## 第 6 步：用 cin 让程序"听懂你"

`cin` 念作"see-in"，意思是"输入"。箭头方向**指向变量**：`cin >> 变量;`

```cpp
#include <iostream>
using namespace std;
int main() {
    int age;
    cout << "请输入你的年龄：";
    cin >> age;
    cout << "你输入的年龄是：" << age << endl;
    return 0;
}
```

**运行后**：程序停下来等你输入 → 输入 `18` 按回车 → 输出 `你输入的年龄是：18`。

> ⚠️ 运行时输入没反应？在 VSCode 里运行程序时，**要先用鼠标点一下终端/调试控制台**，让光标聚焦在那里，再打字。

**马上动手：** 写一个程序，输入一个名字和一个年龄，然后输出"XX 今年 XX 岁"。

## 第 7 步：运算符与"整数除法"大坑

**常用运算符：**

| 运算符 | 含义 | 例子 | 结果 |
| --- | --- | --- | --- |
| `+` | 加 | `7 + 2` | 9 |
| `-` | 减 | `7 - 2` | 5 |
| `*` | 乘 | `7 * 2` | 14 |
| `/` | 除 | `7 / 2` | **3（！）** |
| `%` | 取余 | `7 % 2` | 1 |
| `++` | 自增 1 | `i++` | i 变 i+1 |
| `--` | 自减 1 | `i--` | i 变 i-1 |

> ⚠️ **整数除法会丢小数**：`7 / 2` 在 C++ 里结果是 `3`，不是 `3.5`！因为两个整数相除结果还是整数。想要小数，至少让一边是小数：`7.0 / 2` 或 `7 / 2.0`。

```cpp
cout << 7 / 2 << endl;    // 输出 3
cout << 7.0 / 2 << endl;  // 输出 3.5
```

**混合计算顺序**：和数学一样，`*` `/` `%` 优先于 `+` `-`，想改顺序就加括号。

**马上动手：** 输入两个数，输出它们的和、差、积、商（注意小数）。

## 第 8 步：综合小项目——温度转换器（把前 6 步串起来）

把今天学的东西全部用上：变量、输入、输出、运算符、类型转换。

```cpp
#include <iostream>
using namespace std;
int main() {
    double celsius;
    cout << "请输入摄氏温度：";
    cin >> celsius;

    double fahrenheit = celsius * 9.0 / 5 + 32;

    cout << celsius << " 摄氏度 = " << fahrenheit << " 华氏度" << endl;
    return 0;
}
```

1. 敲进去，`g++ main.cpp -o main && ./main` 运行
2. 输入 `25`，看到输出 `25 摄氏度 = 77 华氏度`
3. 试着输入带小数的温度，比如 `36.6`

> 为什么 `9.0` 不写 `9`？因为 `celsius * 9 / 5` 里如果都是整数会丢小数（第 7 步的坑）。

## 第 9 步：断点调试——学会自己找 bug

程序结果不对时，**不要瞎猜**，用调试器一步步看变量值。VSCode 的调试比 Xcode 还直观：

### 第 1 步：给项目配置调试（launch.json，第一次才需要）

1. 点 VSCode 左侧的 **运行与调试（Run and Debug）** 图标（三角形 + 小虫）
2. 点 **create a launch.json file**
3. 选 **C++ (GDB/LLDB)**
4. 生成的 `launch.json` 里，把 `program` 改成 `"${fileDirname}/main"`（其他保持默认），大致如下：

```json
{
    "version": "0.2.0",
    "configurations": [
        {
            "name": "C/C++: g++ 编译并调试",
            "type": "cppdbg",
            "request": "launch",
            "program": "${fileDirname}/main",
            "preLaunchTask": "build cpp",
            "cwd": "${workspaceFolder}",
            "MIMode": "lldb",
            "externalConsole": false
        }
    ]
}
```

> 其中 `preLaunchTask: "build cpp"` 会先自动编译再开始调试（对应第 2 步配置的 tasks.json）。

### 第 2 步：打断点
- 在代码**行号左侧点一下**，会出现一个**红点**，这就是"断点"
- 程序运行到这一行会**暂停**，不再往下执行

### 第 3 步：开始调试
- 按 **`F5`**（或点运行与调试面板的绿色 ▶）
- 程序停在断点那一行
- **调试控制台/变量面板**会实时显示当前所有变量的值——**这就是你找 bug 的放大镜**

### 第 4 步：单步执行
- 顶部调试工具栏：**Continue（继续）**、**Step Over（跳过）**、**Step Into（进入函数）**、**Step Out（跳出）**、**Stop（停止）**
- 每点一下 Step Over，程序走一行，变量面板跟着变

**一个必做的调试练习：**
在温度转换器里，把断点打在 `double fahrenheit = ...` 那一行，按 `F5` 运行后：
1. 输入 `25`
2. 断点触发，看变量面板里 `celsius` 是不是 25
3. 单步执行一行，再看 `fahrenheit` 变成了多少
4. 你会发现：程序的每一步，你都能亲眼看到

> 💡 调试心法：**结果不对 → 打断点 → 看变量在哪一步变得不符合预期 → 那一步就是 bug 所在。**

## 🏋️ 分级练习（先自己想 10 分钟，再看答案）

**练习 A（基础）：圆的面积**
输入半径 `r`，输出圆面积（`面积 = 3.14159 × r × r`）。
提示：r 可能是小数，用 double；注意乘法不要用 × 符号，用 `*`。

<details><summary>点开看答案</summary>

```cpp
#include <iostream>
using namespace std;
int main() {
    double r;
    cout << "请输入半径：";
    cin >> r;
    double area = 3.14159 * r * r;
    cout << "圆的面积是：" << area << endl;
    return 0;
}
```
</details>

**练习 B（进阶）：三位数反转**
输入一个三位数（如 123），输出反转后的数（321）。
提示：用 `%` 取出个位，用 `/` 去掉个位，拆成百位、十位、个位再重组。

<details><summary>点开看答案</summary>

```cpp
#include <iostream>
using namespace std;
int main() {
    int n;
    cout << "请输入一个三位数：";
    cin >> n;

    int ge = n % 10;        // 个位：n 除以 10 的余数
    int shi = n / 10 % 10;  // 十位：先去掉个位，再取余
    int bai = n / 100;      // 百位：直接除以 100

    cout << "反转后：" << ge << shi << bai << endl;
    return 0;
}
```
</details>

**练习 C（挑战）：秒数换算**
输入一个秒数（如 3661），输出它是几小时几分几秒（3661 秒 = 1 小时 1 分 1 秒）。
提示：`小时 = 秒 / 3600`，`剩余秒 = 秒 % 3600`，`分钟 = 剩余秒 / 60`，`秒 = 剩余秒 % 60`。

<details><summary>点开看答案</summary>

```cpp
#include <iostream>
using namespace std;
int main() {
    int total;
    cout << "请输入秒数：";
    cin >> total;

    int h = total / 3600;
    int m = total % 3600 / 60;
    int s = total % 60;

    cout << h << " 小时 " << m << " 分 " << s << " 秒" << endl;
    return 0;
}
```
</details>

## ⚠️ 今日坑点汇总（记下来，都是过来人的血泪）

| 坑 | 说明 | 正确做法 |
| --- | --- | --- |
| `command not found: g++` | 编译器没装好或 PATH 没配 | 回第 1 步第 3 小步检查 |
| 字符串用单引号 | `"小明"` 写成 `'小明'` 编译报错 | string 用双引号 |
| 整数除法丢小数 | `7/2` 得 3 | 至少一边写成小数 |
| `=` 当 `==` 用 | 判断写成赋值，恒为真 | 判断相等用 `==` |
| 变量没赋值就输出 | 输出随机垃圾值 | 先赋值再使用 |
| 忘了写分号 | 编译报错 | 每条语句结尾 `;` |
| 运行时输入没反应 | 光标不在终端/控制台 | 先点击终端再输入 |
| 改了代码没生效 | 忘了重新编译 | 每次 `g++ main.cpp -o main` 后再运行 |
