## 第 1 步：为什么要类？

**回想第 3 天**：我们用一个数组存 5 个成绩，再用一个函数求平均。

```cpp
int scores[5] = {88, 92, 76, 85, 90};
double average(int arr[], int n);   // 函数在"外面"处理数据
```

**现在来个更复杂的场景**：要管理一个学生，他有**名字、年龄、成绩**，还要能"打印信息""改成绩"。用现在的知识会写成：

```cpp
string name = "小明";
int age = 18;
double score = 88.5;

void printInfo(string n, int a, double s) { ... }
void setScore(double s) { ... }     // 问题：怎么"改"外面的 score？
```

**痛点很明显：**
1. 数据散落各处，和操作它的函数**没有绑定关系**
2. 函数想改数据，得靠引用参数传进传出，啰嗦
3. 如果有 3 个学生，就得 9 个变量、一堆函数，完全失控

**类的解决思路**：把"学生的数据"和"学生能做的事"**装进同一个模具**，用模具造出任意多个学生对象：

```
class Student（模具）
├── 数据：name, age, score
└── 行为：printInfo(), setScore()
        ↓ 用模具造
s1（小明）  s2（小红）  s3（小刚）...
```

**术语：**
- **类（class）**：模具/模板，描述"有什么数据、能做什么"
- **对象（object）**：用模具造出来的具体实例

---

![类与对象：一个模具造出多个实例](demos/demo_class.gif)
> 🗣️ 大白话：类 = **蛋糕模具**（描述形状），对象 = 用模具做出来的**蛋糕**（具体的一块）。一个模具可以做出无数块蛋糕，每块都有自己的馅料（数据）。

## 第 2 步：struct——最朴素的"数据打包"

先看 C++ 里最简单的打包工具 `struct`（结构体）：

```cpp
struct Student {
    string name;
    int age;
    double score;
};
```

```cpp
Student s1;              // 造一个学生
s1.name = "小明";         // 直接访问成员（. 点号）
s1.age = 18;
s1.score = 88.5;

cout << s1.name << " " << s1.age << " " << s1.score << endl;
```

**和数组对比**：数组是一排"同类型"的格子；结构体是把"不同类型"的数据捆在一起。`s1.name` 用点号访问。

**struct 的局限**：它只是"数据容器"，没法把"行为（函数）"也带进去（虽然能加，但默认全公开，不安全）。真正强大的是 `class`。

## 第 3 步：class 与访问权限

### 3.1 定义一个类

```cpp
class Student {
public:                       // 公有：外部可以访问/调用
    string name;
    int age;

    void printInfo() {        // 成员函数：和这个类的数据"绑在一起"
        cout << name << " " << age << endl;
    }
};
```

**成员函数里可以直接用成员变量**（不用传参，因为函数本来就属于这个对象）。

```cpp
Student s1;
s1.name = "小明";
s1.printInfo();      // 输出：小明 18
```

### 3.2 三种访问权限

| 关键字 | 外部能否访问 | 子类能否访问 | 用途 |
| --- | --- | --- | --- |
| `public` | ✅ | ✅ | 对外提供的方法 |
| `private` | ❌ | ❌ | 内部数据，不让外面乱碰 |
| `protected` | ❌ | ✅ | 第 6 天学继承时用 |

```cpp
class BankAccount {
private:
    double balance;          // 私有：外面碰不到

public:
    void deposit(double m) { balance += m; }   // 公有：通过方法操作
};
```

```cpp
BankAccount acc;
// acc.balance = 999;        // ❌ 编译错误：balance 是 private
acc.deposit(100);            // ✅ 通过公有方法操作
```

**为什么要把数据设 private？** 防止被乱改。想想：余额可以被随便赋成负数、被清零，银行还不乱套？把数据锁起来，只留"受控的通道"，这就是**封装**的雏形。

> 设计原则：**成员变量默认 private，操作走公有方法。**

## 第 4 步：构造函数——创建时自动初始化

### 4.1 问题

```cpp
Student s1;
cout << s1.name;    // ⚠️ name 没赋值，输出垃圾
```

每次创建对象后都要手动赋值，容易忘。**构造函数**就是用来解决这个的：**创建对象时自动执行**，负责初始化。

### 4.2 定义构造函数

```cpp
class Student {
private:
    string name;
    int age;
    double score;

public:
    // 构造函数：名字和类名一样，没有返回值类型
    Student(string n, int a, double s) {
        name = n;
        age = a;
        score = s;
    }

    void printInfo() {
        cout << name << " " << age << " " << score << endl;
    }
};
```

```cpp
Student s1("小明", 18, 88.5);   // 创建时自动调用构造函数，完成初始化
Student s2("小红", 19, 95.0);
s1.printInfo();
```

**创建对象时的执行顺序**：分配内存 → 执行构造函数 → 对象可用。

### 4.3 初始化列表（更推荐的写法）

```cpp
Student(string n, int a, double s) : name(n), age(a), score(s) {
    // 函数体里可以什么都不写
}
```

**冒号后面的部分**就是初始化列表：直接初始化成员。效率和安全性都更好，第 6 天继承时你还会再见到它。

### 4.4 默认构造函数

如果不写任何构造函数，编译器会生成一个"什么都不做的默认构造函数"。**但一旦你写了带参数的构造函数，默认构造函数就没了**：

```cpp
class Student {
public:
    Student(string n) { ... }
};
Student s1;        // ❌ 编译错误！没有无参构造函数了
Student s2("小明"); // ✅
```

## 第 5 步：析构函数——销毁时自动清理

**析构函数（destructor）**和构造函数相反：**对象销毁时自动执行**，用来做清理（比如释放对象内部 new 的内存）。

```cpp
class Student {
public:
    ~Student() {              // 名字是 ~类名，没有参数，没有返回值
        cout << "学生对象被销毁了" << endl;
    }
};
```

**什么时候销毁？** 对象离开它所在的花括号作用域时：

```cpp
int main() {
    {
        Student s("小明", 18, 90);
        // 使用 s...
    }                          // ← 到这里 s 销毁，析构函数自动执行
    cout << "main 继续" << endl;
    return 0;
}
// 输出：
// 学生对象被销毁了
// main 继续
```

**为什么要学它？** 如果一个类内部用 `new` 申请了内存，必须在析构函数里 `delete`，否则内存泄漏。标准写法：

```cpp
class DynamicArray {
private:
    int *data;
    int size;
public:
    DynamicArray(int n) {
        size = n;
        data = new int[n];          // 申请
    }
    ~DynamicArray() {
        delete[] data;              // 释放（析构函数的经典用途）
        data = nullptr;
    }
};
```

## 第 6 步：封装——getter / setter

**封装 = 数据私有 + 通过受控方法访问**。核心收益是：**可以在方法里做检查，拦住非法数据**。

```cpp
class Student {
private:
    double score;
public:
    void setScore(double s) {
        if (s >= 0 && s <= 100) {
            score = s;                 // 合法才更新
        } else {
            cout << "成绩必须在 0~100 之间！" << endl;
        }
    }
    double getScore() {
        return score;                  // 只读返回
    }
};
```

```cpp
Student s("小明", 18, 88);
s.setScore(120);     // 被拦住：成绩必须在 0~100 之间！
s.setScore(92);      // 合法，更新成功
cout << s.getScore(); // 92
```

![封装：非法数据被 setter 拦截](demos/demo_encapsulation.gif)
**命名约定**：`getXxx()` 取值，`setXxx()` 设值，一目了然。

**封装的三大好处：**
1. **防呆**：非法数据进不来（成绩 120、余额负数）
2. **灵活**：以后想加规则（比如改成绩要记录日志），只改 setter 一处
3. **稳定**：内部实现随便改，对外接口不变，调用方不用动

**马上动手（练习 3）**：给 BankAccount 加 `getBalance()` 和 `withdraw()`，取款时检查余额是否足够。

<details><summary>点开看参考答案</summary>

```cpp
#include <iostream>
using namespace std;

class BankAccount {
private:
    string owner;
    double balance;
public:
    BankAccount(string o, double b) : owner(o), balance(b) {}

    void deposit(double m) {
        if (m > 0) balance += m;
    }
    bool withdraw(double m) {
        if (m > 0 && m <= balance) {   // 余额足够才放行

            return true;

        return false;

    acc.deposit(200);
    cout << "余额：" << acc.getBalance() << endl;   // 1200
    acc.withdraw(5000);                             // 被拦

    return 0;
```

## 第 7 步：this 指针 + 静态成员

### 7.1 this 指针

**`this` 指向"当前这个对象"**。当参数名和成员变量同名时，用它区分：

```cpp
class BankAccount {
private:
    double balance;
public:
    void deposit(double balance) {      // 参数和成员同名了
        this->balance += balance;       // this->balance 是成员，右边是参数
    }
};
```

- `this->balance`：当前对象的成员变量
- `balance`：参数

`this` 也可以用来"返回自己"，实现链式调用：

```cpp
class Counter {
private:
    int value = 0;
public:
    Counter &add(int n) { value += n; return *this; }   // 返回自身引用
    int get() { return value; }
};

Counter c;
c.add(1).add(2).add(3);   // 链式调用
cout << c.get();          // 6
```

### 7.2 静态成员：属于"类"，不属于"对象"

普通成员每个对象各有一份；**静态成员（static）所有对象共享一份**：

```cpp
class BankAccount {
private:
    static int totalAccounts;    // 所有账户共享这个计数器
    string owner;
public:
    BankAccount(string o) {
        owner = o;
        totalAccounts++;          // 每创建一个账户 +1
    }
    static int getTotal() {       // 静态成员函数
        return totalAccounts;
    }
};

// 静态成员必须在类外定义并初始化（重要！）
int BankAccount::totalAccounts = 0;
```

```cpp
BankAccount a("小明"), b("小红"), c("小刚");
cout << BankAccount::getTotal();   // 3（用"类名::"调用）
```

**理解**：静态成员像是挂在"类"这个大门上的公告板，所有对象都能看，谁都能改；访问用 `类名::`，不需要对象。

### 8.2 综合项目：迷你银行账户系统

把今天学的全用上，做一个"开两个账户、存款取款、显示总账户数"的小系统：

```cpp
#include <iostream>
#include <string>
using namespace std;

class BankAccount {
private:
    string owner;
    double balance;
    static int totalAccounts;

public:
    BankAccount(string o, double b) : owner(o), balance(b) {
        totalAccounts++;
        cout << "开户成功：" << owner << endl;
    }

    ~BankAccount() {
        cout << "账户已注销：" << owner << endl;
    }

    void deposit(double money) {
        if (money > 0) {
            balance += money;
            cout << owner << " 存入 " << money << " 元" << endl;
        }
    }

    bool withdraw(double money) {
        if (money > 0 && money <= balance) {
            balance -= money;
            cout << owner << " 取出 " << money << " 元" << endl;
            return true;
        }
        cout << owner << " 取款失败：余额不足" << endl;
        return false;
    }

    void show() {
        cout << owner << " 的余额：" << balance << " 元" << endl;
    }

    static int getTotal() { return totalAccounts; }
};

int BankAccount::totalAccounts = 0;

int main() {
    BankAccount acc1("小明", 1000);
    BankAccount acc2("小红", 500);

    acc1.deposit(200);
    acc1.withdraw(150);
    acc1.show();

    cout << "当前共有账户：" << BankAccount::getTotal() << " 个" << endl;
    return 0;
}
```

**逐段精讲：**
- `private` 数据 + `public` 方法：封装
- 构造函数里 `totalAccounts++`：静态成员统计开户数
- `withdraw` 里检查余额：防呆
- 析构函数输出提示：观察对象生命周期
- `BankAccount::getTotal()`：用类名访问静态方法

1. 类是模具/模板，对象是用模具造出来的具体实例。
2. public 外部可访问，private 外部不可访问；设 private 能保护数据不被乱改。
3. 创建对象时自动执行；名字与类名相同，无返回值类型。
4. 对象销毁时自动执行；典型用途是释放 new 的内存。
5. 构造函数签名后冒号跟着 `: 成员(值), ...`；用来直接初始化成员。
6. 指向当前对象的指针；参数与成员同名时用 this-> 区分。
7. 静态成员属于类、所有对象共享一份；用 `类名::成员` 访问。
8. 防呆（拦截非法数据）、内部实现可灵活修改、对外接口稳定。
9. 不能，一旦自定义了构造函数，默认无参构造函数就不存在了。
10. 对象数组的元素是对象，创建时逐个调用构造函数，可用下标访问并调用成员函数。

## ⚠️ 今日坑点汇总

| 坑 | 说明 | 正确做法 |
| --- | --- | --- |
| 忘了初始化列表/构造函数 | 成员是垃圾值 | 用构造函数初始化 |
| 成员全 public | 数据可以被乱改 | 数据 private + getter/setter |
| 静态成员忘在类外定义 | 链接报错 | `int 类名::成员 = 初始值;` |
| 自定义构造后无参创建 | 编译错误 | 要么补默认构造，要么传参创建 |
| 析构忘释放内存 | 内存泄漏 | 在析构里 delete/delete[] |
| 参数与成员同名 | 赋值给参数自己 | 用 this-> 区分 |
