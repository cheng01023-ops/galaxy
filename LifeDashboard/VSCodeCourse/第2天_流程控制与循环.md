## 第 1 步：回顾昨天 + 为什么要学"流程控制"

昨天写的程序是**直线型**的：从上到下一条路走到底。

```cpp
cin >> score;            // 读入成绩
cout << score;           // 输出成绩
return 0;                // 结束
```

但真实程序需要**岔路口**和**回路**：
- 成绩 ≥ 60 说"及格"，否则说"不及格" —— 这是**判断**
- 把 1 到 100 全部加起来 —— 这是**循环**

今天学的 `if` 和 `for` 等，就是用来搭"岔路口"和"回路"的零件。

## 第 2 步：if 判断——让程序做选择

### 2.1 最简单的 if（满足才执行）

```cpp
if (score >= 60) {
    cout << "及格" << endl;
}
```

**执行过程**（画一条线在脑子里）：
1. 先算括号里的条件：`score >= 60` 是真还是假？
2. 条件为真 → 执行大括号里的代码
3. 条件为假 → 跳过，什么都不做

```cpp
int score = 80;
if (score >= 60) {          // 80 >= 60 为真
    cout << "及格" << endl;  // 执行这行 → 输出"及格"
}
```

### 2.2 if-else（二选一）

```cpp
if (score >= 60) {
    cout << "及格" << endl;
} else {
    cout << "不及格" << endl;
}
```

**关键理解**：`if` 和 `else` **只会走一边**，永远不会两个都执行。就像过安检：符合条件走这边，不符合走那边。

![if 判断：条件为真走「是」分支](demos/demo_if.gif)
### 2.3 if-else if-else（多选一）

```cpp
if (score >= 90) {
    cout << "优秀" << endl;
} else if (score >= 70) {
    cout << "良好" << endl;
} else if (score >= 60) {
    cout << "及格" << endl;
} else {
    cout << "不及格" << endl;
}
```

**执行规则（重要）**：从上往下，**第一个条件成立的那个分支执行，后面的都不再看**。

> 💡 所以条件的顺序很重要！如果把 `score >= 60` 写在最前面，那么 95 分也会先命中"及格"而不是"优秀"——因为 95 >= 60 已经成立了。**顺序 = 从严格到宽松**。

### 2.4 常见误区

```cpp
if (score >= 60); {          // ❌ if 后面多了分号！{} 变成普通代码块，永远执行
    cout << "及格" << endl;
}

if (score = 60) { ... }      // ❌ 一个等号是赋值！赋值结果是 60（非 0 为真），恒成立
if (score == 60) { ... }     // ✅ 两个等号才是判断相等
```

## 第 3 步：复杂条件——比较运算符 + 逻辑运算符

有时一个条件不够，需要组合。

**比较运算符**（结果都是"真/假"）：

| 运算符 | 含义 | 例子 |
| --- | --- | --- |
| `==` | 等于 | `a == b` |
| `!=` | 不等于 | `a != b` |
| `>` `<` | 大于 / 小于 | `a > 0` |
| `>=` `<=` | 大于等于 / 小于等于 | `a >= 0` |

**逻辑运算符**（组合多个条件）：

| 运算符 | 读法 | 规则 | 例子 |
| --- | --- | --- | --- |
| `&&` | 并且 | **两边都真**才真 | `age >= 18 && age <= 60` |
| `\|\|` | 或者 | **一边真**就真 | `score < 60 \|\| score > 100` |
| `!` | 非 | 真变假、假变真 | `!ok` |

**完整例子：判断一个年份是否是闰年**

规则：能被 4 整除**且**不能被 100 整除，**或者**能被 400 整除。

```cpp
int year = 2024;
bool isLeap = (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0);
if (isLeap) {
    cout << year << " 是闰年" << endl;
} else {
    cout << year << " 不是闰年" << endl;
}
```

**逐行理解：**
- `year % 4 == 0`：能被 4 整除吗？（2024 能 → 真）
- `year % 100 != 0`：不能被 100 整除吗？（2024 能 → 真）
- `&&`：两边都真 → 真
- `||`：左边已经真了 → 整体真 → 2024 是闰年 ✅

**马上动手（练习 2）**：输入三个数，判断是否**能构成三角形**（任意两边之和大于第三边）。

## 第 4 步：switch——处理"多个固定选项"

当判断的对象是**一个变量的多个固定取值**时，用 `switch` 更清晰。

```cpp
int week;
cout << "输入星期几（1-7）：";
cin >> week;

switch (week) {
    case 1: cout << "星期一" << endl; break;
    case 2: cout << "星期二" << endl; break;
    case 3: cout << "星期三" << endl; break;
    case 4: cout << "星期四" << endl; break;
    case 5: cout << "星期五" << endl; break;
    case 6: cout << "星期六" << endl; break;
    case 7: cout << "星期日" << endl; break;
    default: cout << "输入无效" << endl; break;
}
```

**语法要点：**
- `case 值:` 后面是"当变量等于这个值时要做的"
- **每个 case 结尾必须有 `break;`**，否则会"穿透"（fall-through）继续执行下一个 case 的代码——这是 switch 最大的坑
- `default`：所有 case 都不匹配时执行，相当于 else

**穿透演示**（故意去掉 break 看效果）：

```cpp
int n = 2;
switch (n) {
    case 1: cout << "一";
    case 2: cout << "二";      // 从这开始
    case 3: cout << "三";      // 没有 break，一路执行到这里
}
// 输出：二三
```

**switch vs if 怎么选？** 判断的是"同一个变量的具体取值"→ switch；判断的是"范围"（如 ≥60）或"多个条件组合" → if。

**马上动手（练习 3）**：输入 1~5 的一个数，输出对应的"第几季度/阶段"（1=入门, 2=基础, 3=进阶, 4=熟练, 5=精通），超出范围提示无效。

<details><summary>点开看参考答案</summary>

```cpp

using namespace std;
int main() {
    int level;
    cout << "输入你的等级（1-5）：";
    cin >> level;
    switch (level) {
        case 1: cout << "入门" << endl; break;
        case 2: cout << "基础" << endl; break;

        default: cout << "无效等级" << endl; break;

```

## 第 5 步：while 循环——只要条件成立就一直做

**问题：把 1 加到 100，怎么写？** 复制粘贴 100 行显然不行。循环就是答案。

```cpp
int sum = 0;      // 放结果的"存钱罐"，先放 0
int i = 1;        // 从 1 开始
while (i <= 100) {          // 只要 i 不超过 100
    sum += i;               // 把 i 加进存钱罐
    i++;                    // i 加 1（必须有！否则死循环）
}
cout << "1+2+...+100 = " << sum << endl;   // 5050
```

**执行过程（关键）**：
1. 判断 `i <= 100` 是真吗？
2. 真 → 执行大括号里的两行（`sum += i; i++;`）→ 回到第 1 步
3. 假 → 跳出循环，继续往下

```
i=1: 判断真 → sum=1, i=2
i=2: 判断真 → sum=3, i=3
i=3: 判断真 → sum=6, i=4
...
i=100: 判断真 → sum=5050, i=101
i=101: 判断假 → 跳出 ✅
```

**死循环（必踩的坑）**：如果忘记写 `i++`，i 永远等于 1，条件永远成立，程序永远停不下来。

```cpp
int i = 1;
while (i <= 100) {   // ❌ 没有 i++，死循环！
    sum += i;
}
```

> 遇到程序"卡死不动"，第一反应：**是不是死循环了？** 按 `Cmd + .` 或点 ■ 停止程序。

**while 适合什么场景？** 不知道要循环多少次，只知道"什么时候停"（比如一直输入直到输入 -1 为止）。

**马上动手（练习 4）**：用 while 循环，让用户不断输入数字并累加，**直到输入 0 为止**，最后输出总和。

<details><summary>点开看参考答案</summary>

```cpp
#include <iostream>
using namespace std;
int main() {
    int n, sum = 0;
    cout << "输入数字累加（输入 0 结束）：" << endl;
    cin >> n;
    while (n != 0) {
        sum += n;
        cin >> n;          // 再读下一个
    }
    cout << "总和 = " << sum << endl;
    return 0;
}
```
</details>

## 第 6 步：for 循环——知道次数时用它

**for 循环把"起点、条件、步长"写在一行**，比 while 更紧凑：

```cpp
for (int i = 1; i <= 100; i++) {
    sum += i;
}
```

拆解三部分（用分号隔开）：
- `int i = 1`：**起点**（循环前执行一次）
- `i <= 100`：**条件**（每次循环前判断，真就继续）
- `i++`：**步长**（每次循环体执行完执行）

**执行顺序**：起点 → 判断条件 → 执行循环体 → 步长 → 判断条件 → ... → 条件为假跳出

```
i=1 → 判断(1<=100真) → 执行 → i=2 → 判断(2<=100真) → 执行 → ... → i=101 → 判断(假) → 跳出
```

**三种写法对比（效果一样）：**

```cpp
// while 版
int i = 1;
while (i <= 100) { sum += i; i++; }

// for 版（最推荐，结构清晰）
for (int i = 1; i <= 100; i++) { sum += i; }

// for 另一种常见写法：从 0 开始
for (int i = 0; i < 100; i++) { ... }   // 循环 100 次，i 取 0~99
```

> 💡 `for (int i = 0; i < n; i++)` 是 C++ 程序员**最常用**的循环写法，见到要秒懂：循环 n 次。

![for 循环：指针移动，sum 逐次累加](demos/demo_for.gif)
### 6.1 循环嵌套：九九乘法表

循环里再套循环，外层管"行"，内层管"列"：

```cpp
for (int i = 1; i <= 9; i++) {          // 外层：第几行
    for (int j = 1; j <= i; j++) {      // 内层：这一行有几列（到 i 为止）
        cout << j << "x" << i << "=" << i * j << "\t";
    }
    cout << endl;                        // 每行结束换行
}
```

**执行过程**（想象 i=2 时）：
- 外层进入 i=2
- 内层 j=1：输出 `1x2=2`
- 内层 j=2：输出 `2x2=4`
- 内层 j=3：3 <= 2 假 → 内层结束
- `cout << endl` 换行
- 外层进入 i=3 ...

**结果长这样：**
```
1x1=1
1x2=2	2x2=4
1x3=3	2x3=6	3x3=9
...
```

**马上动手（练习 5）**：用 for 循环输出 100 以内的**所有偶数**（每行 5 个）。

## 第 7 步：do-while 和 break/continue

### 7.1 do-while：至少执行一次

普通 while 是"先判断再执行"；`do-while` 是"**先执行再判断**"——**至少执行一次**。

```cpp
int guess;
do {
    cout << "请输入密码：";
    cin >> guess;
} while (guess != 1234);      // 不对就再问
```

**和 while 的区别：**

| 场景 | while | do-while |
| --- | --- | --- |
| 先判断后执行 | ✅ | ❌ |
| 先执行后判断 | ❌ | ✅ |
| 最少执行次数 | 0 次 | **1 次** |

什么时候用 do-while？**"至少要问一次"的场景**，比如猜数字、输密码、输入选项。

### 7.2 break：立即跳出循环

```cpp
for (int i = 1; i <= 10; i++) {
    if (i == 5) break;        // i 到 5 就立刻跳出整个循环
    cout << i << " ";
}
// 输出：1 2 3 4（5 都没输出就跳出了）
```

### 7.3 continue：跳过本次，继续下一次

```cpp
for (int i = 1; i <= 5; i++) {
    if (i == 3) continue;     // i=3 时跳过本次剩余代码
    cout << i << " ";
}
// 输出：1 2 4 5（3 被跳过，但循环继续）
```

**break vs continue 对比：**
- `break`：**结束**整个循环（离开循环）
- `continue`：**跳过**当前这一次，进入下一次循环

**马上动手（练习 6）**：输出 1~20 中所有**不是 3 的倍数**的数（提示：用 continue 跳过 3 的倍数）。

## 第 8 步：综合项目——猜数字游戏（逐步构建）

把今天学的**随机数 + do-while + if 判断**全部用上。分三步搭：

### 第 1 小步：生成随机数

```cpp
#include <cstdlib>   // rand, srand
#include <ctime>     // time
srand((unsigned)time(nullptr));   // 用当前时间做"随机种子"
int target = rand() % 100 + 1;    // 生成 1~100 的随机数
```

- `srand(...)`：给随机数生成器一个"种子"。**不设置的话，每次运行随机数都一样**
- `rand() % 100`：得到 0~99 的随机数，`+1` 后变成 1~100

### 第 2 小步：循环 + 判断（核心逻辑）

```cpp
int guess = 0;
do {
    cin >> guess;                    // 读入猜测
    if (guess > target) {
        cout << "大了！再试：";
    } else if (guess < target) {
        cout << "小了！再试：";
    }
} while (guess != target);           // 没猜中就一直循环
```

### 第 3 小步：加上统计，凑成完整程序

```cpp
#include <iostream>
#include <cstdlib>
#include <ctime>
using namespace std;

int main() {
    srand((unsigned)time(nullptr));
    int target = rand() % 100 + 1;
    int guess = 0, times = 0;

    cout << "【猜数字】我心里想了一个 1~100 的数，你来猜：" << endl;
    do {
        cin >> guess;
        times++;
        if (guess > target) {
            cout << "大了！再试：";
        } else if (guess < target) {
            cout << "小了！再试：";
        }
    } while (guess != target);

    cout << "恭喜猜对！你一共猜了 " << times << " 次。" << endl;
    return 0;
}
```

**逐行精讲：**
- `int target = rand() % 100 + 1;`：随机目标数
- `do { ... } while (guess != target);`：**先让你猜一次**，不对再循环——完美契合 do-while 的"至少执行一次"
- `times++;`：每猜一次计数 +1
- 程序结束前把 target 输出出来，方便测试（正式版可去掉）

**自己改一改（挑战）**：
1. 把随机范围改成 1~1000
2. 限制最多猜 10 次，超过就输出"你输了，答案是 X"（提示：用 if (times == 10) break）
3. 玩家猜对后，根据次数给出评价："天才！"（≤5 次）/ "不错"（≤10 次）/ "继续加油"

    cin >> n;

    bool prime = true;
    for (int i = 2; i < n; i++) {
        if (n % i == 0) { prime = false; break; }   // 找到因子，不是质数
    }
    if (prime) {
        cout << n << " 是质数" << endl;
    } else {
        cout << n << " 不是质数" << endl;
    }
    return 0;
}

## ⚠️ 今日坑点汇总

| 坑 | 说明 | 正确做法 |
| --- | --- | --- |
| if 后面加分号 | `if (x) ;` 导致分支失效 | if 括号后直接跟 `{` |
| 用 `=` 代替 `==` | 判断变赋值，恒为真 | 判断用 `==` |
| switch 漏 break | 穿透执行多个 case | 每个 case 末尾加 break |
| while 忘写条件更新 | 死循环卡死 | 循环体内改变条件变量 |
| 条件顺序搞反 | 宽松条件挡在前面 | 从严格到宽松排列 |
| `rand()` 不设种子 | 每次运行随机数相同 | 先 `srand(time(nullptr))` |
