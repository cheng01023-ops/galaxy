## 第 1 步：为什么要学函数？

假设你要在程序里三次输出"欢迎光临本系统"，于是复制粘贴了三次：

```cpp
cout << "==========" << endl;
cout << "欢迎光临本系统" << endl;
cout << "==========" << endl;
// ... 200 行代码 ...
cout << "==========" << endl;
cout << "欢迎光临本系统" << endl;
cout << "==========" << endl;
```

**问题来了：** 哪天想把分隔线从 `=` 改成 `-`，你得改 3 处；复制 10 次就得改 10 处，漏改一处就出 bug。

**函数就是来解决这个的**：把一段代码**打包成一个"工具"**，起个名字，想用就调用一次。

```cpp
void welcome() {
    cout << "==========" << endl;
    cout << "欢迎光临本系统" << endl;
    cout << "==========" << endl;
}

int main() {
    welcome();   // 用一次
    // ... 200 行代码 ...
    welcome();   // 再用一次
    return 0;
}
```

以后想改分隔线，**只改函数里的 3 行**，所有调用处自动生效。

## 第 2 步：函数核心——定义、调用、参数、返回值

### 2.1 函数的结构

```cpp
返回类型  函数名(参数列表) {
    函数体
    return 返回值;
}
```

**看两个例子：**

```cpp
// 例子 1：无参数、无返回值
void sayHello() {
    cout << "你好！" << endl;
}

// 例子 2：两个参数、有返回值（返回两个数中较大的）
int max2(int a, int b) {
    if (a > b) return a;
    else return b;
}
```

### 2.2 调用函数

```cpp
sayHello();               // 直接调用（无返回值）
int m = max2(3, 7);       // 调用并把返回值存进 m
cout << max2(10, 2);      // 也可以直接用
```

**调用过程**（脑子里的画面）：
1. 程序跳到函数定义处
2. 把实参（3 和 7）复制给形参（a 和 b）
3. 执行函数体
4. `return` 把结果带回调用处，程序回到调用点继续往下

### 2.3 return 的两种角色

```cpp
int max2(int a, int b) {
    if (a > b) return a;   // 返回"值"并结束函数
    return b;              // 走到这说明 a <= b
}
```

- `return 值;`：既**结束函数**，又**把值送回调用处**
- `void` 函数里的 `return;`：只结束函数，不带值（可省略）

### 2.4 常见错误

```cpp
int max2(int a, int b) {        // 函数声明返回 int
    if (a > b) return a;        // ✅
    // 如果 a <= b 走到函数末尾，没有 return → ❌ 编译警告/未定义行为
}
// 修复：保证所有路径都有返回值（见 2.3 的写法）
```

## 第 3 步：值传递——函数里改了外面不变（重点！）

**看这段代码，猜猜输出什么：**

```cpp
void tryChange(int x) {
    x = 999;
}

int main() {
    int num = 5;
    tryChange(num);
    cout << num;     // 输出 5 还是 999？
    return 0;
}
```

**答案是 5。** 因为 C++ 默认是**值传递**：调用时把 `num` 的**值复制一份**给 `x`，函数里改的是"副本"，外面的 `num` 毫发无损。

```
main 里的 num（5）  ──复制──▶  函数里的 x（5 → 改成 999）
外面的 num 还是 5
```

**这个特性重要在哪？**
- 好处：函数不会"意外"修改你的数据，安全
- 限制：想通过函数**真正修改外面的变量**，光靠值传递做不到——这正是**明天（第 4 天）指针/引用**要解决的

**马上动手（练习 2）**：写一个函数尝试交换两个数（用值传递），在 main 里调用后打印，确认"没换成功"，亲身体验这个现象。

<details><summary>点开看参考答案</summary>

```cpp
#include <iostream>
using namespace std;

void trySwap(int a, int b) {   // 值传递：a、b 是副本
    int t = a;
    a = b;
    b = t;
}

int main() {
    int x = 1, y = 2;
    trySwap(x, y);
    cout << "x = " << x << ", y = " << y << endl;   // 还是 1 和 2
    return 0;
}
```
</details>

## 第 4 步：默认参数 + 函数重载

### 4.1 默认参数：不传就用默认值

```cpp
void greet(string name, string prefix = "你好") {
    cout << prefix << "，" << name << "！" << endl;
}

greet("小明");              // 不传 prefix → 用默认值 → "你好，小明！"
greet("小红", "早上好");    // 传了 → "早上好，小红！"
```

**规则**：默认参数必须放在参数列表**右边**，`void f(int a, int b = 1, int c = 2)` 可以，`void f(int a = 1, int b)` 不行。

### 4.2 函数重载：同名不同参

同一个名字可以定义多个函数，只要**参数个数或类型不同**，编译器会自动匹配：

```cpp
void greet(string name) {            // 版本 1：一个参数
    cout << "你好，" << name << endl;
}
void greet(string name, int times) { // 版本 2：两个参数，打印多次
    for (int i = 0; i < times; i++) {
        cout << "Hi, " << name << " ";
    }
    cout << endl;
}

greet("小明");        // 调版本 1
greet("小李", 3);     // 调版本 2
```

> ⚠️ 只有返回值不同不算重载（编译器无法区分），必须参数不同。

## 第 5 步：作用域——变量"活"在哪

**大括号 `{ }` 决定变量的可见范围**：

```cpp
int main() {
    int a = 10;              // a 从这行到 main 结束都可见

    {
        int b = 20;          // b 只在这个花括号里可见
        cout << a + b;       // ✅ 能访问 a（外层）也能访问 b
    }
    // cout << b;            // ❌ 编译错误：b 已"死亡"
    cout << a;               // ✅ 没问题

    return 0;
}
```

**局部变量 vs 全局变量：**

```cpp
int global = 100;            // 全局变量：所有函数都能用（尽量少用）

void f() {
    cout << global;          // ✅ 函数里能访问全局
}

int main() {
    int local = 5;           // 局部变量：只在 main 里
    f();
    return 0;
}
```

**原则**：优先用局部变量和参数传递数据；全局变量多了代码难维护（谁都改它，出了问题难定位）。

## 第 6 步：递归——函数调用自己

### 6.1 什么是递归

**递归就是函数自己调用自己**，适合解决"可以分解成更小同类问题"的场景。

### 6.2 求阶乘 n!

阶乘的定义：`5! = 5 × 4 × 3 × 2 × 1`

换个写法：`n! = n × (n-1)!`——这就是递归的核心："求 n! 的问题，变成了求 (n-1)! 的更小问题"。

```cpp
long long factorial(int n) {
    if (n <= 1) return 1;            // ① 递归出口：n=1 时直接返回 1
    return n * factorial(n - 1);     // ② 递归调用：问题规模变小
}
```

**执行过程**（factorial(4) 的追踪）：

```
factorial(4) = 4 * factorial(3)
             = 4 * 3 * factorial(2)
             = 4 * 3 * 2 * factorial(1)
             = 4 * 3 * 2 * 1        ← 出口，开始"一层层返回"
             = 24
```

**递归必须满足两个条件（缺一不可）：**
1. **有出口**：递归到某个值时直接返回，不再调用自己（否则无限递归 → 栈溢出崩溃）
2. **规模变小**：每次调用都更接近出口

![递归：一层层下潜到出口，再一层层回推](demos/demo_recursion.gif)
### 6.3 斐波那契数列

数列：1, 1, 2, 3, 5, 8, 13...（每一项 = 前两项之和）

```cpp
int fib(int n) {
    if (n <= 2) return 1;            // 出口：前两项都是 1
    return fib(n - 1) + fib(n - 2);  // 分解成两个更小的子问题
}
```

### 6.4 用断点"看"递归（强烈推荐）

1. 在 `return n * factorial(n - 1);` 这行打断点
2. 运行，程序第一次停在这
3. 用 **Step Into** 进入 `factorial(n-1)`，观察每次进入时 n 的值：4 → 3 → 2 → 1
4. 到 n=1 时走 `return 1`，然后一层层 **Step Out** 返回，观察返回值怎么乘出来的

> 亲眼看过一次递归的进出过程，你就永远不会忘记它。

**马上动手（练习 3）**：写一个递归函数 `int sumTo(int n)`，返回 1+2+...+n 的和（提示：`sumTo(n) = n + sumTo(n-1)`）。

<details><summary>点开看参考答案</summary>


## 第 7 步：数组——存"一批"数据

### 7.1 为什么需要数组

想存 5 个成绩，用 5 个变量太痛苦：

```cpp
int s1, s2, s3, s4, s5;   // 5 个还行，500 个呢？
```

数组就是**一排带编号的格子**，用"数组名 + 下标"访问：

```cpp
int scores[5] = {88, 92, 76, 85, 90};
//  下标：      0    1    2    3    4

cout << scores[0];   // 88（第 1 个）
cout << scores[3];   // 85（第 4 个）
scores[1] = 95;      // 修改第 2 个
```

### 7.2 铁律：下标从 0 开始！

```cpp
int arr[5];           // 合法下标：0,1,2,3,4
arr[5] = 10;          // ❌ 越界！访问了不存在的第 6 个
```

**越界不报错，但很危险**：它可能悄悄改掉内存里别处的数据，导致诡异 bug。写代码时心里默念：**长度为 n 的数组，下标最大 n-1**。

### 7.3 遍历数组 + 求最值

```cpp
int scores[5] = {88, 92, 76, 85, 90};

// 求和
int sum = 0;
for (int i = 0; i < 5; i++) {
    sum += scores[i];
}
cout << "平均分：" << sum / 5.0 << endl;

// 求最大值
int maxV = scores[0];               // 先假设第一个最大
for (int i = 1; i < 5; i++) {
    if (scores[i] > maxV) {
        maxV = scores[i];           // 发现更大的就更新
    }
}
cout << "最高分：" << maxV << endl;
```

**求最值的套路**：先拿第 0 个当"冠军"，然后逐个挑战，赢了就换人。

### 7.4 二维数组（表格）

```cpp
int table[3][4] = {            // 3 行 4 列
    {1, 2, 3, 4},              // 第 0 行
    {5, 6, 7, 8},              // 第 1 行
    {9, 10, 11, 12}            // 第 2 行
};

cout << table[1][2];           // 第 2 行第 3 列 = 7
table[0][0] = 100;             // 修改第 1 行第 1 列
```

读法：`table[行][列]`，都从 0 开始。

## 第 8 步：冒泡排序——经典算法逐步推演

**问题**：把 `{5, 2, 9, 1, 7}` 从小到大排好。

**冒泡排序的思路**：相邻两个比较，**大的往后"冒"**。每一轮把当前最大的数送到末尾。

**第一轮过程（把最大的 9 冒到末尾）：**

```
[5, 2, 9, 1, 7]
 5>2? 是 → 交换 → [2, 5, 9, 1, 7]
 5>9? 否 → 不动 → [2, 5, 9, 1, 7]
 9>1? 是 → 交换 → [2, 5, 1, 9, 7]
 9>7? 是 → 交换 → [2, 5, 1, 7, 9]   ← 9 到位
```

**第二轮**（范围缩小到前 4 个，把 7 冒到位）：`[2, 1, 5, 7, 9]`
**第三轮**：`[1, 2, 5, 7, 9]` ... 直到全部有序。

**代码实现：**

```cpp
int arr[] = {5, 2, 9, 1, 7};
int len = sizeof(arr) / sizeof(arr[0]);   // 计算元素个数：20/4 = 5

for (int i = 0; i < len - 1; i++) {            // 外层：一共需要 len-1 轮
    for (int j = 0; j < len - 1 - i; j++) {    // 内层：每轮少比较一次（末尾已就位）
        if (arr[j] > arr[j + 1]) {             // 相邻比较，大的往后
            int t = arr[j];                    // 交换三个步骤
            arr[j] = arr[j + 1];
            arr[j + 1] = t;
        }
    }
}
```

**逐行精讲：**
- `sizeof(arr)`：整个数组占的字节数（5 个 int = 20 字节）
- `sizeof(arr[0])`：一个元素占的字节数（4 字节）
- 相除得到元素个数 5
- 外层 `i < len - 1`：5 个数最多需要 4 轮
- 内层 `j < len - 1 - i`：第 i 轮后，末尾 i 个数已就位，不用再比
- 交换三连：`t = a; a = b; b = t;`（必须用临时变量，否则覆盖丢失）

## 第 9 步：string 字符串操作

`string` 是 C++ 处理文本的主力类型，比 C 风格的字符数组好用太多。

### 9.1 基本操作

```cpp
#include <string>

string s1 = "Hello";
string s2 = "C++";

string s3 = s1 + " " + s2;   // 拼接 → "Hello C++"
s3.length();                  // 长度 → 9
s3[0];                        // 按下标取字符 → 'H'（下标也从 0 开始）
s3[1] = 'a';                  // 修改 → "Hallo C++"
```

### 9.2 常用方法速查

| 方法 | 作用 | 例子 |
| --- | --- | --- |
| `s.length()` | 长度 | `"abc".length()` → 3 |
| `s.substr(起始, 个数)` | 取子串 | `"Hello".substr(1,3)` → "ell" |
| `s.find("关键词")` | 查找，返回位置 | `"Hello".find("ll")` → 2 |
| `s.empty()` | 是否为空 | `"" .empty()` → true |
| `s1 + s2` | 拼接 | `"a" + "b"` → "ab" |

**find 的坑**：找不到时返回 `string::npos`（一个很大的数），要用它判断：

```cpp
string s = "I love C++";
size_t pos = s.find("Python");
if (pos == string::npos) {
    cout << "没找到 Python" << endl;
} else {
    cout << "找到了，位置：" << pos << endl;
}
```

### 9.3 getline：读取含空格的整行

`cin >>` 遇到**空格就停**，所以 `cin >> s` 只能读一个单词。想读整行用 `getline`：

```cpp
string line;
getline(cin, line);        // 读一整行（含空格）
```

**经典坑：cin 和 getline 混用**

```cpp
int age;
cin >> age;                // 输入 18 后按回车
string name;
getline(cin, name);        // ❌ 读到的 name 是空的！
```

**原因**：`cin >> age` 读走 18，但**回车符还留在缓冲区**；`getline` 读到这个回车符，以为行结束了。

**解决**：在中间加 `cin.ignore();` 清掉残留的回车符：

```cpp
int age;
cin >> age;
cin.ignore();              // 清掉缓冲区里的换行符
string name;
getline(cin, name);        // ✅ 正常读整行
```

**练习 B（进阶）：二分查找**
在**已排序**数组里找数字 x，返回下标，找不到返回 -1。
思路：每次都和中间的数比，决定去左半边还是右半边找，每轮排除一半。

<details><summary>点开看答案</summary>

```cpp
#include <iostream>
using namespace std;

int binarySearch(int arr[], int len, int x) {
    int lo = 0, hi = len - 1;
    while (lo <= hi) {
        int mid = (lo + hi) / 2;
        if (arr[mid] == x) return mid;
        else if (arr[mid] < x) lo = mid + 1;   // 去右半边
        else hi = mid - 1;                     // 去左半边
    }
    return -1;
}

int main() {
    int arr[] = {1, 3, 5, 7, 9, 11};
    int len = sizeof(arr) / sizeof(arr[0]);
    cout << binarySearch(arr, len, 7) << endl;   // 3
    cout << binarySearch(arr, len, 8) << endl;   // -1
    return 0;
}
```
</details>

**练习 C（挑战）：字符串反转**
输入一个字符串，原地反转后输出。提示：用两个下标，一个从前往后、一个从后往前，交换字符。

<details><summary>点开看答案</summary>

```cpp
#include <iostream>
#include <string>
using namespace std;
int main() {
    string s;
    cout << "输入字符串：";
    getline(cin, s);

    int left = 0, right = (int)s.length() - 1;
    while (left < right) {
        char t = s[left];
        s[left] = s[right];
        s[right] = t;
        left++;
        right--;
    }
    cout << s << endl;
    return 0;
}
```

## ⚠️ 今日坑点汇总

| 坑 | 说明 | 正确做法 |
| --- | --- | --- |
| 数组越界 | `arr[n]` 访问不存在的位置 | 记住下标 0~n-1 |
| 忘写递归出口 | 无限递归 → 栈溢出崩溃 | 先写 `if (n <= ...) return ...` |

| 默认参数放左边 | 编译错误 | 默认参数放参数列表右边 |
| find 返回值直接当下标 | 找不到时是超大数 | 先判断 `== string::npos` |
